# Provenance

This plugin is developed in the Maka repository and uses Maka's Agent, Session, storage, source and client-plugin APIs. Build and test adapters derive from the Apache-2.0 memory-network plugin in this repository.

The extension bundles Zod (MIT); its license is included in the package alongside Maka's LICENSE and NOTICE. Test adapters and generated artifacts are development-only and are not shipped. No model credentials, user history or live database is included.
