```js
function setApmConfig(enName = '', emplid = '') {
  conf({
    request: { errorsIgnore: [status => status >= 300 && status < 400, '403', '500', '504'] },
    customAuthInfoSync: { enName, emplid, systemName: 'mc' },
    plugin: {
      error: {
        sendErrorToLogcenter: true, // 错误埋点发送到 日志中心
        reportConsoleError: true,   // 全局错误拦截插件，对console.error的内容进行错误埋点收集
      },
    },
  });
}
```

### 3.2 13 分钟内自我推翻的 publicPath

```js
// c41ddf2 17:38 修复项目打包入口路径问题
-    publicPath: process.env.LEGO_FRONTEND_PUBLIC_PATH || 'statics/',
+    publicPath: path.join(process.env.LEGO_FRONTEND_PUBLIC_PATH, 'statics') || 'statics/',
```
