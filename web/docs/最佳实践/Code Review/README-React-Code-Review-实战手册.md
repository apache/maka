# React Code Review 实战手册

## 总入口

这是一套基于 SSAP 中后台项目与 Vercel 规则体系整理出来的 React Code Review 手册。目标不是堆积零散规范，而是建立一套可复用、可面试、可项目复盘、可让 AI 调用的审查系统。

## 阅读路线

建议先读第 1 章到第 3 章建立地图，再重点吃透第 4 章到第 10 章，之后用第 11 章到第 14 章完成案例、规则和面试输出收口。

## 使用建议

1. 看陌生 PR 时，先按第 2 章的扫描顺序走一遍。
2. 遇到具体问题时，回到对应专题章。
3. 复盘 SSAP 项目代码时，重点看第 11 章。
4. 面试准备时，重点看第 13 章和第 14 章。
5. 做长期沉淀时，用第 14 章的 64 条规则做统一编号体系。

## 章节分工

- 第 1 章到第 3 章负责建立全书骨架。
- 第 4 章到第 10 章负责按复杂度来源拆专题。
- 第 11 章负责把 SSAP 真实代码讲透。
- 第 12 章负责把外部最佳实践映射到本地场景。
- 第 13 章负责压缩成面试可直接说出口的模板。
- 第 14 章负责冻结成 64 条规则总表。
