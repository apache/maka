# Review DRILL 台账

## 规则

- 每次一题：5 分钟计时，脱稿，输出发现；计时结束才对照《DRILL-题库.md》答案键打分。
- 漏因只有三类：A 没认出（补知识）/ B 认出了说不清（补口述）/ C 说得清但顺序乱（补扫描顺序）。
- 频率：找工作每周 1 次；平时双周 1 次。
- 判停：连续 2 次同一题命中 ≥80% 且漏因无 A 类 → 加新题，不重刷。
- 只追加，不删历史。第一次 = 题 0 冷启动，结果就是半年后的真实水平，和当年"当时是否想到"对照。
