# pure-admin-thin-max-js 从入门到精通

这是一套写给"要在这个项目上干活的人"的源码导读。全部内容基于当前仓库 v7.0.0 的源码逐文件整理（基线 commit `859f3f8`），文中出现的每个路径、命令和行为都可以对照源码核验。哪句话和代码对不上，以代码为准，并欢迎修正文档。

## 你需要先满足的条件

| 依赖 | 最低版本 | 检查命令 |
| --- | --- | --- |
| Node.js | 22.22.1 | `node -v` |
| pnpm | 11 | `pnpm -v` |
| Git | 2.32.0 | `git --version` |

版本要求来自 `package.json` 的 `engines` 字段和上游提交说明。项目用 `preinstall` 钩子强制 pnpm，用 npm 或 yarn 安装会直接报错。

## 五分钟跑起来

```bash
pnpm install        # 安装依赖，首次较慢
pnpm dev            # 启动开发服务器
```

浏览器打开 `http://localhost:8848`（端口来自 `.env` 的 `VITE_PORT`）。登录页预填了 `admin / admin123`，mock 后端不校验密码，用户名决定角色：用户名 `admin` 是管理员，能看到全部菜单；换成 `common` 是普通用户，只能看到首页和权限管理。这个区别是后面权限篇的核心教具。

## 按需选路

没有大把时间通读的话，按目标挑着读。

- 只想尽快上手改页面：01 → 03 → 11 → 13，遇到名词再回头查。
- 准备对接真实后端：04 → 06 → 09 是主线，07、08 补状态和存储。
- 想彻底吃透这套框架：按顺序读，每篇末尾的"动手验证"都做一遍。

## 阅读约定

- 文中路径都相对仓库根目录，例如 `src/router/utils.js`。
- 术语第一次出现时附解释，例如 keep-alive（Vue 的组件缓存机制）。
- 每篇结尾有"动手验证"和"自查清单"。动手验证是基于当前源码设计的小实验，做完能确认你真的理解了；自查清单是写代码前对照的检查项。
