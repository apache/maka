# vue-pure-admin-max 从入门到精通

一套基于本仓库源码的系列教程。所有文件路径、命令、配置项均对照当前代码（v7.0.0）写就，可逐条核验。

## 这个系列怎么读

按三条阅读路线组织，每条路线对应一个目标。

| 路线 | 章节 | 读完你能 |
| --- | --- | --- |
| 入门（第一天） | 01、02 | 说清这个框架是什么，把它跑起来，改掉标题和端口 |
| 核心机制（第一周） | 03、04、05、06 | 讲透登录到页面渲染的完整链路，能接真实后端 |
| 实战精通（第一个月） | 07 到 11 | 独立新增业务模块，做精简和二次开发 |

章节之间有依赖，跳读的底线：04 依赖 03，05 依赖 04，10 依赖 04、05、06。

## 约定

- 文中路径均相对仓库根目录，如 `src/router/index.ts`。
- 命令默认在仓库根目录执行，包管理器为 pnpm（`package.json` 的 `preinstall` 强制 pnpm）。
- 代码片段仅截取与讲解相关的行，省略处用注释标明。
