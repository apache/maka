# pure-admin-thin-js 从入门到精通

本系列基于仓库当前源码（v7.0.0）逐文件核实后写成。每篇文章只讲一个子系统，全部结论都对应真实文件路径和函数名，读的时候建议开着编辑器对照源码，看到路径就点进去看一眼。

## 这个系列适合谁

- 拿到这份模板要接手开发的工程师：从跑起来到改对、改稳。
- 想理解一套成熟 Vue3 后台模板如何组织路由、权限、请求、状态的人。
- 准备基于这份模板做二次开发（比如新增业务模块、接真实后端）的团队。

前置知识：会用 Vue 3 组合式 API 写过简单页面，了解 npm/pnpm 基本操作。不要求懂 TypeScript（这是 JS 版），不要求看过 vue-pure-admin 完整版。

## 三条阅读路线

按目标选路线，不必从头读到尾。

**接手开发路线**（最快上岗）：01 → 02 → 04 → 05 → 06 → 12。重点掌握权限双轨制和请求层写法，然后直接照第 12 篇开始干活，遇到问题再回头查 03、07。

**理解原理路线**（吃透设计）：02 → 03 → 04 → 05 → 07 → 08。按启动和渲染顺序读，重点看每个机制为什么这样设计，比如路由为什么强制拍平成两级、token 为什么存两份。

**交付上线路线**（准备生产）：10 → 11 → 06。先搞清楚生产环境 mock 未关闭这个坑，再看构建、压缩、CDN 和 Docker，最后核对请求层配置。

## 怎么验证文章里的说法

本系列所有源码引用都遵循同一个格式：文件路径加函数名或标识符，例如 `src/router/utils.js` 的 `initRouter()`。文中给出的命令都标注了用途和预期结果。如果发现文章和源码对不上，以源码为准，并确认一下仓库版本号（`package.json` 的 `version` 字段，本系列基于 7.0.0）。

## 环境要求速查

| 项目 | 要求 | 出处 |
| --- | --- | --- |
| Node.js | ^20.19.0 或 >=22.13.0 | `package.json` 的 `engines` 字段 |
| pnpm | >=9（preinstall 脚本强制校验） | `package.json` 的 `scripts.preinstall` |
| 开发端口 | 8848 | `.env` 的 `VITE_PORT` |
| 路由模式 | hash | `.env.development` 的 `VITE_ROUTER_HISTORY` |
