# 09 - 组件、指令与工具箱

本章结论：模板的可复用资产分三类：`src/components` 下八个 Re 前缀组件、`src/directives` 下六个指令、`src/utils` 下十余个工具模块。图标体系有三套来源（离线 Iconify、在线 Iconify、本地 svg），各有适用场景。第 12 篇实战会直接用到其中的 RePureTableBar、ReDialog 和 message。

## Re 组件族清单

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| ReAuth / RePerms | `src/components/ReAuth`、`RePerms` | 按钮级权限组件（第 04 篇），已全局注册 |
| ReDialog | `src/components/ReDialog` | el-dialog 的函数式封装，`App.vue` 全局挂载，路由切换自动关闭全部弹窗 |
| ReIcon | `src/components/ReIcon` | 图标三件套及 `useRenderIcon` hook，已全局注册 |
| RePureTableBar | `src/components/RePureTableBar` | 表格工具条：刷新、列显隐、密度调整，配合 `@pureadmin/table` 使用 |
| ReCol | `src/components/ReCol` | el-col 的响应式封装 |
| ReSegmented | `src/components/ReSegmented` | 分段控制器（设置抽屉里选布局用的就是它） |
| ReText | `src/components/ReText` | 文本省略展示 |

这些组件在完整版 vue-pure-admin 文档里有带示例的详细说明，本仓库只保留实现没保留示例页。

## 图标三套体系

图标是模板里最容易用错的部分，先把三条管线分清：

**第一套，离线 Iconify（推荐用于菜单和固定 UI）。** 依赖 `@iconify/json` 全量图标集和 unplugin-icons。菜单路由 `meta.icon: "ep:lollipop"` 这种冒号分隔的写法属于它：运行时由 `IconifyIconOffline` 从本地打包数据渲染，不发请求。自己开发时还有更直接的写法，登录页就有示范：

```js
// src/views/login/index.vue —— unplugin-icons 按需导入，编译期内联进 bundle
import Lock from "~icons/ri/lock-fill";
```

`~icons/集合/图标名` 的路径由 build/plugins.js 里 `Icons({ compiler: "vue3" })` 插件解析。离线方案的前提是图标数据被预先注册，`src/components/ReIcon/src/offlineIcon.js` 负责集中 `addIcon`，`src/layout/index.vue` 顶部专门导入了它。

**第二套，在线 Iconify（适合图标数量不确定的场景）。** `IconifyIconOnline` 运行时从 Iconify 的 CDN 拉取。优点是不占包体积，缺点是依赖外网，内网部署会显示空白。选择依据就一条：部署环境能不能访问外网。

**第三套，本地 svg。** build/plugins.js 里 `svgLoader()` 让 svg 可以当组件导入：

```js
// src/views/login/index.vue
import dayIcon from "@/assets/svg/day.svg?component";
```

自己画的图标放 `src/assets/svg/` 下用这种方式，UI 给的切图都走这条路。

三套的判定顺序：UI 内固定图标用离线或本地 svg；内容区动态图标（比如接口返回图标名）用在线；绝不给内网部署的项目用在线图标。

## 六个自定义指令

全部在 `src/directives/` 下，由 `src/directives/index.js` 统一导出、`src/main.js` 遍历注册：

| 指令 | 用途 | 典型用法 |
| --- | --- | --- |
| `v-auth` / `v-perms` | 按钮权限（第 04 篇） | `<el-button v-perms="'user:add'">` |
| `v-copy` | 点击复制到剪贴板 | `<span v-copy="'文本'">` |
| `v-longpress` | 长按触发 | 长按删除、长按录制 |
| `v-ripple` | 点击水波纹 | 卡片、按钮的点击反馈 |
| `v-optimize` | 防抖节流事件绑定 | 高频触发场景 |

## utils 工具箱速览

| 模块 | 内容 | 备注 |
| --- | --- | --- |
| `utils/http/` | PureHttp（第 06 篇） | 全站请求出口 |

| `utils/message.js` | el-message 封装 `message()` | 全站提示统一入口 |
| `utils/mitt.js` | 事件总线 | 跨组件解耦通信 |
| `utils/tree.js` | `buildHierarchyTree` 等 | 路由树处理依赖它 |
| `utils/progress/` | NProgress 顶部进度条 | 路由守卫在用 |
| `utils/localforage/` | 带过期时间的离线存储（第 07 篇） | |
| `utils/responsive.js` | responsive-storage 注入（第 07 篇） | |
| `utils/propTypes.js` | VueTypes 的 re-export | 组件 props 定义 |
| `utils/print.js`、`preventDefault.js`、`globalPolyfills.js` | 打印、事件、浏览器兼容补丁 | 低频 |

注意 `@pureadmin/utils` 这个包（工具函数库，全站大量使用的 `storageLocal`、`debounce`、`deviceDetection`、`isAllEmpty` 都来自它），写业务时先查它有没有现成函数，能省不少自造轮子。

## 一个"半启用"状态：echarts

`echarts ^6.0.0` 在依赖里，`src/plugins/` 下原有过 echarts 按需注册方案，但 `src/main.js` 里 `useEcharts` 的导入被注释，当前没有任何页面使用。要启用图表：取消注释、在依赖完整的前提下按官方完整版文档的写法注册即可。依赖与功能分离是精简版的常见状态，拿到任何"依赖在但没生效"的疑问，先查 main.js 的注册链。
