## 4. Worktree 命令

```bash
# 在主仓库目录
git fetch origin && git switch main && git pull
for wp in wp1-egress wp2-ingress wp3-errors wp5-openai-compatible; do
  git worktree add ../qpa-$wp -b feat/$wp origin/main
done
# 每个 worktree 里
pnpm install && pnpm -r test
# 合并后清理
git worktree remove ../qpa-wp1-egress && git branch -d feat/wp1-egress
```

- 每个编码代理只开一个 worktree，提示词开头就写清它的归属文件（见各工作包）。
- 共享的 fixture（`test/fixtures/**`）只增不改；要改现有 fixture，在 WP0 里改。

## 5. 冲突高发点与对策

| 冲突点 | 对策 |
|---|---|
| 出口序列化器（WP1 vs WP3） | WP1 先合；WP3 只动写头时机，且用 `peekFirst` 包一层，不碰映射 |
| `server.ts`（WP3 / WP6 / WP7） | WP3 抽出 `handleData(req,res)`；WP6 只替换其中 `provider.stream` 为 `routeStream`；WP7 只加 `/admin`、`/ui` 两个前缀分支 |
| `providerRegistry.ts`（WP5 / WP7） | WP5 加静态注册；WP7 改为"从 config 快照构建"，保留 WP5 的工厂函数 |
| `packages/contracts` | 只有 WP0 能改；后续变更走"契约 PR"，所有进行中的包 rebase |
| 控制台 Agent 页（WP8 / WP9） | WP8 做静态壳（mock），WP9 接真实 API 与写入器 |
