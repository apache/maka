## 待你确认的决定

1. **默认策略**：`ordered`（可预测）还是 `smart`？本包建议默认 `ordered`。
2. **legacy `PROXY_API_KEY`** 是否保留到 v1.0？建议保留并标记 deprecated。
3. **改道响应头 `x-qpa-member`** 是否下发给 Agent？建议下发（便于排查），只含 providerId/model。
4. **Claude Code 的 Key 写进 `settings.json`** 还是只走环境变量？建议与 Codex 一致改走环境变量，代价是用户要多一步。
