置信度：**高** = 已在骨架或 spike 里跑通；**中** = 看过源码、逻辑成立但没有端到端跑；**低** = 推测，需要在对应 WP 里验证。

| 结论 | 证据 |

## 3. 有意不做、但应该知道的

- **任务迁到 LangGraph durable execution**：现在的任务是定时器模拟，没有可恢复的中间状态。等真的接入"生成养护方案"的 LLM 调用时再评估。届时任务 = 一个带 checkpointer 的子图，`thread_id = taskId`。
- **持久化 checkpointer**：需要 SQLite / Postgres 依赖和迁移脚本，不在本轮。
- **多用户隔离**：threadId 由前端生成，没有鉴权。演示项目可以接受；上线前 threadId 必须绑定用户会话（服务端签发）。
- **LangSmith / OTel**：不在本轮。

## 4. 回退方案

- WP4 到 WP9 之间，`AGENT_BACKEND=py` 一键回到旧后端，前端协议不变。
- WP9 合并后只能 `git revert`；因此 WP9 的前置条件是 04 §6 的人工验收全部打勾。
