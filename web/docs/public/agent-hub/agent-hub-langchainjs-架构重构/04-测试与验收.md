## 2. 每个包先写的红灯用例

### WP1 工具（tools.test.ts）

1. 本轮没检索 → `present_recommendation` 抛错，信息里含"请先调用 search_evidence"。
2. 引用了上一轮（上一条 HumanMessage 之前）检索到的证据 → 抛错。
3. 检索后引用 → 返回成功；`writer` 依次收到 1 个 card + n 个 evidence，且都能被 `AgentStreamEvent.parse`。
4. card 的 `items[].priceFen` 等于 `CATALOG` 中的值（模型无法传价格：schema 没有这个字段）。
5. `search_catalog({scene:'gift'})` 只返回 gift 商品；artifact 不含 `scenes` 字段。
6. status=error 的检索结果不算"检索过"。

### WP2 翻译（translate.test.ts）

1. reasoning 两段增量 → 同一 seq 追加；新的模型调用 → 新 seq。
2. 开场白 "我先查一下。" + tool_call_chunk → 进 thought，不出 token。
3. 30 字正文无工具调用 → 首个 token 前有 final thought，正文全文无损。
4. ToolMessage(status=error) → 「校验未通过…」thought。
5. 非 model_request 节点的 AIMessageChunk → 无输出。
6. custom card 不合契约 → 最后一个事件是 `error{protocol}`，且没有 done。
7. 抛 `{status:500}` → `error{server}`，message 不含原始报错文本。
8. 中止 → `error{aborted}`。
9. S1–S5 序列断言作为公共函数 `assertSequence(evs)`，其他测试复用。

### WP3 智能体（agent.test.ts）

1. 三场景：卡片标题、商品 id、证据 id、正文全文与旧 `agent.py` 一致（E2E 依赖这些文案）。
2. 幻觉证据策略 → 出现「校验未通过」→ 最终 done 且卡片证据合法。
3. 死循环策略 → `error{server}`，message 含"步数超出上限"，模型调用次数 ≤ 8。
4. 上游抛错 → 只有 1 个 error 事件。
5. 中止：第一个事件后 abort → 最后一个事件是 `error{aborted}`。

### WP4 HTTP（server.test.ts）

1. 每帧匹配 `/^event: (\w+)\ndata: [^\n]+\n\n$/`，且 event 名 = data.type。
2. `{}` → 422；超长 message → 422。
3. `/api/evidence/ev-purchase-01` → 200；`/api/evidence/nope` → 404。
4. 客户端在第一个帧后断开 → 服务端模型调用停止（`ScriptedChatModel` 计数不再增长）。

### WP5 记忆

1. 同 threadId 两轮：第二轮模型收到的消息里有第一轮的 HumanMessage。
2. 不同 threadId 互不可见。
3. 不带 threadId：两次请求互不可见（等价旧行为）。
4. 前端：`reset()` 后 threadId 变化（store 单测或 E2E 断言请求体）。
5. 摘要：`AGENT_SUMMARY_MODEL` 未配置时不挂 summarization；配置后，构造超阈值历史，断言模型收到的消息条数下降（用 fakeModel 作为摘要模型）。

### WP6 Python 任务

1. 重启恢复：快照里 `running` 的任务 → 恢复后为 `failed`（`error: "服务重启，任务已中断，可重试"`），不是永远 running。
2. 回归 `tasks.py:68`：恢复后 `_TASKS` 真的包含该任务。原条件 `task.status not in _TASKS` 是拿状态和 id 比，永远为真。
3. `create_task` 的后台任务被强引用持有，完成后从集合移除。

### WP7 真实路径

假上游按序回放：

- 正常 reasoning + content；
- tool_calls 分 3 片；
- 首帧 `choices: []`；
- HTTP 500；
- 发到一半断开连接；
- 有 usage 的结束帧。

每种都断言事件序列满足 S1–S5，错误码与 02 §5 一致。
