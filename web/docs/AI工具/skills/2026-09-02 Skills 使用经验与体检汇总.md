> 2026-09-02 由 `docs/temp/` 三份笔记收纳成篇：`2026-08-25-备忘录.txt`、`使用技能经验总结.txt`、`skill-doctor会话分析汇总.md`。源文件已确认删除，本文为唯一留存。

## 核心结论

1. 技能按任务路由，不全套加载：ponytail 管最小改动打底，practices-me 管项目实践路由，领域技能（React / TS / 注释 / 文档）只取与本次改动直接相关的约束。
2. skill-doctor 首轮体检（376 会话采样、10 份深度评分，采样窗口 2026-07-09 ~ 08-27）：代码质量 0.80（B）合格，效率 0.56（D）是短板，技能覆盖率 0.15（54 个 skill 只用 8 个）。
3. 效率丢分集中在六类屡错屡犯，全部有对应改法，其中两条要落进 practices-me 和 verification-before-completion（见待办）。

## 二、skill-doctor 体检

### 调用流程（三段式流水线，入口 `/skill-doctor`）

| 阶段 | 执行者 | 做什么 |
|---|---|---|
| 收集 | 脚本 | 扫 `~/.codex/sessions/` 的 rollout 文件，按选定范围采样，产出 inventory.json + 每会话浓缩转录 |
| 评分 | AI | 按 efficiency（四档）和 code_quality（审查档）两把尺子读转录打分 |
| 渲染 | 脚本 | 评分汇总成 report.json，渲染为一页自包含 HTML（带分享按钮） |

同一个 skill，不同模型跑出的报告深度不同——评分这一步本来就是留给执行 AI 的。

### 与 retro 的分工（入口 `/retro`，可带会话标识，不带复盘当前会话）

| | skill-doctor | retro |
|---|---|---|
| 看多少 | 全量会话采样 | 单个会话深挖 |
| 回答什么 | skill 使用率、效率分 | 环境哪里拖累了 AI |
| 产出 | 打分报告页 | 改进清单（按严重度排序） |

retro 按 7 个固定类别找改进点，当前最相关的三个：**导航**（AI 找文件费劲，该加导航指针）、**自动检查**（AI 犯的错本可被 lint/测试拦住）、**空转指令**（AGENTS.md 里写了但从不生效的规则，白占上下文）。

### 推荐节奏

- skill-doctor 双周一次：盯技能使用率变化与效率分（首轮基线：54 装 8 用、效率 0.56）。
- retro 大活儿后跑：迭代收尾时对关键会话复盘，改进项落进 AGENTS.md 或新增 skill。

### 亮点（保持住）

- 10/10 会话收尾都有真实验证证据，未出现一次"没验证就声称完成"。
- 破坏性操作前有盘点纪律（SHA256 校验后再删源、stash 按索引从大到小 drop）。
- 默认不自动提交、只给中文 Conventional Commit 文案、交付说明带结构化验证证据。

### Windows 环境坑（沉淀 here，别再现场探测）

| 坑 | 事实 |
|---|---|
| python3 | 命中商店 stub，静默 exit 49；真 Python 在 `D:\DevTools\Languages\Backend\Python\python.exe`，用绝对路径 |

| node | 不在 PATH，用 fnm bundled runtime（两个会话各撞一次） |
| 家目录 | 项目 AGENTS.md 指向 `C:\Users\ggbdpq` 的规则路径已失效，真实家目录 `C:\Users\802165` |
