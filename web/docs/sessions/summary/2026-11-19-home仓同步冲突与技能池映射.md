## 可复用经验与案例

### 1. stash 含未跟踪保全 → 快进 → 程序化合并（home 仓打法升级）

先例链（备份→还原→ff→回填）见 [2026-10-26-home仓库拉取冲突与技能上架](2026-10-26-home仓库拉取冲突与技能上架.md)，本轮升级点（2026-11-08 实测，在制 994 改动 + 1176 未跟踪）：

1. `git stash push --include-untracked`（裸 stash push 不含未跟踪，skills 更新那批新文件会挡合并）。
2. `merge --ff-only` → `stash apply`。跨机互写的运行态配置才 UU（本轮恰好只有 `.claude/settings.json`、`.codex/config.toml` 两个）。
3. **程序化合并取代手工挑边**，且显式读三方引用绕开 pop 冲突方向坑（旧档：stash pop 里 ours/theirs 与 merge 直觉相反）：`stash@{0}^1`=共同基线、`stash@{0}`=本地版、`HEAD`=远程版。JSON 用递归合并（本地没动取远端；远端没动或两边一致取本地；真冲突取本地——运行态配置 ours 有据）；TOML 用 `git merge-file --ours -p`。两种产物都必须过解析校验（json.loads / tomllib.loads）才算合并完成。
4. 校验未跟踪树完整还原：`git ls-tree -r --name-only stash@{0}^3` 逐个存在才收；stash 本体留作回滚点。

适用边界：ours 一把梭只对机器生成/本机运行态配置成立；人工编辑的真内容冲突不适用。

### 3. CRLF 幻影清理的 Windows 补充

姊妹篇（剥 CR 哈希逐文件鉴定）：[2026-11-01-SMB挂载git克隆同步与CRLF清理](2026-11-01-SMB挂载git克隆同步与CRLF清理.md)。本轮补充：

- **批量场景判定捷径**：`status --porcelain` 的 M 数 − `git diff --name-only | wc -l` = 幻影数（4498−975=3523），比逐文件剥 CR 快一个量级。
- **Windows 命令行上限坑**：一条 `git checkout --` 带 400 个超长中文路径直接翻车（spawnSync 退出）。实测批 50 + 整批失败逐个退避清 3523 个零失败；更稳是姊妹篇的 `--pathspec-from-file + --pathspec-file-nul`。
- 幻影会每轮同步再生（autocrlf 检出即翻行尾），根治候选见待验证。

## 常用命令

```bash
# 已 ignore 却仍跟踪的矛盾清单（前提：ignore 规则已就位；输出即待收口全集）
git ls-files -i -c --exclude-standard

# 在制全量保全（含未跟踪）→ 合并 → 恢复 → 校验未跟踪树；stash 留作回滚点
git stash push --include-untracked -m "home-before-pull-$(date +%Y%m%d)"
git merge --ff-only origin/main && git stash apply
git ls-tree -r --name-only "stash@{0}^3"

# 文本配置三方合并：显式引用取三方，不靠 ours/theirs 方向记忆
git show "stash@{0}^1:<路径>" > base.toml; git show "stash@{0}:<路径>" > ours.toml; git show "HEAD:<路径>" > theirs.toml
git merge-file --ours -p ours.toml base.toml theirs.toml > merged.toml   # 产物必须解析校验

# CRLF 幻影批量还原：M 列表与真实 diff 列表求差，pathspec 文件避开命令行长度上限
git status --porcelain -z -- <目录> | 求差于 git diff --name-only -z > /tmp/phantom.nul
git checkout --pathspec-from-file=/tmp/phantom.nul --pathspec-file-nul --

# gh 验证 org/repo 存在性（exit 0 即存在）与搜索补刀
gh api repos/<org>/<repo> --jq .full_name
gh search repos <关键词> --limit 3 --json fullName,stargazersCount
```

第 2/3/4 条本轮以一次性 Node/Python 脚本实现（用后即删），上列为行为等价 bash 化示意；求差管道需自写（porcelain -z 为 NUL 分隔）。
