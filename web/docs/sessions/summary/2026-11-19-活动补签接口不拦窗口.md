## 常用命令

场景：分支已经 fetch，工作区必须停在另一个分支，又要确认某接口在不在功能分支上。前提：目标 ref 已在本地，不额外 fetch。在对应仓库目录执行。本轮在 PowerShell 下跑通。成功信号：功能分支有命中，当前 `HEAD` 无命中，且 ancestor 检查退出码为 1。副作用：只读；退出码 1 在这里表示「不是祖先 / 无匹配」，不是网络失败。

```powershell
git grep -n -e "manualSignIn" -e "stat/summary" -e "stat/satisfaction" origin/feature/master_4.44.3_20261027 -- "*.java"
git show origin/feature/master_4.44.3_20261027:clife-senior-org-web-bff-app/src/main/java/com/clife/senior/org/web/bff/controller/aggregate/web/activity/ActivityApplicantAggregateController.java
git merge-base --is-ancestor origin/feature/master_4.44.3_20261027 HEAD; echo "ancestor_exit:$LASTEXITCODE"
git grep -l "manualSignIn" HEAD -- "*.java"
```

`git show <ref>:<path>` 本身已有多份笔记。上面这组的用处是同时证明「当前检出没有」。
