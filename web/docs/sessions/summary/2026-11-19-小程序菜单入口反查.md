# 小程序菜单入口反查

## 一句话结论

从界面文案找小程序页面时，先看 `app.config` 是否注册，再区分写死跳转和远程菜单的 `menuUrl`。同名页面文件未进 `pages` 列表，就不是现行入口。

## Skill 增量建议

目标：`gua-dev-tools` → `modules/prd/MODULE.md`「从组件反查页面入口」。建议追加，不另开节。未改 Skill。未执行检验。

现有规则从组件文件上追 `import`，再对齐仓内 routes/菜单，并用 `router.push` / `router-link` 判断是否仍在用。它不覆盖两件事：界面文案先于文件路径；小程序宫格可以不在仓内菜单常量里，而由运行时菜单下发。

建议追加：

> 从界面文案反查时，先搜文案，再只把 `app.config` 已注册页面当现行入口；同名页面未进入 `pages` 则标未注册。宫格若本地菜单常量里没有该项，先查运行时菜单的 `menuUrl`，不要因为没有写死路径就判断入口不存在。`Taro.navigateTo` 与 `router.push` 同样算跳转证据。

来源：本对话对 `mp-c-terminal-wxapp` 的静态检索。`subPkg/activeManage/index.tsx` 写死标题「热门活动」，但 `src/app.config.ts` 的 `subPkg.pages` 没有它；已注册的是 `activePkg/activeManage/index`。首页宫格来自 `getMenuByLoginUser`，筛「首页 → 快捷菜单」（`src/pages/index/index.tsx` 的 `httpGetMenuList`，`MenuList` 渲染）。`src/pages/index/config.js` 的 `MENU_LIST` 也有「热门活动」，但不是截图那排宫格。

边界：只用于「这段界面从哪进」。不用于改菜单、改路由或推断未抓到的接口字段。

检验场景：两份源码都写「热门活动」，只报未注册的 `subPkg` 为错；报已注册的 `activePkg`，并说明宫格 `menuUrl` 要看菜单响应，为对。

`gua-writer`、`gua-pr-patch` 无增量。这是公司小程序的入口定位，不是文档写作，也不是上游贡献。

## 可复用经验与案例

问题：长者小程序已本地启动，截图是首页宫格里的「热门活动」，源码里同名命中不止一处。

关键证据（均为源码静态可见，本对话未抓菜单响应、未在开发者工具里点按）：

| 看到的 | 实际归属 |
| --- | --- |
| 首页宫格（企业概况、服务介绍、热门活动等） | 登录后 `menu/getMenuByLoginUser`，「首页 → 快捷菜单」；点击走 `onMenuClick(menuUrl)` |
| 首页内容区「热门活动」卡片 | `hasHomeModule('热门活动')` 控制显隐；卡片在 `src/pages/index/comp/active/index.tsx`，更多跳 `/activePkg/activeManage/index` |
| 活动页 | `src/activePkg/activeManage/index.tsx`；列表 `components/activeList`；接口 `getHotActivityList` |
| 同名旧页 | `src/subPkg/activeManage/index.tsx` 未进 `app.config`，不能当点击目标 |
| 「我的」里的活动 | `src/pages/mine/config.js` 跳 `/activePkg/activeManage/index?activeType=2`，打开的是「我的活动」 |

取舍：宫格文案和跳转地址分属两处。文案能定位页面，不能代替该租户菜单里的 `menuUrl`。内容卡片和宫格可以同名，但是两个入口。

下次复用：在这个小程序里按首页宫格文案找页时，沿「文案 → `app.config` 注册页 → 谁 `navigateTo` 了它 → 宫格是否只在菜单接口里」走一遍。`businPkg` 下企业概况、服务介绍等页的注释已写明入口是首页宫格，模式相同。

## 待验证与不适用边界

- 未闭环：当前登录租户返回的「热门活动」`menuUrl` 字面量没有抓到。代码里其它跳转指向 `/activePkg/activeManage/index`，只能当作候选，不能写成该租户菜单的实测值。
- 本地是否真能点到该页，取决于菜单有没有下发这一项；源码里有页面，不表示当前账号首页看得见。
- 不适用于 H5 的 `router.push` 反查，也不适用于把 `MENU_LIST` 当成截图宫格。
