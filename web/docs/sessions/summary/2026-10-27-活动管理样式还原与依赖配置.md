# 活动管理 7 模块样式还原与本地依赖配置

**一句话总结**：microweb-saas-business 本地跑不起来是私有 npm 源缺 CNB_TOKEN（设环境变量解决）；7 个新页面的样式还原要走"原型 iframe 里取计算样式 → 项目侧同位置对比 → 只改页面级样式"的路子，踩坑点全在 CSS Modules 隔离和公共组件覆盖上。

## 背景

接手"活动管理·机构端 7 模块"开发包迁移到 microweb-saas-business：先是 `npm install` 全部 401 起不来；装好后逐页对照高保真原型（单文件 HTML，内容渲染在 sandbox iframe 里）修样式，第一轮按原型做了 16px 留边的共享框架被推翻——现有系统的页面惯例是 24px 左右留边，以现有页面为准重新调。

## 核心命令

```bash
# 私有源 token：从已配置的兄弟项目 .npmrc 里取（注意剥离 CRLF，否则 npm 报 not a legal HTTP header value）
TOKEN=$(grep -o '_authToken=.*' ../<兄弟项目>/.npmrc | cut -d= -f2 | tr -d '\r\n')

# 安装依赖（peer 冲突必须带 --legacy-peer-deps，CI 同款参数）
CNB_TOKEN=$TOKEN npm ci --legacy-peer-deps

# token 永久写入用户环境变量；setx 不影响已开进程，需重开终端
setx CNB_TOKEN "<token值>"

# 启动：固定 4002 端口，只有 npm run start 有效（start:dev 等脚本没人消费 REACT_APP_ENV）
npm run start

# 代码量统计（git ls-files 天然排除 node_modules，wc 汇总）
git ls-files -- '*.js' '*.jsx' '*.ts' | xargs -d '\n' -n 200 wc -l | awk '/total$/{s+=$1} END{print s}'

# 找项目现有页面的留边惯例（定标准用，别猜）
grep -rn "padding.*24px" src/pages --include="*.scss" | grep -v <新模块目录> | head

# 看"暂存区 vs 工作区"差异：先 git add 旧版，再覆盖工作区，diff 出来就是新旧版差异
git status --porcelain   # 第一列=暂存区状态，第二列=工作区改动；AM=暂存后工作区又改了
```

原型样式测量（原型 HTML 把应用渲染进 sandbox iframe，要先进 contentDocument 再逐级点菜单）：

```js
// 浏览器控制台或 MCP evaluate_script 里跑；iframe 无 src，用 contentDocument 拿文档
const doc = document.querySelector("iframe.frame").contentDocument;
const el = [...doc.querySelectorAll(".sub-item")].find(e => e.textContent.trim() === "活动报名");
el.click();  // 点菜单切视图，等 500ms 再取
// 取计算样式：getComputedStyle(el) 读 padding/margin/gap/font/radius/shadow，别目测截图
```

## 关键结论

1. **npm 401 根因**：项目 `.npmrc` 里 `_authToken=${CNB_TOKEN}` 依赖环境变量注入，CI 平台自动注入、本地没人注入就是空。解法只有环境变量一条路：写进项目 `.npmrc` 不安全（git 跟踪），写用户级 `~/.npmrc` 会被项目 `.npmrc` 覆盖，均无效。
2. **CSS Modules 的哈希类没法跨文件覆盖**。公共组件（Query/TableNormal）根类名是哈希值，页面里必须用组件源码里写死的普通字符串类（`formContent`、`rowContent`、`seach-button`）通过 `:global` 嵌套在本页根类下覆盖。
3. **Query 组件有个好设计**：除 `queryConfig/setQuery` 外的 props 全部透传给内部 antd Form，所以页面可以直接传 `colon={false}`（去掉 label 冒号）、`hidegap`（去掉 12px 灰色垫条），不用改公共组件。
4. **覆盖公共组件的三板斧**：Query 自带 `.ant-row { margin: 0 !important }`，页面覆盖 margin 也要 `!important`（注释说明原因）；栅格字段要靠左打包需同时 `flex: none; width: auto; max-width: none`（antd Col 的 span 类带 max-width）；换按钮顺序用 flex 容器 + CSS `order` 属性，不动 DOM。
5. **样式改了没生效的两种静默失败**：共享全局 scss 每个页面入口都要显式 `import`（漏一个页面就没样式）；作用域类名对不上（页面挂 A 类、规则写在 B 类下）整块规则不生效。验证一律用 `getComputedStyle` 读实际值，不靠截图目测。
6. **还原标准以现有系统为准，原型值让位**：原型左右留边 16px，但现有页面是 24px，用户明确要求对齐现有页面。颜色同理：主色用 `var(--primary-color)` 不写死。
7. **USE_MOCK 开关**在 `common/constant.js`，联调前置 true 看效果，提测前必须改回 false。

## 下次怎么用

- 新项目本地装依赖 401：先查 `.npmrc` 是否 `${VAR}` 形式的 token，找兄弟项目拿现成 token 设同名环境变量，`setx` 后重开终端。
- 做高保真还原：先写脚本从原型取计算样式存 JSON，再对项目侧同位置取值比对，输出差异清单后动手；只改页面级 scss/jsx，公共组件用其暴露的 props 和字符串全局类覆盖。
- 改动验收固定动作：浏览器 `getComputedStyle` 逐项核对 → 控制台无新增报错 → `git status` 第二列确认工作区改动范围（不碰暂存区）。
