# 2026-10-19 magpie 路由组配置与使用指南

## 结论

今天在 magpie（本机网关 127.0.0.1:3425，版本 0.1.1279）里配好了 **2 个路由组**，每个组都是同一个优先级，按你的要求：

| 顺位 | 成员 | 来源 |
| --- | --- | --- |
| 第 1 | `codex/gpt-6.1-sol` | Codex 的 ChatGPT Plus 订阅登录 |
| 第 2 | `zcode/GLM-5.3-Flash` | ZCode 的 GLM Coding Lite 订阅登录 |
| 第 3 | `deepseek/deepseek-flash` | DeepSeek 的 API Key |

| 组名 | Agent 里选它时的写法 | 路由方式 |
| --- | --- | --- |
| 主力 main | `group/main` | order（顺序顺延） |
| 备用 backup | `group/backup` | order（顺序顺延） |

两个组内容完全一样，是按"先配 2 个"的要求有意这样配的。建议的用法：一个给常用的 Agent 用，另一个留作实验或给别的 Agent；用不上哪个就 `magpie group rm backup` 删掉，随时可以再建。

**验证记录（2026-10-19 实测）**：`magpie groups` 列出两组；网关 `/v1/models` 出现 `group/main`、`group/backup`；发了一个真实请求到 `group/main`，由第 1 顺位的 gpt-6.1-sol 应答成功（约 4.3k token）。说明路由已经通了。

## 怎么用（最短路径）

在 Codex、ZCode 等接入 magpie 的 Agent 里，把模型切换为 `group/main`（模型列表里会出现它，界面里也可能显示组名「主力 main」）。之后这个 Agent 的所有请求都走这条路由，不需要再改别的。

路由方式是 **order（顺序）**，含义：**永远先问第 1 顺位**（gpt-6.1-sol），只有它答不了（限流、额度用完、出错）才自动去问下一个（GLM-5.3-Flash），再不行才到 deepseek-flash。哪个模型答的，在 magpie 窗口的「路由」页能看到——就是截图里那三个卡片连线的图：左边是请求方，中间 magpie 网关，右边是实际回答的账号。

两条补充语义，知道即可，不用配置：

- **粘性（stays=auto，默认）**：一个会话只要回答过的账号还能用，就继续用它，这样提示词缓存命中率高（截图右上角那个 97% 命中就是这么来的）。
- 一个账号"暂时不行"会进入短暂休息，恢复后自动回到第 1 顺位，不需要手动干预。

## 界面和命令行的对应关系

「路由」页右上角的 **＋ 新建组** 按钮做的就是命令行这两步的事：起名字 → 从各供应商挑成员 → 排顺序 → 选路由方式。今天是用命令行配的（结果完全一样，写进的是同一份配置文件）。日常查看在界面点就行，改动用命令行更不容易点错。

打开命令行的方式：`D:\DevTools\AI\Tools\Magpie\magpie-windows-amd64.exe` 加子命令（下面命令都假定在 Git Bash / CMD 里直接跑这个完整路径）。

```bash
# 看所有组（自己建的在前，magpie 自动发现的在后）
magpie-windows-amd64.exe groups

# 看一个组的详情
magpie-windows-amd64.exe group main
```

## 日常管理命令

```bash
# 给组加一个成员（排在最后，比如把向量引擎的 gpt-6-sol 加进主力组）
magpie-windows-amd64.exe group set main models+=vectorengine/gpt-6-sol

# 从组里去掉一个成员
magpie-windows-amd64.exe group set main models-=deepseek/deepseek-flash

# 整个重排顺序（全量写，顺序就是优先级）
magpie-windows-amd64.exe group set main models=codex/gpt-6.1-sol,zcode/GLM-5.3-Flash,deepseek/deepseek-flash

# 临时强制所有请求走某一个成员（其余的不再接管，也不故障转移）
magpie-windows-amd64.exe group set main routing=manual
magpie-windows-amd64.exe group pick main zcode/GLM-5.3-Flash
# 恢复自动顺延：
magpie-windows-amd64.exe group set main routing=order

# 删组
magpie-windows-amd64.exe group rm backup
```

改完立刻生效，不用重启 magpie（网关每次都重新读配置）。
