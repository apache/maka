# VSCode 签出弹窗与联调造数

## 一句话结论

VS Code 反复弹「在签出前，请清理仓库工作树」的真因是仓库级 `pull.rebase=true`（并行会话为直线化所设）与本仓纪律性常驻的未提交改动（proxy.ts/.gitignore）冲突——已 unset 恢复合并式拉取并实测；同对话完成行 338 多月区间实施与推送（ffc4538→8f7cd1c），导入链路经用户人工拖拽升级为实测闭环并实证后端模板错位缺陷。

## 可复用经验与案例

### 1. 「直线化配置」与常驻未提交改动不可共存（修订旧笔记结论）

《2026-11-19-数据归集联调收口与git直线配置.md》记录了给本仓设 `pull.rebase=true`（直线化）。本对话证明该配置在本仓**站不住**：proxy.ts/.gitignore 按纪律长期留在工作区未提交，rebase pull 要求工作区干净，于是每次 VS Code 同步必失败。已 `git config --local --unset pull.rebase` 恢复系统级 false（合并式）。**旧笔记「当前仅数据归集仓库已配」的状态已失效**，以本文为准；若要重建直线化，前置条件是先清空常驻未提交改动（或把它们提交掉），二选一。

### 2. push rejected 的安全整合顺序（本对话完整执行成功）

push 报 `fetch first` 时不要盲目 pull：①`git fetch` ②`git log HEAD..origin/<分支> --oneline` 看远端新增什么 ③`git diff HEAD origin/<分支> --name-only` 核对是否触碰**本地未提交的文件**（触碰则先处理冲突风险）④安全则 merge --no-edit ⑤`git push origin HEAD:refs/heads/<分支>` 显式 refspec。本轮远端新增 aa65299/0e56f47（同事的培训结构适配），未触碰本地文件，合并推送 `0e56f47..8f7cd1c` 一次通过。

### 3. IAB 无文件选择器 → HITL 导入实测（把「人工待测」升级为实测闭环）

内置浏览器不支持 file chooser，导入上传原只能登记人工待测。实际做法：装好 `window.__netlog` 只读探针 → 让用户在可见浏览器手动拖拽 xlsx + 点「确认导入」→ 探针捕获 66058 multipart 请求与响应（`{totalRows:1,successRows:1,...,status:"SUCCESS"}`）→ toast 分支渲染 + 自动刷新四链路 + 搜索列表验证入库。注意：**页面不能中途 reload**（探针随页面丢失），用户操作前把现场（弹窗+探针）备好再交出去。副产品：这次实测直接抓到后端解析器把错位模板的示例行当数据导入（B-7 实证，导入 id=714「某某」）。

### 4. xlsx 模板表头取证（发现 B-7 的手段）

对模板文件 `unzip -o -q x.xlsx -d dir` 后用 `python -I` 解析 `xl/sharedStrings.xml`（字符串表）与 `xl/worksheets/sheet1.xml`（按 `r="A1"` 列位还原每行），核对表头是否单行、有无合并单元格；再 `md5sum` 对比用户文件与模板是否同源。本轮借此实证：后端下发的机构养老导入模板把 25 个表头错拆两行、第 2 行表头与示例值混排、无合并单元格——填数必错位。

### 5. 多月区间统计的前端实现要点（行 338，已实测）

契约 65988 已撤 statisticsMonth(s) 改 `periodType+queryStartTime/queryEndTime`；后端响应是区间内每人每月一行、**行内无月份字段**（后端明确不补）。前端做法：RangePicker(picker="month") 换算区间首尾传起止；八卡=前端对区间行求和（`reduce` 后 `toFixed(2)` 防浮点误差）；增值明细 flatMap 跨月合并；residenceStatus 取首行；「删除当月数据」按钮仅区间为单月时可用（多月 disabled+title 提示，66441 单月语义安全）。**缺口**：itest 无「同证件号跨多月」数据，多月求和分支未真实复验，需造数或等后端铺数。

```bash

git fetch origin
git log HEAD..origin/<分支> --oneline                      # 远端新增
git diff HEAD origin/<分支> --name-only | grep -E "本地未提交文件名"  # 触碰检查
git merge origin/<分支> --no-edit
git push origin HEAD:refs/heads/<分支>
```

```bash
# 两版 HetAPI 导出 JSON 对账（python 拍平后按 id 对比，一次出三类清单）
python -I -c "
import json, io
old = json.load(io.open('旧版.json', encoding='utf-8'))
new = json.load(io.open('新版.json', encoding='utf-8'))
def flat(d):
    out = {}
    for p in d['projects']:
        for m in p['modules']:
            for it in m['interfaces']: out[it['id']] = it
    return out
O, N = flat(old), flat(new)
print('新增:', sorted(set(N)-set(O))); print('删除:', sorted(set(O)-set(N)))
for k in sorted(set(O)&set(N)):
    if json.dumps(O[k], sort_keys=True) != json.dumps(N[k], sort_keys=True): print('变更:', k, N[k]['name'])
"
# 成功信号：三清单齐出；再对变更项单独 diff request_query/request_body 定位字段级差异
```
