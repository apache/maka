## 常用命令

- **符号考古判定功能是否曾落库**（本次实锤「TOP8 联动从未提交」的关键）：
  `git log --oneline -S "fetchServiceTop8" -- <目录或文件路径>`；需跨所有分支补查加 `--all`。
  前提：目标仓根目录。成功信号：列出引入/改动/删除该符号的提交；**无输出 = 该符号从未进任何提交**。配合 `git log -1 --format="%H %ad %s" --date=short <sha>` 取提交时间线。
