# magpie 接线台本地预览：沙盒隔离 + 脱敏快照

**一句话总结**：想在本地看 magpie 新接线台 UI 的效果，不用改生产代码——用现成 dev exe 加环境变量隔离启动，再用只读白名单把本机配置投影成脱敏快照，套进设计原型里浏览器直接看。

## 背景

magpie 仓库（`magpie-ui`）里有个未完成的「接线台」新布局，代码里只有布局外壳（shell.js），卡片和连线（bridge.js/inspector.js）还没写，打开是一片空白。想用自己本机真实的 Agent/模型来源数据看看设计稿的样式效果，但又不想动正在运行的 magpie 和真实配置。

## 关键结论

1. **看到空白接线台不是 bug**。当前代码只实现了 P0 外壳（页头切换、两岸标题、占位提示），`bridge.js`/`inspector.js` 还不存在。要看有数据的效果，复用设计稿原型（`docs/magpie-ui-design-v0.2/docs/mockups/switchboard.html`）比在生产代码里补实现便宜得多。

2. **沙盒里接线台会被自动关掉**。`magpie web` 检测不到 Agent 时自动进网关模式，接线台布局被禁用。沙盒的 `settings.json` 里写 `"gatewayMode": "off"` 即可，顺带加 `"noAutoUpdate": true` 防止沙盒程序自更新。

3. **Windows 隔离只改 HOME 没用**。Go 程序在 Windows 从 `USERPROFILE` 读主目录，WebKit/AppData 各有各的读法，八个变量要一起改。更省事的招：把 exe 复制进沙盒再启动，程序自己进 portable 模式，配置全落沙盒，不碰真实 `~/.config/magpie`。

4. **读真实配置要走只读白名单**。`providers.json`、`usage.jsonl`、`applied.json`、`quotas.json` 可以只读投影（名称、模型、请求统计、额度百分比）；`logins.json`、`stash.json` 含凭证绝不读。网关端口只有 `GET /api/hello` 是纯只读探活，其他 API（如 `/api/providers`、`/v1/models`）会触发后台抓取甚至写盘，别拿来当探针。

5. **异步加载的页面，断言前必须等元素可见**。预览页 fetch 快照后才渲染卡片，测试直接 `innerText` 断言会偶发失败（只读到"正在加载"提示）。先 `getByRole(...).waitFor({ state: "visible" })` 再断言，单跑并行跑都稳。
