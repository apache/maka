## 常用命令

### 1. git 归属举证（判断改动是我引入还是历史遗留）

```bash
git show HEAD:<file>          # 看接手前版本是否含目标代码
git diff HEAD -- <file>       # 看本轮工作区是否引入/删除了它
```

成功信号：HEAD 版本含目标行 + diff 有对应 `-` 行 = 本轮引入；HEAD 就没有 = 历史遗留。只读操作，无副作用。

### 2. 无浏览器接口验证（MCP 浏览器被占用时的替代）

```bash
curl -s -m 10 "<接口URL>" -H "authorization: <页面登录态cookie>" -H "sysid: <系统号>" | node -e "
let s='';process.stdin.on('data',d=>s+=d).on('end',()=>{
  const res=JSON.parse(s);
  // 对返回数据跑与页面 config 相同的映射，断言输出
  console.log(JSON.stringify(res.data, null, 1));
});"
```

前提：token/cookie 从页面 Network 请求头复制（用占位符，不落盘）；适用 GET 只读接口；成功信号=code:0 且映射输出与预期一致。本会话用它验证了 typeBars 的 `typeName:null` 分组（后端把无主题场次聚成 null 组），替代被占用的受控浏览器。

### 3. 批量语法解析（本机 eslint 因共享配置缺 typescript 跑不了时的替代）

```bash
node -e "
const parser=require('@babel/parser');const fs=require('fs');
for(const f of ['<file1>','<file2>']){
  parser.parse(fs.readFileSync(f,'utf8'),{sourceType:'module',plugins:['jsx']});
  console.log('OK',f);}"
```

注意：只验语法，查不出依赖数组漏改这类语义问题（见 Skill 增量 1）；Git Bash 需先 `eval "$(fnm env)"`，失效时直接用 node 绝对路径。
