## 可复用经验与案例

**字段级契约正本在项目文档，不在对话**：`E:\cc\web\senior\03-接口定义\v4.44.4-集团-数据归集\机构养老-接口定义补充.md`（本轮产出，六节：版本与证据/接口总览/逐接口定义/适配差异/待确认 9 项/旧结论失效表 10 条）。居家/咨询/培训模块可复用该结构；"失效表"是 delivery-workflow §4「历史记录保留，标已被何条确认替代」的落地产物。

**契约快照演进的收口动作**（流程已 covered，留落点清单）：11-10 清单 → 11-10 全量核对版推翻三结论（单月/联动/券字段）→ 11-11 导出闭合三项契约。旧结论标失效同步写到三处：项目记忆状态文件、代码注释（ElderMonthDetailModal 多月阻塞注释直接引用推翻关系）、接口定义补充文档失效表——三处指向一致，避免下轮会话把旧假设当事实。

**同页三口径实例**（§2「列表、卡片、图表不可因同页就假设同口径」）：同一月机构养老 65987 跨月聚合=4 人、65988 月内聚合=4 行、原始记录=7 条；删除接口删的是原始条数，预览必须用逐条接口（68793）且待删数取其 `total`，不得用聚合列表数。

**periodType 双语义**（项目契约特例，已入正本文档）：A 类趋势接口=聚合分桶（`YEAR`=全部历史年份各一行，不是"本年"）；B 类汇总卡=统计区间范围（`YEAR`=本年累计，枚举优先于起止）。同名同值不同窗口，卡片与趋势按各自语义组装参数。

**禁用态落地细节**：scss 与表格结构保留（恢复时零样式改动）；挂载即查默认月；预览与主列表用独立 hook 实例 + 竞态序号防护互不串扰；删除成功提示按实际返回条数（Number 可缺失则不拼接数字），预览数与删除数不写恒等（并发变化属正常，提示以实际返回为准）。

## 常用命令

从 HetAPI JSON 导出按接口 ID 提取字段树（本轮执行两次：65987 全结构核对、66441/68793/65987/65988 对比）。Windows 本机 fnm shim 损坏，node 需全路径直调（见记忆 microweb-node-fnm-shim-broken）：

```bash
NODE=/d/DevTools/Languages/Frontend/Fnm/node-versions/v22.23.3/installation/node.exe
"$NODE" -e "
const data = JSON.parse(require('fs').readFileSync('<导出>.json','utf8'));
const ifaces = data.projects[0].modules[0].interfaces;
const walk = (nodes, depth) => (nodes||[]).forEach(n => { console.log('  '.repeat(depth) + n.name + ' | ' + n.data_type + ' | ' + (n.necessary?'必填':'可选') + ' | ' + (n.remark||'').slice(0,80)); walk(n.child, depth+1); });
for (const id of [<接口ID>]) {
  const t = ifaces.find(i => i.id === id);
  console.log('=== ' + id + ' ' + t.name + ' | ' + t.request_method + ' | update ' + t.update_time + ' ===');
  walk(t.request_method === 'GET' ? t.request_query : (t.request_body ? t.request_body.data : []), 0);
  const dataNode = (t.response.data||[]).find(n => n.name === 'data');
  if (dataNode) { console.log('data: ' + dataNode.data_type + ' | ' + (dataNode.remark||'')); walk(dataNode.child, 1); }
}"
```

前提：导出为 HetAPI JSON（`projects[].modules[].interfaces[]`，接口含 `id/name/request_method/request_query/request_body/response`）。成功信号：打印每个接口的方法/更新时间/query 或 body 字段树与 `data` 层级（类型/必填/remark 截断 80 字）。只读本地文件，无副作用。`modules[].interfaces[]` 层级按导出实际调整，多模块导出时先按模块名过滤。
