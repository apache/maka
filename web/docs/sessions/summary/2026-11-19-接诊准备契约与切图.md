## 常用命令

### 判断 PNG 是不是 APNG

- 场景：附件或切图看起来是 png，要确认会不会被动图处理打掉。
- 前提：本机 Node，文件在本地。不要把文件内容打到终端。
- 命令：

```powershell
node --input-type=commonjs -e "const fs=require('fs'); const b=fs.readFileSync(process.argv[1]); const sig=b.slice(0,8).toString('hex'); const kind = sig.startsWith('89504e47') && b.includes(Buffer.from('acTL')) ? 'apng' : (sig.startsWith('89504e47') ? 'png' : 'other'); console.log(JSON.stringify({ bytes: b.length, sig, kind }));" "<本地图片路径>"
```

- 成功信号：本会话输出 `{"bytes":37201,"sig":"89504e470d0a1a0a","kind":"apng"}`。
- 副作用：只读文件。

同一文件再读 IHDR，宽高在偏移 16 和 20 的大端 uint32。本会话结果是 356×64。

Windows PowerShell 5 不接受 `&&`。多条命令要分开跑。这是失败信号，不是推荐写法。
