钉钉存档工具链完成全量收口（57 单聊 + 19 群聊 + 一键 bat），本对话新增两条环境铁律候选（bat 必须 CRLF、node_repl 中文路径乱码绕行）和一条已入记忆的工作流更新；战报统计（6 条喜报 1.56 亿）为一次性项目事实，不归档。

## 2. Skill 增量建议（待确认，未直接修改）

### 候选 1：bat 文件必须 CRLF

- **位置**：`gua-dev-tools` SKILL.md →「通用铁律」（与 wsl.exe UTF-16、core.quotepath 两条同类：环境陷阱导致静默错误行为）。
- **缺口**：现有规则只覆盖「Edit/Write 把仓库代码文件转 LF」（见记忆 local-4002-static-bundle-pitfalls），未覆盖 bat 这一特殊目标——cmd.exe 只认 CRLF，LF 行尾的 bat 每行命令名尾部带 `\n`，Win10 全屏报乱码+「xxx 不是内部或外部命令」，且 `chcp 65001` 救不了。
- **建议追加文本**：`ZCode Write/Edit 落盘一律 LF；.bat 交给 cmd 执行必须 CRLF，写完用 python 二次转 CRLF 并回读验证（raw.count(b'\r\n')），否则逐行报"不是内部或外部命令"式乱码。`
- **证据**：11-12 会话实测——更新存档.bat 用 Write 写 LF 后用户执行全屏乱码报错（截图），python 转 CRLF（31 行）后恢复；本会话「执行」后回读 `raw.count(b'\r\n')`=31 验证。
- **边界**：只适用于 cmd 批处理；PowerShell ps1、sh 脚本不受此限；仓库代码 CRLF 问题已有旧规则，不重复。
- **检验场景**：写一个两行 bat（echo ok + pause），LF 版在 cmd 下必报错，CRLF 版正常——能区分对错。

### 候选 2：node_repl 读中文路径文件必乱码，用 python 中转

- **位置**：同「通用铁律」。
- **缺口**：现有规则无 node_repl/文件读取编码类条目。
- **建议追加文本**：`node_repl 的 fs 读含中文的 Windows 路径时路径被 GBK 化报 ENOENT（错误信息本身也是乱码，可作识别特征）；读这类文件改用 python -I -c 读字节转 base64 stdout 中转（execFileSync maxBuffer 调大），不在 node 侧拼中文路径。`
- **证据**：11-12 会话读群聊图片 20 连 ENOENT、错误信息 `06ҳ濪` 乱码；改 python 中转后 56 张全部读出并完成视觉识别。
- **边界**：仅 node_repl 独立 Worker 环境；Bash 通道正常时优先 Bash；纯 ASCII 路径不受影响。
- **检验场景**：node_repl 里 `fs.readFileSync` 一个中文目录下文件 → ENOENT+乱码；同一文件走 python 中转 → 成功。

## 4. 常用命令

**bat 转 CRLF（写完 bat 后必跑）**
```bash
python -c "p=r'<路径>.bat'; s=open(p,encoding='utf-8',newline='').read(); s=s.replace('\r\n','\n').replace('\n','\r\n'); open(p,'wb').write(s.encode('utf-8'))"
```
成功信号：`open(p,'rb').read().count(b'\r\n')` 等于行数；副作用：无（内容不变只换行尾）。

**node_repl 绕行读中文路径文件**
```js
const { execFileSync } = await import("node:child_process");
const b64 = execFileSync("python", ["-I", "-c",
  `import base64;print(base64.b64encode(open(r'<中文路径>','rb').read()).decode())`],
  { encoding: "utf8", maxBuffer: 100*1024*1024 });
Buffer.from(b64, "base64");
```
前提：`-I` 隔离模式；成功信号：base64 可解码；注意 maxBuffer 默认 1MB 会炸大文件。

**存档增量是否落库检查**
```bash
python -I -c "import sqlite3,datetime;db=sqlite3.connect(r'<dingtalk.db>');print([ (t,db.execute(f'SELECT COUNT(*),MAX(createdAt) FROM {t} WHERE cid=<cid>').fetchone()) for t in [f'tbmsg_{i:03d}' for i in range(128)] if db.execute(f'SELECT 1 FROM {t} WHERE cid=<cid> LIMIT 1').fetchone()])"
```
MAX(createdAt) 换算时间早于客户端最新消息 → WAL 未落库，重跑解密无用。
