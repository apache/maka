后端修复声明必须逐条运行态直调拿错误码实证（截图≠修复）；测试报告里同一条目不得并存互斥状态、未覆盖不得汇总成通过；跨会话接手时报告/Skill 里的历史"待办"先以当前源码核实再执行——本轮三处旧待办被并行会话修掉，照做就是重复修改。

## 可复用经验与案例

**浏览器通道分层（回答"测试跑 MCP/IAB/ACP/CDP 哪个"）**：三者不同层——chrome-devtools MCP 是 MCP server（底层 CDP，对使用者透明）；ZCode IAB 是宿主内置浏览器（协议被封装，不可选也不需要选）；ACP 是编辑器↔Agent 通信协议，与浏览器无关；"在 IAB 里跑 ACP 还是 CDP"是伪问题。AI 一次性验证用 MCP 或 IAB（产出截图/文本记录，不可重复）；可回归的自动化测试用 Playwright Test（断言/重试/trace/CI）。两通道已实测等价：MCP profile 锁失效时 IAB+页面内 fetch/XHR 拦截器可完整替代 Network 面板核对。

**F-6 三色实现案例（用户两次纠正的完整链）**：初版按"对齐签到页统一 blue"实现 → 用户出示原型 `actTag()` 证据纠正为三色（PENDING→processing/ONGOING→success/FINISHED→default）→ 再强调"不要自创配色、不扩展公共工具、先固定改前失败再最小修改"。落地=文件内局部常量 `STATUS_TAG_COLOR` + render 三分支（空值 renderEmpty、未知 `|| "default"`、文案恒取服务端 statusName），diff +14/-2 CRLF 保持。教训：UI 配色的权威源是原型实现，不是兄弟页面的现有写法；改前失败断言（运行页 hasTag=false）必须先固定。

**像素采样判圆角不可靠**：canvas getImageData 逐列统计柱顶/柱身宽度比来判"是否有圆角"，抗锯齿像素让结果在 true/false 间随机——不可作结论。改用 `document.body.style.zoom='2.5'` 放大后截图目视对比，可靠且便宜。

**报告多轮追加的行内留痕模式**：同一报告多轮测试时，历史行不删——旧结论划线或加日期标注补注（如"~~无期限内数据~~ 11-03 造数补测通过"），新结论写当前状态；汇总数字每轮重算。本轮 121 用例从 86→96→97 的演进全靠此模式可追溯。

## 常用命令

**React fiber 取 echarts 实例调 API（合成 mousemove 触发不了 zrender 时的唯一路径）**

- 场景：验证 echarts option（圆角/series 数据）或程序化 showTip。
- 前提：页面已渲染 `.echarts-for-react` 容器；在页面 evaluate 内执行。
- 命令（页面内 JS）：
```js
const container = document.querySelectorAll('.echarts-for-react')[0];
const reactKeys = Object.keys(container).filter(k => k.startsWith('__react'));
let fiber = container[reactKeys[0]], depth = 0;
while (fiber && depth < 40) {
  if (fiber.stateNode && typeof fiber.stateNode.getEchartsInstance === 'function') break;
  fiber = fiber.return; depth++;
}
const chart = fiber.stateNode.getEchartsInstance();
const opt = chart.getOption();            // 断言 series[].itemStyle.barBorderRadius
chart.dispatchAction({ type: 'showTip', seriesIndex: 0, dataIndex: 4 }); // 程序化 tooltip
```
- 成功信号：getOption 返回真实 option；showTip 后页面出现 tooltip div。副作用：无（只读+临时 tooltip）。

**antd Select 合成事件打不开时的键盘路径**

- 场景：IAB/自动化里 `dispatchEvent(mousedown)`、元素 `.click()` 都打不开 antd Select 下拉。
- 命令（页面内 JS）：`combo.querySelector('.ant-select-selector').focus(); selectorEl.dispatchEvent(new KeyboardEvent('keydown', { key: 'Enter', code: 'Enter', keyCode: 13, which: 13, bubbles: true }));`
- 成功信号：`.ant-select-dropdown:not(.ant-select-dropdown-hidden)` 出现且含选项。radio 类组件此路不通（本轮标未覆盖，须真实鼠标）。

**暂存区单向核对（只暂存目标文件）**

- 场景：工作区有多个改动（含用户预存），只把本次修改放入暂存区。
- 命令：`git add <目标文件> && git status --porcelain && git diff --cached --stat`
- 成功信号：porcelain 中目标文件为 `M `（第一列 M），预存改动保持 ` M`（第二列）；`--cached` 只含目标文件。
