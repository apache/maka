## 可复用经验与案例

- **版本事实（本轮实际安装并验证）**：Vite 8.3.1 / TypeScript 6.0.3 / react-router 8.4.0 / zod 4.6.5 / zustand 5.0.15 / Tailwind 4.3.3 / shadcn v4（radix-nova 预设）。两个版本坑：TS 6 起 `baseUrl` 弃用（报 TS5101，要求 `ignoreDeprecations: "6.0"`），`paths` 改为相对 tsconfig 解析，直接删 `baseUrl` 即可；react-router 8 仍完整导出经典 API（BrowserRouter/Routes/Route/useParams 等，实测核验）。
- **md 作唯一真相源的 Vite 管线要点**：`import.meta.glob('**/*.md', { query: '?raw', import: 'default' })` 会让每个 md 自动成为懒加载 chunk（按需进分区页）；跨 app 根目录读仓库文件需 `server.fs.allow: [repoRoot]`。完整设计已沉淀在 `app/README.md`，此处只记两个非显而易见点。
- **BYOK 多模型前端的三个边界决策**（已实现于 `app/src/features/interviewer/`，可作面试讲材）：Key 只存浏览器 localStorage 不经任何服务器；CORS 不通的厂商走本地白名单中继（`app/proxy.mjs`，`x-llm-target` 头指真实地址，中继不落盘 Key，白名单限主流大模型域名防滥用）；结构化评分用 Zod 校验 + 平衡花括号抽取，容忍模型把 JSON 包进代码块/闲话（实测写法在 `prompts.ts` 的 `parseScoreReply`）。
- **测试失败先定性再动手**：本轮 7 个失败中 5 个是测试自身笔误（fixture 多了分隔符、断言数错、split 拆行手误），只有 `levelOf` 分档函数是真 bug（`LEVEL_BUCKETS` 循环从 i=1 起导致 0 次判成有颜色）。教训：跑红先区分"测试错/代码错"，用显式输入的调试测试快速定性，再改实现。
- **ZCode IAB 浏览器怪癖（待验证，随宿主版本变化）**：渲染进程死后表现为截图全黑、`tabs.list()` 变空——关标签重开即恢复，不要反复 reload；元素唯一可见但命中测试超时是环境层问题，用 `locator.evaluate(el => el.click())` 原生点击可绕过验证交互（本轮添加服务商预设即此法验证通过）。
- **宿主 Bash 派生失败的诊断信号**：`spawn D:\DevTools\Languages\DevOpts\Git\bin\bash.exe ENOENT` 但 Read 工具能确认该文件存在 = 宿主进程派生链路故障（疑杀软锁定或资源耗尽），自愈型；此时连 `echo` 都失败，不要误判为 Git 被删，也不要重试相同命令刷屏，改用不依赖 shell 的工具（Read/Write）继续收尾。

## 常用命令

- **shadcn/ui CLI v4 初始化（交互式新流程）**
  - 场景：Vite + Tailwind 4 项目接入 shadcn v4。
  - 命令：`pnpm dlx shadcn@latest init -y -b radix -p nova`
  - 前提：`src/index.css` 已含 `@import "tailwindcss";`，否则报 `No Tailwind CSS configuration found`；`-b` 现在是组件基座（radix/base/aria，传 zinc 会报 Invalid enum value），主题预设是 `-p nova|vega|…`（传 `radix-nova` 会报 Invalid preset）。
  - 成功信号：生成 `components.json`（`"style": "radix-nova"`）+ `src/lib/utils.ts`，自动安装 `cn`、`radix-ui` 依赖（生成组件从这两个包导入）。
- **shadcn 组件批量添加**
  - 命令：`pnpm dlx shadcn@latest add button card badge progress separator sonner scroll-area textarea sheet alert-dialog input -y`
  - 成功信号：`src/components/ui/` 出现对应 tsx；未用组件建议手动删除（本次删除了未引用的 tabs.tsx）。
- **跨大版本升级前核库 API 面（以 react-router 8 为例）**
  - 命令（参数化）：`node --input-type=module -e "import * as rr from 'file:///<项目>/node_modules/react-router/dist/development/index.js'; console.log(['BrowserRouter','Routes','Route'].map(k=>k+':'+typeof rr[k]).join('\n'))"`
  - 前提：入口文件按实际包调整——react-router 的 dev 入口是 `dist/development/index.js`（`.mjs` 路径会 ERR_MODULE_NOT_FOUND）。
  - 成功信号：逐个导出打印 `function/object/undefined`，升级前快速确认破坏面。
- **dev 模块图探针（页面空白、终端无错时）**
  - 见上文 Skill 增量建议内的注入脚本，属浏览器操作不是 shell 命令；成功信号是 console 打出真实模块错误或 `OK`。
