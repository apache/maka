## 常用命令

以下两条在 Windows Git Bash 实际执行并返回证据。`<repo>` 是本地仓库路径，两条都只读。

```bash
git -C "<repo>" reflog show <branch>
git -C "<repo>" branch -a --contains <fix-sha>
```

第一条用于核实本地分支创建来源，成功信号是 `branch: Created from origin/<base>`，前提是创建记录仍在本地。第二条用于确认已知修复提交是否包含于某条本地或远程跟踪分支，目标 ref 出现在列表即证明可达。本次输出包含 `origin/develop`。远程跟踪引用可能滞后，且 squash 或改写提交要另查等效补丁。

## 待验证与不适用边界

- **扫码未闭环。** 可见对话中没有小程序 `68279/68117` 的真实响应。后续 PC 查询也出现过服务不可用与登录失效，缺失 `data` 不能判成空名单。先前“就是账号归属”“码肯定有效”属于超出证据的判断。账号归属只保留为假设。
- **部署损坏位置未证实。** 日志证明部署端读到的 ZIP 无法完整解压，缺少源包测试、两端摘要与重跑结果，无法区分源包、存储、下载或落盘问题。构建恢复与测试环境发布成功分开记。
