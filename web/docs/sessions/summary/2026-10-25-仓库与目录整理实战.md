# 仓库与目录整理实战：Figma 抓取、安全删仓、孤儿重置

**一句话总结**：一天内整理完个人资产仓——Figma REST 增量抓图、MD5 级目录对比、删仓前三查、大仓孤儿重置推送，全程可复用的命令与判断口径。

## 背景

个人资产散在多个目录/仓库（Figma 归档、知识库、AI 会话、独立小项目），要合并到统一大仓并删除冗余：既不能丢内容，也不能丢 git 历史，还要把 8G 的 .git 压成单提交。

## 核心命令

```bash
# —— Figma REST 抓取（令牌放 .env，不落命令行历史）——
node --env-file=~/.path/to/.env fetch.mjs        # Node 原生 .env 注入，免 dotenv 依赖
curl -s -H "X-Figma-Token: <FIGMA_TOKEN>" \
  "https://api.figma.com/v1/files/<fileKey>/nodes?ids=<页面id>&depth=1"   # 拉页面子节点清单
curl -s -H "X-Figma-Token: <FIGMA_TOKEN>" \
  "https://api.figma.com/v1/images/<fileKey>?ids=<id1>,<id2>&scale=2&format=png"  # 批量渲染 PNG

# —— 目录对比三步法（合并/删除前必做）——
(cd A && find . -type f -not -path '*/node_modules/*' | sort > /tmp/a.txt)  # ① 路径清单
diff -rq -x .git -x node_modules -x .next A B    # ② 路径级差异（Only in / differ）
# ③ 内容级：node 对两边文件逐个 md5 建 Map 比对（脚本模板见下），改名/移位自动命中

# —— 删仓前三查（缺一不可）——
git -C <仓> status --short                        # ① 有无未提交改动
git -C <仓> rev-parse HEAD && git -C <父仓> cat-file -t <SHA>  # ② 历史是否已在父仓
git -C <仓> bundle create x.bundle --all && git -C <仓> bundle verify x.bundle  # ③ 独立历史先归档

# —— 大仓孤儿重置（⚠️ 两步都是不可逆）——
rm -rf .git && git init -b main && git add -A && git commit -m "重建：全量收编"  # ⚠️ 丢弃全部提交历史，仅确认无需旧史后使用
git push -f origin main                           # ⚠️ 覆盖远程历史，协作者拉取会冲突
```

## 关键结论

1. **Figma images 端点单图上限 2²⁵ 像素，超限静默等比缩小**（无任何报错）；GROUP 带阴影时导出是效果外扩盒。唯一可靠口径：落盘后读 PNG 实际像素比对，别信 API 返回。
2. **路径级 diff 不够，必须 MD5 内容级**：同路径不同内容（新旧版）、改名移位（路径独有但内容已在）只有内容指纹能定性。本次 680 文件合并靠它做到零缺失。
3. **删仓判据是"HEAD 在不在父仓历史"**：在（git cat-file 能查到）＝内容与历史都有副本，可删；不在（如本地独立历史无远程仓）＝必须先 bundle 归档再删，否则历史永久丢失。
4. **嵌套仓在父仓里只是 gitlink 指针**（Finder 看不到任何变化）：显示"M"= 子仓 HEAD 前进了、父仓记的指针过期，不是内容改动；不想刷屏可在 .gitignore 忽略该路径。
5. **zsh 的 `UID` 是只读内建变量**，脚本里自定义变量叫 UID 会报 "failed to change user ID"，换名即好；TS 模块级初始化（如 `export const db = openDb()`）要放文件尾，否则 TDZ 报错。
6. 批量抓取 Figma 会撞 429 限流：分批 + 批间 sleep ≥1s + 429 退避重试；S3 下载偶发 ECONNRESET 也要重试兜底。

## 下次怎么用

- **合并两个"看起来差不多"的目录**：跑三步法 → 内容已在的跳过 → 真缺失的原路径迁入 → 同名不同内容的逐个 diff 定新旧 → 复跑 MD5 对比直到零缺失 → 才删源。
- **删除任何仓库/大目录前**：三查清单走一遍（未提交改动 / HEAD 归属 / bundle），三绿再删。
- **大仓瘦身**：照本次 `finish-cleanup.sh` 模式（删副本 → 嵌套 .git 迁出或忽略 → rm .git 重建 → 单提交 → 强推），步骤写进脚本一次跑完。
- **再抓 Figma 归档**：manifest 记录 fetchedAt，页面 lastModified 更新才增量重抓；图层名以 REST 实际返回为准，防改名漂移。
