# 接口脱敏与同文件暂存

## 一句话结论

对展示字段，先核对产品口径与真实响应，再决定是否删除前端格式化。对同文件混合改动，按差异块暂存，并分别核对暂存区与工作区。

## Skill 增量建议

**gua-dev-tools → `modules/quality/references/format.md`「高价值反模式」**。现有第 34、55 行要求混合改动时停下并由人工确定范围，缺少范围确定后的操作与验证。建议接在原规则后：「用户明确授权部分暂存时，逐块核对目标补丁，仅将获准的差异写入索引。随后检查 `git diff --cached` 与 `git diff`，分别确认目标已暂存、无关改动仍留在工作区。」

证据见会话末尾「过滤补丁并部分暂存 applicantModal」及紧邻的核对结果。`git apply --cached` 成功后，同一文件显示 `MM`，cached 侧为移除 `maskPhone` 的两个差异块，工作区侧仍有导出按钮样式改动。适用于用户已确定暂存范围，且目标改动可明确拆分的场景。检验场景是同一文件同时含电话渲染修复和未授权纳入的按钮样式，索引只出现前者。历史案例满足该判据，本轮未重跑，未修改 Skill。

## 可复用经验与案例

活动报名联调中，68090 首次列表请求（reqid 47）的可见响应已包含 `contact: "****1233"`。此条样本证明该环境的接口返回了掩码值。原有 `maskPhone` 对带 `*` 的字符串本就原样返回，前后页面长相相同，截图无法单独证明格式化调用已经移除。产品随后明确「联系电话直接显示后端返回的值」，5 文件 diff 显示删除工具函数和 4 处调用，统一沿用 `renderEmpty`，空值显示 `--`。两条 `rg` 检查均为零命中，针对性 ESLint 对这 5 个文件退出 0。项目 ESLint 配置链因缺 `typescript` 无法运行，改后浏览器验收未见执行记录。

下次遇到相似场景，用产品确认确定展示规则，用具体接口样本确认服务端输出，用消费点 diff 确认前端只保留空值兜底。仅看到旧页面的 `dataIndex` 或有限的 Git 历史搜索结果，无法推出各接口都已脱敏。现有 API 模块已覆盖「接口样本 → 消费点」核对，`quality/references/test.md` 已覆盖独立 ESLint 诊断，现有 senior 模块也已收录 MCP profile 冲突处置，这些不重复提案。

## 常用命令

Git Bash，仓库根目录。把 `git diff -- "$target_file"` 中逐块确认后的 unified diff 保存为 `$patch_file`，保留文件头和目标差异块后执行：

```bash
git apply --cached "$patch_file"
git diff --cached -- "$target_file"
git diff -- "$target_file"
```

会话中这三个 Git 操作实际执行成功。应用补丁会修改索引，工作区文件保留原内容。成功信号是暂存 diff 仅含获准差异，工作区 diff 仍含无关改动。历史操作用差异块顺序截取补丁，该顺序只对当时的文件有效。ESLint 降级命令已归档在《maxLength 类缺陷复现手法与 eslint 直跑命令》，不重复收录。
