# 顾问首页样式溯源整理

**一句话总结**：样式还原要查真实布局和原始图标，用设计注释、资源索引与针对性回归把修复留得住、查得到。

## 背景

顾问首页、底部菜单栏和日常成交复盘经过多轮还原，仍有状态标签过高、专场选中图标缺失、动图染色异常等问题。这轮同时整理了 Figma 资源和模块公共样式，避免以后重复排查。

## 核心命令

在仓库根目录的 Git Bash 中执行；尖括号内容替换成实际文件，多个文件用空格分隔。以下命令在本轮验证记录中有成功结果，属于当次检查，不代表后续改动自动通过。

```bash
git diff --check # 检查未暂存补丁的空白错误
npx prettier --check <改动文件> # 检查触达文件的格式，不做全仓格式化
DISABLE_V8_COMPILE_CACHE=1 npx stylelint <改动SCSS> --customSyntax postcss-scss # 按 SCSS 语法检查样式；此环境变量为当时的运行配置
node scripts/lint-px.mjs src/pages/home/h5 src/pages/homeTabs src/pages/dealReview # 检查三个模块的尺寸约定
node src/pages/home/h5/tests/sticky-layout.test.cjs # 回归首页吸顶布局约束
node src/pages/dealReview/tests/dealReviewStyles.test.cjs # 回归成交复盘样式约束
git apply --check -R "<补丁文件>" # 只验证补丁能否反向应用，不实际回滚
```

两个测试脚本依赖本机保留的 `tests/`；本项目约定 `tests/`、`.debug/` 均不进入暂存或提交。静态检查和结构测试通过，不等于真机视觉验收通过。

## 关键结论

1. **标签变高先查行盒，不要只改字号。** 专场“进行中”被父级行盒撑高；标签改为 flex 居中、状态行顶部对齐后解决。本项目使用 750 设计单位，375 视口下对应一半 CSS 尺寸，检查 computed style 时要统一单位，避免重复缩放。
2. **图标要补对资源和状态映射。** 专场选中图标缺失源于 `selectedIconSrc` 为空；补入 Figma 原始 SVG 的 COS 地址并保留原始留白。复盘完成图标也使用原始资源，不再用 CSS 近似；完成态按用户确认只显示“已复盘”，去掉前面的勾。两份资源当次均核验 HTTP 200、SVG 类型及本地与公网字节一致。
3. **Lottie 染色只改可见绘制路径。** 全量修改 `path` 的 fill/stroke 会影响 defs、蒙版等，形成整片蓝色。移除全局染色调用，分别限定已有 fill/stroke 且非 `none` 的可见路径。
4. **公共样式抽取要核对编译结果。** 重复值和结构收进各模块自己的 `styles`，从统一出口引用，保留组件上方的设计帧注释。`@include` 按 Stylelint 要求前置后，当次 33 份 CSS 的选择器、属性和值集合一致，其中 5 份声明顺序变化；字节不同不直接等于视觉回归，仍需检查覆盖顺序与页面表现。
5. **资源可溯源，清理才有依据。** `.debug` 统一使用版本主题目录，按“序号＋中文”分为设计源、图片资产、工具脚本、验证记录和历史归档；索引保留“节点 → 本地文件 → COS URL → 代码位置 → 验证记录”。样式上方注明节点与实测值，值改时同步注释；临时资产链接不作长期依赖。目录清理先比 SHA256，只删除完全重复文件，唯一资料归档并保留备份；本轮删除了 11 个重复文件，独立副本恢复校验通过。

## 下次怎么用

遇到“改了几次仍不像设计稿”时，先统一设计单位与视口尺寸，再查父级行高、对齐、图标状态映射和 SVG 留白，不继续凭截图猜值。保存原始资源并登记索引后做最小修改，依次跑格式、样式和模块测试，最后在页面检查弹窗、完成态、专场标题行及底栏。提交按首页、底栏、成交复盘分别组织，人工确认暂存范围。
