## 常用命令

控制台中文乱码时，不要把 xlsx 打到 stdout。下面这条在本机 PowerShell 跑通，结果写入 UTF-8 文件后再读。前提：已安装 `openpyxl`。成功信号：文件里能看到工作表名和「spec2」等中文单元格。读完删掉临时文件。

```powershell
python -c "import openpyxl; wb=openpyxl.load_workbook(r'<清单.xlsx>', data_only=True); out=[]
for ws in wb.worksheets:
    out.append('SHEET '+ws.title)
    for row in ws.iter_rows(values_only=True):
        cells=[('' if c is None else str(c)).strip() for c in row]
        if any(cells): out.append(' | '.join(cells))
open(r'<输出.txt>','w',encoding='utf-8').write(chr(10).join(out))"
```

`python .specify/scripts/python/check_prerequisites.py --json --paths-only` 本会话退出码 0，能拿到 `FEATURE_SPEC`。同一命令已记在 `2026-10-26-PRD转需求Spec三轮澄清.md`，不重复展开。
