# 暂存区保留与样式报错处理

**一句话总结**：拉代码时用 `stash --index` 恢复暂存边界；两行省略的前缀告警局部豁免，旧 TypeScript 缺失的 DOM 类型局部补充。

## 背景

本地同时有已暂存和未暂存的改动，需要同步远程并保留两者边界。随后遇到两行省略样式被 Stylelint 拦截，以及 `document.fonts` 缺少 TypeScript 类型的问题。

## 核心命令

以下命令在仓库根目录执行，占位符替换成实际分支或文件。

```bash
git status --short # 区分暂存区与工作区；左列是暂存状态，右列是工作区状态
git diff --cached --stat # 查看本次准备提交的文件与改动量
git diff --stat # 查看尚未暂存的改动
git fetch origin # 更新远程分支信息，不修改工作区
git rev-list --left-right --count HEAD...origin/<分支> # 查看本地独有、远程独有的提交数量

git stash push -m "pre-pull: staged + worktree" # 临时收起已跟踪文件的本地改动，包含暂存区内容
git merge --ff-only origin/<分支> # 仅允许快进同步；分支已分叉则停止
git stash pop --index # 恢复改动并尽量还原原来的暂存状态

git diff --cached -- <文件路径> # 查看暂存版本；写提交文案时以它为准
git diff -- <文件路径> # 查看工作区相对暂存版本的差异
npx stylelint "<样式文件路径>" # 检查指定样式文件，不加 --fix
npx prettier --check "<文件路径>" # 只检查格式，不写入文件
```

## 关键结论

1. **同步远程不一定产生冲突。** 本次远程和本地修改了同一个 SCSS 文件的不同区域，快进后恢复 stash 自动合并成功。`stash pop --index` 保留了原先的暂存边界；若恢复时出现冲突，必须检查并解决，不能假定暂存状态完整恢复。默认 `stash push` 不包含未跟踪文件。
2. **注释在磁盘上却看不到，先核对查看的是哪个版本。** 本次注释在工作区，IDE 打开的是暂存版本。`AM` 表示文件已作为新增文件暂存，之后又有未暂存修改；不等于注释没有写入。
3. **`Unexpected vendor-prefix "-webkit-box"` 是 Stylelint 规则告警，不是格式错误。** 两行省略需要保留 `display: -webkit-box`、`-webkit-box-orient: vertical`、`-webkit-line-clamp: 2` 的配合。沿用项目已有做法，在必要声明前局部豁免，不关闭全局规则：

   ```scss
   /* stylelint-disable-next-line value-no-vendor-prefix -- 旧版内核两行省略需要该写法 */
   display: -webkit-box;
   ```

4. **`Document` 上不存在 `fonts` 是类型定义缺失。** 本次项目使用 TypeScript 4.2.3；局部补充实际消费的属性，同时保留运行时检测，无需为此升级依赖：

   ```ts
   if (typeof document !== 'undefined') {
     const fontSet = (document as Document & { fonts?: { ready: Promise<unknown> } }).fonts;
     if (fontSet) fontSet.ready.then(update).catch(() => undefined);
   }
   ```

5. **验证结果要看真实退出码。** 本次指定文件的 Stylelint、Prettier 检查通过；ESLint 被依赖加载异常阻断。局部类型检查曾通过管道截取输出，未可靠保留编译器退出码，因此“类型检查通过”的结论待验证。命令接 `| head` 后的 `$?` 通常是 `head` 的状态，不能当成编译成功证据；样式实际显示效果也未完成页面验收。

## 下次怎么用

同步前先看 `status` 和两份 diff；需要保留暂存边界时，按 fetch → stash → 快进 → `pop --index` 的顺序操作，最后再次核对状态。本次仅验证了可快进且自动合并成功的情况。

遇到编辑器红线时，先区分 Stylelint 规则、TypeScript 类型和真正的运行错误。兼容性必需的前缀按项目惯例局部豁免；DOM 类型缺失只补实际使用的属性。提交文案只描述当前 `git diff --cached` 中确实存在的内容。
