# spec7首页复盘修复与按主题拆提交

**一句话总结**：Taro 项目按 spec7 补齐首页/复盘业务后，修掉迁移断链导致的编译失败与吸顶抖动，并把 80 个改动文件按主题拆成 feat/docs/chore 三批提交。

## 背景

spec7 迭代中做了三件事：按审核清单补齐业务逻辑（枚举贯穿、静默刷新、状态单源）、把数据层从公共 services 迁回各自模块（参照 receptionPrep 规范）、修复页面打不开和首页吸顶抖动。最后 80 个文件需要按主题提交。

## 核心命令

```bash
# git mv 对未跟踪文件无效（fatal: not under version control），直接用 mv
mv src/services/spec7.ts src/pages/dealReview/service.ts

# git status --short 里的状态码：第一列=暂存区，第二列=工作区
# "M "（M后有空格）=已暂存；" M"=仅工作区改动；"??"=未跟踪
git status --short

# 用最小 tsconfig 验证类型：types:[] + files 指定目标，躲开 @types 1000+ 噪音
npx tsc -p .debug/tsconfig.wire-v173.json

# git log --pretty=format: --name-only 统计某人改过的目录（找"哪些模块是我写的"）
git log --author="802165@clife.cn" --pretty=format: --name-only | grep -v '^$' | sed -E 's#^(src/[^/]+/[^/]+)/.*#\1#' | sort | uniq -c | sort -rn

# grep -oE 抽出 markdown 链接路径并逐个验证文件存在（防文档死链）
grep -oE '\]\(src/[^)]+\)' AGENTS.md | sed 's/^](//;s/)$//' | while read -r p; do [ -e "$p" ] && echo "OK $p" || echo "MISS $p"; done

# Figma REST 节点必须过滤 visible=false（废弃图层照树还原=无中生有）
curl -s "https://api.figma.com/v1/files/<fileKey>/nodes?ids=<nodeId>" -H "X-Figma-Token: <token>"

# 提交文案带空行：写临时文件用 -F，避免 GUI/终端粘贴丢换行
git commit -F "C:/Users/802165/AppData/Local/Temp/msg-xxx.txt"

# 已跟踪文件的本地改动不想入库：.gitignore 不生效，必须 skip-worktree
git update-index --skip-worktree package-lock.json stylelint.config.js AGENTS.md
# 恢复跟踪显示
git update-index --no-skip-worktree AGENTS.md
```

## 关键结论

1. **Figma REST 节点树必须过滤 `visible: false`**：同名图层每张卡都有 ≠ 可见，废弃图层整组隐藏（强调线、状态箭头两次实锤）；颜色要合成 `color.a × paint.opacity`，描边透明度在节点 `strokeOpacity`（不在 paint.opacity）——四次返工全是"字段只读了一半"。
2. **间距不目测**：区块间距读 Auto Layout 的 `itemSpacing`/`padding*` 字段；设计稿卡片 itemSpacing=24，漏一条就是肉眼可见的拥挤。
3. **设计源版本唯一**：以用户本轮给的 Figma 链接帧为准；历史截图/旧帧/原型 HTML 只作背景。按旧图删了"面诊分析"标题，新帧有，又改回——来回返工。
4. **审核对照要"数据值 vs 实现值"逐节点 diff**：交付前用 computed style 或源码抽查颜色/间距/字号，"看起来像"不算数；不可见节点与 DOM 一一对应，多一个少一个都算 FAIL。
5. **Taro H5 的 `taro-text-core` 点击无命中框**：Playwright getByText 能找到元素但 click 报 no click point；用 `evaluate` 找到父 View 直接 `.click()`，或 cua 坐标点击。
6. **吸顶抖动根因**：`stuck` 同时驱动内容容器背景、卡片 padding 和页签高度，吸顶瞬间内容变尺寸→判定振荡。修复：独立 1px sentinel + IntersectionObserver 判定，页签外层占位固定 270px 只切内部紧凑态，吸顶 class 只作用页签自身；滚动跟随用 rAF 合并、值不变不 setState。
7. **TS 4.2.3 不支持 `import { type X }` 内联写法**（TS 4.4+ 语法），value 与 type 需拆两条 import；`import/no-duplicates` 会对同源两条报错，属已知取舍。
8. **迁移断链自查三件套**：`git status --short`（迁移后手工 mv 极易漏）、webpack "Compiled with problems" 截图、grep 被删符号的全仓引用。"测试全绿"不可信：结构测试断言的是源码字符串，编译失败它照样绿。
9. **jsdom 测试进程不退出**：React/定时器留有句柄，测试尾部显式 `process.exit(0)`（成功路径）；失败路径靠 `process.exitCode = 1` + assert 抛错。
10. **多文件批量 patch 用 python 脚本要防截断**：过长 heredoc 会被 shell 截断出 SyntaxError；且 `s.replace(...)` 后若再 `s = 其他表达式` 覆盖成 None，`open(w).write(None)` 会先把文件清空再报错——先在内存拼好完整内容、校验后再写盘，或直接用 Edit 工具。

## 提交拆分口径（按主题，不按模块）

- 数据接入+UI 收敛+删除项合一个 feat（删除与接线在同批文件，单独拆会不可编译）；删除项写进正文单列一条。
- 纯 docs（README/docs 目录）第二个提交；`.gitignore` 等本地约定单独 chore。
- 无关脏改动（package-lock 漂移、本地 stylelint 配置）不提交，用 skip-worktree 隐藏。
