# 健康页复用首页视频，切 tab 卡死

归档判断：独立笔记 + 一条 Skill 增量建议 + 一条已跑通命令。gua-pr-patch 不收（公司小程序，不是上游 PR）。gua-writer 没有新的写作规则。

最值得留下的是：微信原生 tab 不销毁，把带固定 `id` 的自动播放 `Video` 挂进 tab，同时另一个 tab 再打开也会创建同一颗视频的页面，来回切会卡或崩。`modules/taro` 已有的 `redirectTo` 规则只覆盖 App 内嵌 H5 的返回栈，没覆盖这条。

资料缺口：崩溃消失没有真机复验；关掉视频后的画面没有对过设计；`activeOut` 被忽略后的产品接受度没有确认。对话里的助手总结不算验证。stash 当时是空的，旧草稿不可恢复。

## 1. 一句话结论

未登录健康 tab 不要挂首页那颗 `Video`；未登录的 AI tab 不要再 `redirectTo` 到也会挂这颗视频的首页。

## 2. Skill 增量建议

目标：`gua-dev-tools` 的 `modules/taro/MODULE.md`，追加到「反模式」，不另起一条重复的 `redirectTo` 规则。

现有规则：`references/project-facts.md` 只写了 App 内嵌 H5 不要用 `redirectTo` 伪造返回。没有「原生 tab 常驻 + 同 id 视频」这条。

建议追加：

> 微信原生 tab 切换不销毁。不要把带固定 id 的 `<Video autoplay>` 挂进 tab 页，同时另一个 tab 在 `useDidShow` 里 `redirectTo` 到也会创建同一 Video 的页面。两路解码器叠在一起，来回切会卡或崩，底栏可能消失。tab 上要同一套界面时关掉视频；未登录分流不要再打开那一页。从 tab 页的 `useDidShow` 里 `redirectTo` 会离开 tab，不能当成「两个 tab 看起来一样」的修法。纯函数测试锁不住页面上有没有 Video。

来源证据：

- 用户报告：未登录时 AI智伴和健康是同一页；多次切回健康会卡，有时底栏消失、下半截空白。三张截图在当轮对话里。
- 源码：`src/components/home/welcome/index.tsx` 默认渲染 `Video`，`id="video"`，`autoplay`，`onProgress` 打日志。长者首页 `src/subPkg/elder-home/index.tsx` 使用它。`pages/home/index` 不是 tab。
- 当时的错误路径：健康访客复用 `Welcome`；AI 页在 `activeOut` 为真时 `redirectTo /pages/home/index`。
- 工作区改动（未提交，真机未复验）：`src/healthPkg/healthHub/index.tsx` 的访客分支 `showVideo={false}`；`src/pages/ai/target.ts` 的 `resolveAiTarget` 在未登录时一律去登录页，第二个参数 `activeOut` 不改变目标。

适用边界：微信小程序原生 tab。不要推广到 H5，也不要改 App 内嵌 H5 那条返回规则。

检验场景（未执行）：未登录健康 tab 使用 `Welcome` 且不关视频，AI tab 在 `activeOut` 为真时打开首页。来回切数次应卡或崩。对的做法是健康页不创建这颗 `Video`，AI 未登录不去首页。只断言路径字符串、却声称崩溃已消失，算错。

未执行：没有把这段写进 Skill，也没有在真机上消融。

## 3. 可复用经验与案例

问题：未登录健康页要留在 tab 内，展示问候、推荐问题和微信登录，不进健康待办。做完后两个 tab 看起来一样，切几次就卡或崩。

关键证据：

- 健康页原来在未登录时 `redirectTo` 登录页。产品要的是留在 tab 里。`resolveHealthEntry` 只有 `isFormLogin === true` 才进待办。
- 访客块直接复用了首页的 `Welcome`、`RandomQuestion`、`QuickLogin`。AI 未登录且 `activeOut` 为真时打开的长者首页，用的是同一套，所以两个 tab 看起来一样。
- 原生 tab 切走不销毁。健康页留着一路视频，首页再开一路同 id 视频。

取舍：健康访客关掉视频，背景仍用 `Welcome` 里已有的静态图。AI 未登录一律去登录页，不再打开首页。首页自己的视频不动。

验证：`test/health-entry.test.mts` 两条通过，只锁路由返回值。页面上没有 `Video` 没有断言。真机切 tab 未跑。

下次：小程序 tab 上复用「看起来只是一块 UI」的首页组件时，先看它有没有 `Video`、定时器和 `useDidShow` 里的 `redirectTo`。

`activeOut` 仍会在取消登录和 webview 退出时写入，但 AI 目标已不再读它。这是行为变化，不是已确认的产品决定。

失败信号，不要收成成功命令：`node --experimental-strip-types --test test/health-todo.test.mts` 整文件失败，因为 `adapters.ts` 用 `./config` 这种不带扩展名的相对导入，Node 报 `ERR_MODULE_NOT_FOUND`。能跑的测试文件不要去带上这种导入。

## 4. 常用命令

场景：这个仓库里只依赖纯函数、且导入路径带 `.ts` 的测试。

```
node --experimental-strip-types --test test/health-entry.test.mts
```

前提：工作目录是 `mp-c-whood-wxapp`。本轮 Shell 的 Node 是 v26.12.1，不是约定的 fnm 24。被测文件不能再导入不带扩展名的相对路径。

成功信号：`test/health-entry.test.mts` 里两条测试通过（健康入口、AI 未登录不去首页）。副作用：没有 `"type": "module"` 时会打出 `MODULE_TYPELESS_PACKAGE_JSON` 警告，测试仍可过。
