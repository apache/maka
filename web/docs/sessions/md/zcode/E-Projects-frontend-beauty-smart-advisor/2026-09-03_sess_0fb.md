## 图 2：Stylelint 报 `Unexpected vendor-prefix "-webkit-box"`

**根因**：项目的 stylelint 继承了 `stylelint-config-standard`，其中 `value-no-vendor-prefix` 规则禁止带前缀的**值**；但两行省略在旧内核上必须写 `display: -webkit-box`，属于规则误伤的业务必需写法。

**解法**：同模块早有先例——`PageContent` 和 `HomeCareProducts` 里都是加行内豁免注释。我在 4 处（CareContinuation 的 `stageActionText`、ComfortMemory 的 `tileTitle`、NextCareGuide 的 `prefValue` / `prefTiming`）套用了同样的写法：

```scss
/* stylelint-disable-next-line value-no-vendor-prefix -- 旧版内核两行省略需要该写法 */
display: -webkit-box;
```

你补的 `-webkit-box-orient: vertical` 和 `-webkit-line-clamp: 2` 属性本身没被规则拦截（只拦值前缀），clamp 写法现在是完整可生效的。

## 图 3：TS 报 `类型"Document"上不存在属性"fonts"`

**根因**：项目的 TypeScript 是 **4.2.3**，这个版本的 `lib.dom.d.ts` 还没有 `Document.fonts` 的类型定义，不是代码写错。

**解法**：不升级依赖，在 `useAlignedTextGroup.ts` 里做局部类型断言，只补充实际消费的 `ready`，并保留 `typeof document` 守卫（小程序环境没有 `document`）：

```ts
const fontSet = (document as Document & { fonts?: { ready: Promise<unknown> } }).fonts;
if (fontSet) fontSet.ready.then(update).catch(() => undefined);
```
