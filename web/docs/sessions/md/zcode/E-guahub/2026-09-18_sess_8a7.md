## 怎么开始用

1. **注册**：打开 [console.typesafe.ai](https://console.typesafe.ai/home)，用 Google 登录或邮箱收验证码。注意 Jev 目前是 early access，官方说法是从 waitlist 逐步放行，新账号不一定立刻能用。
2. **先在 Playground 玩**：登录后进 [playground](https://console.typesafe.ai/playground)，不写代码就能试各种问题，感受它返回的概率和置信度。
3. **拿 API Key**：在控制台 [console.typesafe.ai/settings/keys](https://console.typesafe.ai/settings/keys) 创建，设成环境变量 `TYPESAFE_API_KEY`。
4. **写代码调用**（官方 [Quick Start](https://docs.typesafe.ai/introduction/quickstart)）：

```bash
pip install typesafe-sdk   # Python ≥3.10；或直接 REST 调用
```

```python
from typesafe_sdk import Choice, Score, Noul, TypeSafeClient

client = TypeSafeClient()  # 自动读 TYPESAFE_API_KEY
resp = client.system_one(
    state="Hi, I've been trying to connect my Stripe account for 3 days...",
    questions={
        "department": Choice(instructions="Which team should handle this",
            criteria={"billing": "...", "technical": "...", "sales": "..."}),
        "is_urgent": Noul(instructions="The message conveys urgency"),
    },
)
print(resp.answers["department"].choice)   # "billing"
print(resp.answers["department"].confidence)  # 校准过的置信度
```

REST 等价物是 `POST https://api.typesafe.ai/v1/systemone` + `Authorization: Bearer <key>`，请求体就是 `state` + `questions` 的 JSON。

## 核心概念：只有三种“题型”

- **Choice**：从你给的候选里选一个，返回选项 + 各项概率 + 置信度（做路由/分类）
- **Score**：按你给的 rubric 数组打分（如 0=平静 / 1=不满 / 2=愤怒），分数可以是小数
- **Noul**：判断一句陈述的真伪，返回 0–1 概率
