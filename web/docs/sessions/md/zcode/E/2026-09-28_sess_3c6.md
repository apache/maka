## 怎么执行

这套脚本全部是**零依赖的 Node 脚本**（只用 node 内置模块），不需要 `pnpm install`，也不需要 cd 进项目——用绝对路径在任何目录都能跑。当前机器 Node v24.21.0，满足脚本要求的 ≥ 20.12。

### 日常同步：一条命令跑完整管线

```bash
node E:\ggbdpq\gh\agents\skills-explorer\scripts\update-skills.js
```

这是官方入口（`update-skills.js`），自动串起五步，各步骤失败会中止并写日志：

1. `npx skills update -g -y` 拉上游更新（CLI 会临时把 `~/.agents/skills` 写成实体）
2. robocopy 把实体内容合并进 `~/.ai/categories` 真身（只覆盖+新增、不删除）
3. `sk-rebuild.js` 清走实体（备份到 `.ai/.removed-<时间戳>/`）、按 manifest 重建 `~/.agents/skills` junction 视图
4. `sk-sync.js` 把视图镜像到 15 个 CLI 目录 + Codex 原生技能
5. `sk-doctor.js` 复核（problems 非 0 报错退出）

日志落在项目根的 `logs/skills-update.log`（512KB 自动轮转）。

### 只做局部操作时按需单跑

| 目的 | 命令 |
|---|---|
| 重建全局视图 `~/.agents/skills` | `node ...\scripts\sk-rebuild.js`（可加 `--dry-run` 先看） |
| 镜像到各 AI IDE 目录 | `node ...\scripts\sk-sync.js`（可加 `--dry-run` 先看） |
| 只读体检，不改任何东西 | `node ...\scripts\sk-doctor.js` |

几个实用判断：

- **改了 `.ai/categories` 真身**（新增/调整技能）→ 跑 `sk-rebuild.js` + `sk-sync.js`，不需要 `update-skills.js`（那是拉上游用的）
- **只怀疑各 IDE 目录的链接坏了** → `sk-sync.js` 是幂等的，直接重跑即可
- `sk-sync.js` 镜像的 15 个目录：`.claude`、`.codex`、`.cc-switch`、`.cursor`、`.gemini`、`.kimi`、`.kiro`、`.pi/agent`、`.zcode`、`.qoder`、`.qoder-cn`、`.codebuddy`、`.grok`、`.openclaw`、`.trae-cn`（各家的 `skills/`）
- doctor 报 `problems: 49` 属既有基线，不是这次搞坏的（README 有注明）；`update-skills.js` 只在 problems 变化时才报错
