### Q10
Q3. interface 和 type 怎么选
对象模型、接口响应、页面状态我更习惯用 interface，因为可读性更强。联合字面量、交叉类型、工具类型组合我更习惯用 type，因为表达力更直接。我的选择标准主要看场景和团队一致性。


Q4. 泛型在项目里怎么用
我项目里泛型主要用在三类地方。第一类是通用 Hook，把表单和表格的数据结构参数化。第二类是工具函数，把 key 和返回值联动起来。第三类是页面 store 更新函数，让字段名和字段值自动对应，这样能减少字符串写错和类型漂移。

Q5. Pick、Partial、Record、ReturnType 怎么落地
我在项目里用工具类型主要是为了减少重复定义。Pick 适合从后端响应里裁出页面真正要展示的字段，Partial 适合搜索条件和局部状态，ReturnType 适合把 Hook 暴露类型和实现绑定，Record 适合处理动态 key 的映射结构。这样维护成本会低很多。

Q6. 类型守卫怎么做
我做类型守卫通常分两层。通用层做 string、number、plainObject 这些基础判断，业务层再补像字段配置对象这种自定义守卫。这样做的价值很直接，外部数据进来先收窄，再进页面逻辑，代码会稳很多。
