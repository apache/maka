.eslintrc.js 里你们显式加了：

这说明在你们这套 React 项目里，最核心、最明确强调的就是 Hooks 使用规范。

这两条你一定要会讲，因为它们和你前面面试里那道题是直接相关的。

第一条，react-hooks/rules-of-hooks。
它要求 Hook 只能在 React 函数组件或自定义 Hook 顶层调用，不能放在条件、循环、嵌套函数里。
它的价值不是“代码更优雅”，而是保证 Hook 调用顺序稳定，否则状态会错位，组件行为会变得不可预测。

第二条，react-hooks/exhaustive-deps。
它要求 useEffect、useMemo、useCallback 这些 Hook 的依赖项尽量写完整。
它的价值是让副作用和真实数据源保持一致，避免出现旧值、漏更新、错误请求、竞态这种问题。
你前面那场面试，面试官盯着问你的 useEffect 依赖，就是这条规则背后的真实场景。

所以如果只看 ssap-front，你最该讲的其实就是这两条。
