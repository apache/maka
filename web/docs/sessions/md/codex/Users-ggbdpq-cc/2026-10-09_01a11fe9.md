你是一名拥有 20 年经验的 Go 语言架构师、AI Agent 工程专家及软件工程治理专家。

请在当前 **GuaHub 项目根目录**中，基于 [https://skills.sh](https://skills.sh) 对 Go 开发相关 Skills 进行审计、安装、配置与验证，建立可维护、低冗余的项目级 AI 编码规范体系。

## 一、执行原则

1. 仅允许项目级安装，禁止使用 `--global`、`-g` 或修改用户级 Skills。
2. 遵守现有 `AGENTS.md`、项目架构、Go 版本及工程规范。
3. 先审计现状，再执行变更，禁止覆盖既有配置。
4. 优先采用成熟、专注 Go 语言的 Skills，避免功能重叠。
5. Skills 仅提供开发指导，不得替代 Go 官方工具链及项目质量门禁。

## 二、推荐 Skills

主仓库：[https://skills.sh/samber/cc-skills-golang](https://skills.sh/samber/cc-skills-golang)

**核心 Skills（优先安装）**

- `golang-code-style`：代码风格与惯用写法
- `golang-error-handling`：错误处理
- `golang-testing`：测试与竞态检测
- `golang-concurrency`：并发编程
- `golang-context`：Context 生命周期管理
- `golang-lint`：静态分析与代码质量

**扩展 Skills（评估后安装）**

- `golang-gopls`：语义分析与代码导航
- `go-code-review`：来自 `cxuu/golang-skills` 的代码审查规范

## 三、执行流程

### 阶段一：环境审计

检查项目结构、Go 版本、`go.mod`、现有 Skills、Agent 配置及测试体系，识别兼容性问题和重复规则。

### 阶段二：Skills 安装

核验 skills.sh 对应仓库、`SKILL.md`、安装命令及脚本安全性。

通过官方 Skills CLI 完成项目级安装，确保 Claude Code、Codex 等实际使用的 Agent 能够发现 Skills。禁止修改全局配置。

### 阶段三：工程集成

遵循现有目录规范，维护项目级 Skills 索引及适用场景说明。

建立 Go 开发、测试、审查、重构的调用规则，明确各 Skill 的职责和触发条件。

不得无故新增重复规范、引入第三方依赖或重构业务代码。

### 阶段四：验收

验证安装路径、Skills 可发现性、规则冲突及作用域隔离。

根据项目已有质量门禁执行 `go test ./...`、`go vet ./...`，必要时补充竞态检测和静态检查。

## 四、最终交付
