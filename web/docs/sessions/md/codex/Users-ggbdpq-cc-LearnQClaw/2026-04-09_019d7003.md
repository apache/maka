**可执行步骤**
1. 先安装 OpenClaw CLI。
```bash
npm install -g openclaw@2026.4.8
rehash
openclaw --version
```

2. 安装微信插件。
```bash
mkdir -p ~/.openclaw/tmp/npm-cache
npm_config_cache=~/.openclaw/tmp/npm-cache openclaw plugins install @tencent-weixin/openclaw-weixin@2.1.7
openclaw plugins inspect openclaw-weixin
```

3. 打开微信通道。
```bash
openclaw config set channels.openclaw-weixin.enabled true
```

4. 配置 GLM。
```bash
cat > /tmp/glm-provider.json <<'JSON'
{"api":"openai-completions","baseUrl":"https://open.bigmodel.cn/api/paas/v4","models":[{"id":"glm-4.6","name":"GLM-4.6"}]}
JSON

openclaw config set models.providers.glm "$(cat /tmp/glm-provider.json)" --strict-json
openclaw config set models.providers.glm.apiKey --ref-provider default --ref-source env --ref-id GLM_API_KEY
openclaw models set glm/glm-4.6
```

5. 扫码登录微信。
```bash
openclaw channels login --channel openclaw-weixin --verbose
```

6. 启动网关。
```bash
openclaw gateway
```

7. 再开一个终端看状态和日志。
```bash
openclaw status --deep
openclaw channels logs --channel openclaw-weixin --lines 80
```

如果你想要一句最短版，可以记成这句话：
