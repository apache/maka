# AI Screenshot Renamer

## Overview

把“随手截图、命名混乱、后续难检索”的图片堆，转换成统一命名格式，方便手动二次分类。

默认命名模板：`YYYY-MM-DD+[分类]+解决了什么问题`。

分类词典见 `references/taxonomy.md`。

## Workflow

1) 先预览（Dry Run）

```bash
python3 scripts/screenshot_renamer.py --input <截图目录> --recursive
```

2) 确认预览输出符合预期后再执行改名

```bash
python3 scripts/screenshot_renamer.py --input <截图目录> --recursive --apply
```

3) 抽样检查结果后，再进行手动移动到你的现有分类目录。

## Naming Rules

- 日期提取优先级：
  - 文件名中的时间模式（如 `20260208_0120`）
  - OCR 文本中的时间模式（如 `26年2月8日, 1:20`）
  - 文件修改时间（兜底）
- 分类提取：按关键词打分映射到热门 AI 分类。
- 问题摘要提取：尽量保留能表达“解决什么问题”的主句。
- 冲突处理：同名自动追加 `-02`、`-03` 序号。

## Input Preparation

- 推荐把待整理截图放在一个临时目录，再执行脚本，避免误改名。
- 如果系统装了 `tesseract`，脚本会直接 OCR 图片文本。
- 如果没装 `tesseract`，可给每张图旁边放同名 `.txt`（sidecar）辅助分类。
  - 例如：`xxx.png` 对应 `xxx.txt`

## Examples

输入截图文本（推文）：

`OpenAI和Anthropic是两条完全不同的商业发展路线...`

输出文件名：

`2026-02-08+[模型公司与战略]+OpenAI和Anthropic商业路线差异分析.png`

## Resources

- `scripts/screenshot_renamer.py`：批量扫描与重命名脚本
- `scripts/test_screenshot_renamer.py`：核心行为测试
- `references/taxonomy.md`：热门 AI 分类和命名语义

## Guardrails

- 永远先 Dry Run，再 `--apply`。
- 不做删除操作，只做重命名。
- OCR 识别不可靠时保持保守命名，交给人工最终裁决。
