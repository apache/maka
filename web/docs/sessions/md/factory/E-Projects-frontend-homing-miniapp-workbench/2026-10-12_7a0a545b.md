### A3
JSON 里的 `plans` 是一个数组，装着所有方案。代码里的 `plan` 是从这个数组里挑出来的其中一条。这两个名字不冲突，是“列表”和“列表里的一项”的区别。

**取值过程**（`evidence.ts`，`case 'strategy'`）

```ts
// title = 当前选中的项目名，例如「水光补水」
const opportunity = opportunityCard?.opportunities.find(item => item.projectName === title);
return mapPrepPlanEvidenceView(
  planCard?.plans.find(plan => plan.opportunityNo === opportunity?.opportunityNo) ?? null,
  title
);
```

1. 用项目名“水光补水”在 `opportunities[]` 里找到对应的机会，它的 `opportunityNo` 是 1。
2. 用 `opportunityNo = 1` 在 `plans[]` 里找到对应的那一条方案。
3. 只把这一条方案传给 `mapPrepPlanEvidenceView(plan, ...)`。所以函数参数叫 `plan`，类型是 `PrepReceptionPlanItem`，表示一条方案。

**对应到你的数据**

```
receptionPlan.plans[0]   → opportunityNo 1，水光补水   ← 选中“水光补水”时，传进去的 plan 就是它
receptionPlan.plans[1]   → opportunityNo 2，光子嫩肤
```

所以 `plan.credibilityScore` 读的就是 `plans[0].credibilityScore`，也就是和 `projectName: "水光补水"` 同一层的那个字段，正好是后端说的“外层”。
