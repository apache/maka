## 不重启能否生效:**不能**

证据在 [patchService.ts:210-218](plugins/cursor-language-pack-zh-hans/src/patchService.ts#L210-L218):`translator.install()` 做了三件事,其中第三件是**修改 Cursor 应用 `resources/app/package.json` 的 `main` 入口**(状态检查里的 `packageJsonPatched` 就是这一项,[patchService.ts:273-276](plugins/cursor-language-pack-zh-hans/src/patchService.ts#L273-L276))。

这个 `main` 是 Electron **主进程**启动时读取的入口。补丁把它改成「拦截器先 require 翻译逻辑,再 require 原 main」。

- **`reloadWindow`(重新加载窗口)** 只重启渲染进程,主进程不重新读 `main`,所以**汉化不会生效**。
- **完整重启主进程**才有效。

这正是你代码注释里写的判断,正确。所以「不重启就生效」在当前补丁机制下做不到,除非把注入点整个重写到渲染层,那是方案级大改。
