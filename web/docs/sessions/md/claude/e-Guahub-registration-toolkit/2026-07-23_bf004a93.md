### ❌ 唯一卡点：Auth0 React 表单无法提交

**现象**：在 ChatGPT 注册页（`Create an account`）输入邮箱后，无论用什么方式点击"Continue"或按 Enter，页面都不跳转——永远停留在邮箱输入步骤。

**已尝试的方案**（全部失败）：

| 方案 | 原理 | 失败原因推测 |
|------|------|-------------|
| CDP `keyboard.type() + press('Enter')` | CDP 协议级 `Input.dispatchKeyEvent` | Auth0 不响应纯键盘提交 |
| DOM `button.click()` | `evaluate` 中模拟点击 | `isTrusted: false`，Auth0 忽略 |
| `nativeSetter + form.submit()` | 绕过 React `_valueTracker` | `form.submit()` 触发 but Auth0 拦截 |
| CDP `mouse.click(x,y)` 坐标点击 | CDP `Input.dispatchMouseEvent` | 点击触发 but 实际未通过 Auth0 校验 |
| `InputEvent(inputType:'insertText')` | 模拟 DOM Level 3 输入事件 | `isTrusted: false` |
| **React Fiber 注入** | 遍历 `__reactFiber$` 找 `onChange` handler 直接调用 | 刚实现，尚未充分测试 |

### 📋 建议的突破方向

1. **React Fiber 深度注入**（最可逆）：找到 Auth0 组件的 React 内部状态，直接调用 `handleSubmit` 而非模拟用户交互
2. **切换到 Playwright**：Playwright 的 CDP 实现不同于 puppeteer-real-browser，导航处理更成熟
3. **MIDDLEWARE 方案**：不通过 UI，改为抓取 Auth0 的 API 调用（邮箱验证 → 密码创建 → 验证码），直接用 HTTP 请求模拟注册流程
4. **手动+自动混合**：手动注册一个账号的同时用 Chrome DevTools 记录所有网络请求，然后批量回放
