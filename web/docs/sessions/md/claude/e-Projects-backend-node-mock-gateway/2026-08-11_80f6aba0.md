## 一个必须知道的关键机制（实测确认）

**请求带分页参数时，网关从「命中的场景 + 所有映射场景」中选 `list` 最长者做切片数据源**，再按 `pageIndex` 切片。实测 pageIndex=1/2/3/4 返回的全是 long-text 数据（totalRows 恒为 25）。

推论：只有**全场最长**的场景，数据才会真正显示在分页列表上。这也意味着你之前的 `add-remaining-items-default.mjs`（改 default）其实是**不生效的**——分页请求看到的剩余项目来自 long-text。模板用 `writeMasterState` 内置了这一协调：跑哪个模板，哪个场景就是数据源。
