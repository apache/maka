`✶ Insight ─────────────────────────────────────`
- `git ls-files --others` 只列**未跟踪**文件——你在 VSCode 里点过暂存后它们就变成了 index 中的 `A` 状态，`ls-files --others` 返回空不是文件丢了，而是它们已不再是 "others"。`git status --short` 的两列（index 列 + worktree 列）才是判断暂存状态的权威依据：`A ` 是已暂存新文件，`??` 是未跟踪。
- 之前 `Get-Item` 找不到文件是因为 git 默认 `core.quotepath=true`——非 ASCII 路径输出为八进制转义（`\351\272\246...`），这只是显示层转义，实际路径没变。处理中文文件名时加 `-c core.quotepath=false`，或者像我这次一样用 `git diff --cached --stat`（二进制文件直接给字节数）绕开路径解码问题。
- GitHub 的单文件限制是 100MB（硬拒）、50MB（警告）。本次最大文件 11.5MB 安全，但二进制一旦进了提交，仓库体积就是**不可逆累积**——后续每次 clone 都要下载全部历史版本，这是二进制入库前值得掂量的唯一账。
