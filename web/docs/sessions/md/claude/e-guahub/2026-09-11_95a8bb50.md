`✶ Insight ─────────────────────────────────────`
- **`git diff -- <不存在的路径>` 不报错、只返回空**——"查无此路径"与"无差异"输出完全相同。这是本次连环错误的机制根源：错误路径叠加 `--ignore-cr-at-eol` 过滤器，让"空"看起来像是证据。
- **NBSP（U+00A0）是文档编辑的隐形陷阱**：Read 工具把 `C2 A0` 渲染成普通空格，肉眼无法分辨，Edit 因而匹配失败。该文档固有 505 个 NBSP（多半来自 Word/飞书导入），修正时只匹配纯 ASCII 子串（`Dem1o`）即可绕开。
- **`--force-with-lease` 是 force push 的安全形态**：它在远程自你上次 fetch 后又被更新时拒绝推送，避免覆盖他人刚推的提交。已推送的 `amend` 必定造成分叉，此处用它比 `--force` 或 merge 都干净。
