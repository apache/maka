# 知识库输出型转型方案

## 一、现状诊断

当前知识库的核心矛盾：**管理体系 >> 训练体系**

| 维度     | 现状                                   | 目标                                |
| -------- | -------------------------------------- | ----------------------------------- |
| 导航层   | 61 个 README，多套入口                 | 保留，但增加"训练入口"              |
| 知识密度 | P0/P1 高频清单已结构化                 | 提取为可独立训练的"闪卡"            |
| 复习追踪 | frontmatter 有 confidence 字段但未使用 | 基于 confidence + review 做间隔复习 |
| 输出验证 | 无                                     | 增加"口述检查清单"                  |

## 二、核心思路：不重建，只叠加

不破坏现有目录结构和文档，在现有体系上叠加三个"训练层"：

### 层 1：闪卡提取层（每日训练素材）

从 P0/P1 高频清单中，提取每道题的「30 秒回答」为独立闪卡。

- **位置**：`04-面试与复盘/4.2-高频清单/flashcards/`
- **格式**：每张闪卡一个文件，包含「问题 -> 30 秒回答 -> 关键词提示 -> 追问链接」
- **来源**：直接从 `01-P0-必背题目.md`、`02-P1-重要题目.md` 提取，不重复内容
- **数量**：P0 约 35 张，P1 约 30 张，合计约 65 张
- **命名**：`js-01-事件循环.md`、`react-01-hooks规则.md`

### 层 2：间隔复习追踪层（知道自己忘了什么）

利用现有 frontmatter 的 `confidence` 和 `review` 字段，建立一个轻量的复习追踪机制。

- **位置**：`04-面试与复盘/4.2-高频清单/review-tracker.md`
- **内容**：一张表格，列出所有闪卡的「上次复习日期 + confidence 等级 + 下次复习日期」
- **规则**：
  - confidence: low -> 每天复习
  - confidence: medium -> 每 3 天
  - confidence: high -> 每 7 天
- **操作**：每次复习后手动更新日期和 confidence（极低成本）

### 层 3：口述验证层（从"写得出"到"说得出"）

面试是口试，不是笔试。增加一个口述训练入口。

- **位置**：`04-面试与复盘/4.4-面试话术/oral-checklist.md`
- **内容**：
  - 每日口述清单（从 review-tracker 中挑选当日应复习的 5-8 道题）
  - 口述评分标准（流利度 / 关键词命中 / 时间控制）
  - 录音回听建议
- **关联**：链接到对应闪卡和原始文档

## 三、额外优化：精简导航层

当前多入口问题（`从这里开始.md` vs `00-入口与索引/README.md` vs 各模块 README）造成选择困难。建议：

- 在 `00-入口与索引/从这里开始.md` 中增加一个"今日训练"快速入口
- 不删除现有入口，但明确区分"管理入口"和"训练入口"
- 训练入口直接链接到 review-tracker 和当日口述清单

## 四、不做的事

- 不重新组织现有目录结构
- 不合并或删除现有文档
- 不引入外部工具（Anki、Notion 等）——保持纯 Markdown 的轻量性
- 不为 `02-专业技能/` 的知识文档做结构改造（那些是参考资料，不需要变成训练素材）

## 五、实施节奏

分 3 步，每步可独立交付，不依赖后续步骤：

1. **Step 1**：从 P0 必背题目提取闪卡 + 创建 review-tracker（约 35 张闪卡）
2. **Step 2**：从 P1 重要题目提取闪卡 + 扩展 review-tracker（约 30 张闪卡）
3. **Step 3**：创建口述验证清单 + 在「从这里开始」增加训练入口

## 六、预期效果

- 面试前 10 分钟：打开 review-tracker，看到今日应复习的 5-8 道题
- 每道题 30 秒：打开闪卡，先不看答案自己说一遍，再对照
- 每天 15 分钟：完成一轮口述训练，更新 confidence
- 一周后：confidence 分布从"大量 medium"变成"多数 high + 少量 low 重点攻克"
