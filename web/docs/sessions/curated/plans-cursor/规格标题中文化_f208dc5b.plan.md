# 规格标题改为中文在前

今晚会议里难懂的是加粗英文标题（`Feature Branch`、`Reading Order`、`Given` / `When` / `Then`），不是已经是中文的正文。写法按你选的：**中文在前，括号留英文协议词**。编号、文件名、接口字段仍不译。

## 新约定（一条就能执行）

```markdown
# 特性规格（Feature Specification）: 平板端舒适记忆与安心延续

**特性分支（Feature Branch）**: `001-tablet-comfort-report`

## 0. 阅读顺序（Reading Order）

### 用户故事 1（User Story 1）- 美容师讲解舒适记忆，顾客感到被记住（Priority: P1）

1. **假如（Given）** …，**当（When）** …，**则（Then）** …
```

领域节从 `Comfort Memory - 舒适记忆` 改成 `舒适记忆（Comfort Memory）`，和协议节同一方向：人先读中文。

**仍不译：** `FR-001` / `SC-001` / `T001` / `P1` / `[P]` / `[US1]`、文件名、命令名、代码路径、接口字段（如 `launchId`）、组件名（如 `ComfortMemory`）。

**仍不改：** 官方英文模板 [`.specify/templates/`](.specify/templates/)（生成后再按本仓库规则写成中文在前）；全局 `speckit-*` 技能；`.specify/templates/` 核心英文。括号里的英文足够让 `/speckit-analyze` 等继续对上 `User Story`、`Feature Specification`。
