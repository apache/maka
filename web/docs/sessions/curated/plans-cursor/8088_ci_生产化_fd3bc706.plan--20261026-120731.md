## 关键纠偏原则

- 不再把第一轮的 `TranscriptProvider` / `CustomerRecognizer` 作为 8087 真实生产方向。
- 不在 8087 新增讯飞、Qwen、Spark、Tencent CI、COS SDK、ffmpeg/ffprobe 相关实现。
- 不把本地 `/audio-edit/results` URL 当作真实腾讯云 CI 输入。
- 不假装异步任务同步完成，提交接口只返回任务快照，结果通过 detail 或后续回调/轮询补齐。
- 不覆盖源音频，所有 transcript 输出、AIGC marked audio、clip 中间产物都使用新 key。
- 不改前端，不让前端直连 8088。
