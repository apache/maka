## 使用原则

1. 先读活动主题文档，需要证据时再查原始备份。
2. 同一主题有新增结论时更新既有文档，不创建「第二份总结」。
3. 项目代码、最新接口契约、测试与运行日志的优先级高于聊天沉淀。
4. 基础常识、一次性计算和强时效清单默认不进入长期知识库。
5. 原始备份已于 2026-09-30 二次清理（见目录说明）；删除在 git 历史中可回滚，仍非不可逆操作。
