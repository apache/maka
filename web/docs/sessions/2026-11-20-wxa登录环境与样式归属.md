# wxa 登录环境与样式归属

## 一句话结论

wxa-runner 里各浏览器都提示「登录已失效」时，先看请求域名是否和 token 的 `ENV_KEY` 一致；接口 403 会清掉刚写入的登录态，看起来像 token 没写上。健康报告卡片样式不是本次健康待办改的。

### 1. wxa：登录失效先对域名，再换 token

位置：`modules/wxa/MODULE.md` 步骤表之后。表里已有 `WXA_ENV_KEY` / `WXA_IS_TEST`，同文件也写了假 token 会触发 403 清登录态。缺的是这条判断顺序。

建议追加：

> 各浏览器都提示「登录已失效」、且 setup 已写入 token 时，先看请求域名是否和 `WXA_ENV_KEY` 一致。浏览器里残留的 `ENV_KEY` / `isTest` 会把 itest 的 token 发到别的环境；业务 code 403 会清掉刚写入的登录态。换 token 之前先对齐环境。

来源：本对话里 Cursor 浏览器在 `ENV_KEY=1` 时健康页能打开；谷歌浏览器仍提示登录失效。随后 setup 增加 `isTest` 与 `ENV_KEY`，`/__wxa__/setup.js` 已含这两项。谷歌刷新后的结果未在本对话里再确认。

检验场景：一个浏览器的 Storage 把 `ENV_KEY` 指到非 itest，另一个已是 itest。同一枚 token 应只在 itest 打开健康页；对齐 `ENV_KEY` 后两边都能开。未执行。

不另写：开发者工具登录态不会打包进浏览器、`dev dist` 要在仓库根用 `wxa.config.js` 指向 setup、旧进程读不到新环境变量、token 不进源码。这些已在 wxa 模块。

### 2. gua-pr-patch：下线仓的孤儿提交不能快进

位置：`references/workflow.md` 接手或同步 fork 处。现有文档未写「无共同祖先」。

建议追加：

> 上游最后一次提交没有父提交、compare 报 no common ancestor 时，不要快进或强推到自己的 fork。那一笔通常是清空历史的下线提交。只同步仍与现有历史相连、且作者是原维护者的提交。

来源：本对话 `gh api repos/ggbdpq/wxa-runner/compare/main...open-wxa:main` 返回 404、无共同祖先。`fsy0718/wxa-runner` 相对当时的 fork 是快进 4 个提交、落后 0，已用更新 ref 同步。npm 上的 0.14.0 安装包只有 CLI 入口，实现在 `@open-wxa/wxa-runner-core` 与 `extractor`，公开 fork 里没有这份源码。

检验场景：compare 无共同祖先时停止同步；有共同祖先且 ahead>0、behind=0 才更新 fork。未执行成规则。

## 常用命令

前提：Windows PowerShell，Node 由本机 fnm 提供。把 `<repo>` 换成仓库路径。

```powershell
npm view wxa-runner version dist-tags --json
```

看 npm `latest`。本对话结果是 0.14.0。同一次 `npx wxa-runner` 却提示安装 0.13.1。全局安装后改跑 `wxa-runner`，不要再加 `npx`。

```powershell
npm install -g wxa-runner@0.14.0
wxa-runner --version
```

成功信号是输出版本号。若 esbuild 的 postinstall 被跳过，再执行一次并加上 `--allow-scripts=esbuild,@parcel/watcher`。副作用：写入用户级全局 prefix。

```powershell
gh api "repos/<owner>/<repo>/compare/main...<fork-owner>:main" --jq "{status:.status,ahead:.ahead_by,behind:.behind_by}"
```

`identical` 或 `behind` 且 ahead=0 表示对方没有更新的提交。无共同祖先时接口直接失败，不要据此强推。

```powershell
git -C <repo> blame -L 40,65 -- src/healthPkg/healthHub/components/HealthReport/index.module.scss
```

成功信号是每行带作者和提交。用来回答「这行是谁改的」，不能代替设计是否已定。

## 待验证与不适用边界

- 谷歌浏览器在写入 `ENV_KEY` 之后刷新是否已登录，本对话没有再看一眼。
- `npx` 解析到旧版本只观察到这一次，不写成 npm 的普遍行为。
- 下线仓的孤儿提交规则只适用于「官方历史被清空、fork 仍留着旧历史」。正常有共同祖先的落后 fork 仍应快进。
