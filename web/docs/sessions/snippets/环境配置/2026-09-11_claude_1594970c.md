`✶ Insight ─────────────────────────────────────`
- 「停止跟踪」的暂存态是个**中间态**：索引里删了、HEAD 里还有，所以 `git status` 显示 `D` 而磁盘文件安然无恙。只有这个删除被 commit 后，`.env` 才真正脱离跟踪，此后 `.gitignore` 的排除规则才开始对它起作用——顺序反了（只加 ignore 不删索引）是常见的无效操作。
- 这次泄露能被 `git rm --cached` 干净收场的根本前提是**仓库为 private 且协作者仅自己**：如果已有他人克隆，停止跟踪不减少任何已扩散的副本，轮换凭证就从「建议」升级为「唯一有效的补救」。
