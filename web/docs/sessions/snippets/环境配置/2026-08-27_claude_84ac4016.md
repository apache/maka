`✶ Insight ─────────────────────────────────────`
- **`approval_policy` 与 `sandbox_mode` 是两个独立闸门**：`danger-full-access` 只解除沙箱隔离，`approval_policy = "never"` 才是取消“执行前问你”。你的模板只开了前者，等于“能全权执行但仍会请示”——比网友的配置多保留一层确认，这与你全局宪法里的 Read → Plan → Confirm → Execute 原则一致。
- **`supports_websockets` 的取值由网络拓扑决定，无关优劣**：WSS 流式传输体验更好但易被中间代理掐断。你的模板注释记录了这一踩坑（v2rayN mixed 端口 10808），网友直连中转站没有这层链路，所以能开 `true`。
- **中转站配置缺少重试参数是常见隐患**：你模板里 `stream_max_retries = 10` / `stream_idle_timeout_ms` 这组容错对第三方中转尤其重要——公网中转的流式稳定性通常不如官方直连，网友那份配置遇到网络抖动会直接断流重跑。
`─────────────────────────────────────────────────`
