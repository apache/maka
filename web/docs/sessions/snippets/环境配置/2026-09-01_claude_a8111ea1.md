`✶ Insight ─────────────────────────────────────`
- `reset --soft <根提交>` + `commit --amend` 是压缩到单条无父历史的最短路径：soft 只移动分支指针、暂存区保留全部变更，amend 直接改写根提交本身——比 `checkout --orphan` 重建少一半步骤，且旧提交仍在 reflog 中可寻回（`adc8c72b`、`b72f1be2`）。
- force push 后远程与本地是“同一历史的两个克隆”关系，另一台机器**不能** `git pull`（会产生不相关历史合并），必须重新 clone 或 `fetch + reset --hard origin/main`。这一点已写入记忆。
