## 一键方案（在你那个管理员 PowerShell 里跑）

**先做一件事**：切回 VSCode，按 **`Ctrl+K` 再按 `S`** 保存全部编辑器（下面命令会强制关闭 VSCode）。

然后在管理员 PowerShell 粘贴执行：

```powershell
Stop-Process -Name Code,cockpit*,codex* -Force -ErrorAction SilentlyContinue
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\802165\Downloads\dev-config\scripts\setup-dev-config-bom.ps1" *>&1 | Tee-Object "C:\Users\802165\Downloads\dev-config-setup.log"
```

**这条命令做什么**：①杀掉所有 VSCode + codex 进程（释放 `.agents` 句柄，且没有扩展宿主就不会重启 codex）②立即跑 setup 脚本（窗口期内 `.agents` 解锁，`Move-Item` 能成功）③日志写入 `dev-config-setup.log`。

## 跑完之后（重要）

- 执行命令的瞬间**本会话会中断**（VSCode 被杀）—— 这是必然的。
- 脚本跑完后**重开 VSCode**：直接**开新会话**（不用 `/resume`，因为本会话日志随 `.claude` 被搬进了 `.claude.bak-xxx`，`/resume` 找不到）。
- 新会话开头会**自动加载本会话的进度记忆**（context-mode 已索引关键决策/步骤），你只需说一句"**脚本跑完了**"，我会读 `dev-config-setup.log` + 检查 home 状态完成验证收尾。
