`✶ Insight ─────────────────────────────────────`
- 识别历史重置的信号：`git log origin/main..HEAD` 突然显示大量「本地领先」——那些提交明明已在远程过。先 `git log --format="%h %p" origin/main` 看到无父提交即可定性，然后验证 `git diff <本地HEAD> origin/main --stat` 确认新历史是超集，再放心 reset。
