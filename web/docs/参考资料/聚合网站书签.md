## 一、怎么读这份文档

**分类逻辑**：先按「它替你解决什么问题」分 16 个大类，再按技术栈/场景排列（本期限于体量，大部分类目拆出了二级小节）。同一站点的多条链接（重复的设计稿、ChatGPT 对话、内网深链、搜索入口）合并到同一个条目下逐条列出。表格里的「条数」按表格行数计，一行含多个链接时只算一行。

**「网络」列的含义**（2026-09-30 在本机、公司网络、**不走代理直连**实测）：

| 标记 | 含义 |
| --- | --- |
| ✅ 直连 | 不用代理就能打开（返回 HTTP 状态码即算通，403/405/468 属于站点反爬或不允许 HEAD，浏览器里正常） |
| 🔒 需代理 | 直连超时/被重置，走本机代理 `127.0.0.1:7897` 可打开 |
| 🏢 内网 | 只能在公司网络访问，家里/外网打不开 |
| 💻 本地 | 本机服务或本地文件，与外网无关 |

**本期与上期的网络判定变化**（网络快照漂移的实证）：`github.com` 上期直连可通、**本期直连超时需代理**（涉及面最广，正文所有 GitHub 链接已改标 🔒）；`www.lennysproductpass.com` 上期要代理、本期直连可通；`muse.ai`、`key.tpkcur.click` 由直连可通变为需代理。

**使用注意**：

- 网络判定是**当天快照**，会随 GFW 策略和站点变化；「✅ 直连」不等于永远能开，遇到打不开先挂代理再试。
- 标注「**未验证**」的条目，是没抓到页面内容、只能按标题或域名推断的，用前自己点开确认。
- 内网条目（10.6.33.x、itest.clife.net 等）和本地服务条目是工作现场快照；本期实测 `itest.clife.net`、`oa.clife.cn:8087` 可达，`10.6.33.85/49` 与本机 `127.0.0.1` 上的几个服务仍未监听（可能按需启动）。
