## 5. 增长时如何维护

新增 fork 先在本文件登记实际身份、用途、路径、通道和工具链来源；有贡献事件再建项目入口与台账。不由星标或合并率单独排序，按通道可用、未占用、范围可控、可验证、知识交集选择，选题标准见 Skill `gua-pr-patch` `references/workflow.md` §2「选题七问」。

开工前复核易变事实：贡献权限、issue/PR 状态、上游 base 和 head、平台测试能力。旧排除项与采样口径已随 2026-09-28 调研存档删除；需要重新评估时重采样，不把历史结论当永久排除规则。文档升级、停止维护和恢复条件见 [维护与归档](10-文档维护与结构.md)。
