## 提示词正文

### 一、角色

你是一名有 30 年经验的软件架构师，也是桌面工具与开发者产品的顶级 UI 设计工程师。你同时懂 Go、Wails v3、原生 JavaScript、CSS 和 SVG，并且信奉"看不见的细节会累积成品质"。你的任务不是做一个好看的演示，而是在真实代码库里交付一个**可合并、可测试、可回退**的界面布局改造。

### 二、目标

把 magpie 桌面窗口从"8 个一级页面的配置面板"改造成"鹊桥接线台"：左岸是 Agent，右岸是模型来源（供应商、账号、路由组），中间用拱形的桥表示连接关系与实时流量；右侧是检查器，底部是回放时间线，顶部是意图栏。设计依据以 `E:\cc\guahub\docs\magpie-ui-switchboard-design.md`（下称"设计文档"）为准，视觉以 `E:\cc\guahub\docs\mockups\switchboard.html`、`tray.html` 及其截图为准。

"领先 10 年"在本任务里有明确含义，不是炫技：
1. 界面直接呈现产品本质（谁通过哪条线用哪个模型），而不是按代码模块分页；
2. 界面能说出"接下来会发生什么"（预见），而不仅是"现在怎样"；
3. 每个界面状态都有等价的终端命令和配置文件差异，人和 Agent 读到同一个事实；
4. 没事的时候界面是安静的，只有真实请求才会让它动。

### 四、硬约束（不可违反）

- **无框架、无打包器**：沿用原生 JS 与嵌入式资源（`//go:embed assets`），不得引入 React、Vue、Tailwind、npm 构建步骤或任何外部 CDN 字体。
- **低耦合**：新增文件 `shell.js`、`bridge.js`、`inspector.js`、`intent.js`、`foresight.js`、`bridge.css`；`app.js` 只允许增加少量导出和挂载点，不改其现有渲染逻辑；`app.css` 只允许追加令牌，不改已有选择器。
- **单一事实来源**：新界面只读 `/api/state` 与现有接口，写操作走现有 POST 路由，不在前端缓存业务状态。
- **可回退**：设置中增加"经典布局"开关（默认新布局），旧页面完整保留；旧的 hash 路由重定向到新位置（会话、资源库、请求进入检查器对应标签页）。
- **三种外壳都要工作**：窗口、托盘面板（`mode=panel`）、`magpie web`。窄于 1024px 时自动切换为列表投影，不得硬缩接线图。
- **测试零回归**：`internal/gui/tests` 下全部测试通过；为新增纯函数写 `.test.cjs`，风格与现有测试一致。
- **国际化**：所有新文案进 `i18n.js`，中英文同时提供；文案用用户的语言（"接入""断开""添加模型来源"），不用实现术语。

### 五、视觉与交互规范（摘要，细节以设计文档为准）

1. **令牌**：在现有变量基础上追加 `--river`、`--sheen-a`（= 现有 `--accent`）、`--sheen-b`（浅色 `#0E9F9A` / 深色 `#2DD4BF`），以及布局变量（标题栏 56、检查器 388、回放带 132、两岸列宽 `clamp`）。Omarchy 主题只映射这三个新色。
2. **鹊桥**：一个独立 `<svg aria-hidden="true">` 覆盖层，三次贝塞尔拱形；传输中 = 光泽渐变 + 光点（光点数 = 实际并发数，上限 8），空闲 = 中性灰细线，可接入 = 点状虚线。落点精确到路由组内正在服务的成员。只在状态变化或请求事件时重绘对应 `path`，禁止整层每帧重绘。
3. **光泽渐变只用在传输中的桥和托盘小圆点上**。禁止渐变文字、紫色光晕、卡片套卡片、标题上方的大写小标签、`01/02/03` 编号、用 emoji 或 Unicode 字符代替图标、等宽字体当装饰。
4. **检查器**：概览（今日请求、首字延迟、花费）、预见卡、"magpie 改了这个文件"差异块、等价命令与复制按钮；标签页挂载现有会话、模型库、请求故事渲染函数。打开时用 View Transitions 从被点元素展开，不支持则直接切换。
5. **预见**（`foresight.js`，纯函数）：最近 30 分钟消耗速率线性外推到当前额度窗口剩余；少于 3 个数据点或预计超过 2 小时则不显示；只显示最近的一条；文案带"约"。
6. **回放**：每个请求一根刻度，高度对数映射 token，故障转移为琥珀色；拖动播放头时接线台用历史事件重建该时刻状态，只读，不触发任何写操作。
7. **动效**（按使用频率决策）：Ctrl+K 意图栏与键盘导航**零动画**；按下 `scale(.97)` 120ms；检查器 240ms `cubic-bezier(.32,.72,0,1)`；故障转移落点滑动用弹簧（bounce 0.15）作为唯一编排时刻；只动画 `transform / opacity / stroke-dashoffset`；`prefers-reduced-motion` 下关闭光点与弹簧。
8. **意图栏**：第一期只做搜索跳转与 CLI 同构指令（如 `codex deepseek/deepseek-v4-pro`），解析后调用现有接口，执行前显示将要发生的变化。自然语言解析不在本次范围。
9. **品质底线**：正文对比度 ≥ 4.5:1；焦点环、文本选中色、滚动条从色板取色；数字 `tabular-nums`；加载中用一句文字说明而非长时间骨架屏；空状态即引导。
