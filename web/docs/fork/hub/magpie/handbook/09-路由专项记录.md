## 3. 家族打法与教训

- **嵌套组兄弟面序列**：#2246（firstToken，被自修）→ #2255（Sink，合入）→ #2259（Affinity，在途）→ #2410（Patience，合入）→ #2407（rotate，合入）——同一棵递归组树逐面摘，是台账「新报告兄弟面核对」打法最成功的一片。组语义一行改动必须 rg 全部递归消费点，Sink/Patience/firstToken/Affinity 判定同步改。
- **在审区风险**：路由是维护者重写最活跃的区域（10-15 P3 插件化 `b1d02fa6`/`af9bd6c3`，10-17 compaction `bf931f82`）。接路由单先重读最新架构与 LESSONS（七问第 5 问）；在途的 #2259/#2471 落地前先对照新架构确认仍成立。
- **构造证据的边界**：路由行为的「确凿证据」优先用假上游走完整网关链路（#2255/#2410 先例），纯读码推断（如 #2187 前我方定位方向对但实现被并行的更收敛修法取代）只值一半。
