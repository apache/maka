# 11-狩猎轮机制（2026-11-06 定版）

> **机制热改原则（用户定版）**：本文件与 magpie-hub/AGENTS.md 狩猎节由主线程**随时可改**——变更只对新派任务书生效；在跑子智能体按开工任务书快照继续，**主线程任何变化不影响子智能体干活**。改机制不动任务书，改任务书不追在跑车道。

## 车道机制

| 条目 | 规则 |
| --- | --- |
| 车道数 | **3 干活编制**：2 子智能体 + 主线程亲自下场（用户 11-06 令）；主线程先扩池验收，车道清空即下场做单 |
| 续派 | **谁回笼谁续派**：完成通知 → 主线程验收（PATCH 回读+落账）→ 立即从续作队列头补派 → 车道保持满转直到当轮目标 |
| 目标 | 每轮累计接单数由用户定（如 20 单）；按单号去重计数（rework/rebase=new head 非新单） |
| 分工 | 主线程=扩池、验收、记账、对账 + **亲自接单做单**（与子智能体同流程同纪律）；子智能体专注任务书 |
| 隔离 | 子智能体只按开工任务书干活，不读候选池/编年热区；主线程记账不回写车道产物 |

## 选单正典

1. **先 take 后做**：认领评论一个词 `take`（本仓无认领机制，交付速度是护城河；占坑防抢）
2. **非 yetone 单**：维护者亲单不接（2026-10-25 用户令——他自己跟踪自己修）；派单前按 author 过滤
3. **只挑擅长族 + 档位（2026-11-14 用户定版：专注档一）**：
   - **只接一（丢数据/丢账号）**；**禁接二（用户可见错误/计费/缓存）、三（UX/文字/展示）、四（只动测试）的新单**——存量在途（含档2 104 单）继续等审与保鲜，不新增投入。（沿革：2026-11-10 定版为「优先档一、其次档二按影响人数、禁三与四」；2026-11-14 收紧为只接档一。）
   - 档一内部按擅长族排：gateway 数据丢失/状态覆写、rest 与状态绑定、账号/凭据语义（登录态/同步/导入导出）、持久化文件写路径（读失败/覆写/迁移）；排除纯 feature 提案、纯 UX 抱怨、无数据面的问题报告——triage 时如发现实为档2/3/4 面或纯咨询，按出列/转档处置，不硬凑档1。
4. **派前排雷五查**（2026-11-07 由四查升级，hunt-20261107 两实战判例）：①评论数与逐条扫描（take/Taking/will open a PR=占坑）②收编形态（Landed as/in、It is ggbdpq's、「v0.1.xxxx (sha)」开头——限维护者末评）③open PR 正文 Fixes #N ④`git log --grep` 单号 ⑤**同域 log -S/`--grep` 域词扫描+正文逐链接核 fork fix**——⑤防两形态：无声收编第三形态（提交主题无单号+issue 零评论，单号 grep 与末评双双失效，#5573 被 `140efc8f7` 于 v0.1.2379 修复实战）与报告者自带 fix 藏 issue 正文（零评论零 PR，#5576 报告者 `a29faee3` 实战）。grep 数字命中须逐笔核 body 排除数字巧合（sha 片段/消息 id 等）

## 三查铁律（每单必做，Watched 退出路径）

1. **消融回红**：先提交再消融、只回退产品文件、基线=分支父提交、变异点放语义分叉行、原输出逐行看
2. **兄弟面 rg 全查+举一反百**：同名判定全部调用方逐个对比，改/不改都写理由；**修一及百（2026-11-14 用户令）**——同族全量清单随交付产出，能修的一并修（series 或相邻交付），暂不修的每面给处置方案，不留无方案的 Left（判例：#3254/#4258 的 Left 面成了维护者自开的 #6601/#6602，见 handbook/10 #26）
3. **失败读取语义**：每个读文件的改动回答"读不到变成什么"

## 署名铁律（2026-10-25 用户定版，全 fork 通用）

交付必带：commit author=ggbdpq + patch 帖 Attribution + `Generated-by: GLM-5.3-Flash (ZCode)` 尾注；提醒/允许报告者保留其署名（合作单 Co-authored-by 双 credit）；**不白白替别人打工**。

## 池子维护

- 正典文件：`journal/账册/候选池.md`（新队列按日期分区追加在顶部；接/弃/收编后更新处置列）
- 主线程每轮先扩池：open 池全扫 → 初筛入册（优质=复现步骤/日志/量化数据/代码级分析）→ **池子 ≥ 目标单数 + 淘汰余量**（排雷会淘汰）
- 产物落位：`issues/hunt-YYYYMMDD/`（日期式，2026-11-06 规约）

## 交付与验证

patch 附 issue（禁 PR）+ 验证矩阵（定向+改动包全量+race 相称+gofmt+vet+build；没跑的列 not run 不谎报）+ GET 回读；git 2.50.1 用 `format-patch -1 --zero-commit`；push 显式 SHA refspec。细节按 fork 层 AGENTS.md 与 magpie-hub/AGENTS.md 接单开场节。
