# 单均成本与采纳统计

> 建于 2026-10-19（hunt46 当轮）。目的：逐单记录三件事——**耗时**、**token 消耗**、**交付后需要补几轮 patch 才最终通过**。只统计 2026-10-19 起采用「主线程派单 + 子智能体执行 + 主线程复核发布」模式的单；更早的历史单（hunt2–hunt42）不回填。
> 更新规则：每次维护者回合（review 意见 / 合入 / 关闭）后，更新对应行的「补丁轮数」和「状态」，必要时在备注追加一行事实。状态枚举：待审 / 修改中 / ✅ 合入 `<sha>` / 重写合入 / 被拒 / 撤回。

## 列定义

- **耗时**：子智能体从派单到最终报告的墙上时间（Agent 工具的 `duration_ms`）。主线程复核与发布的时间未计入（发生在并行收口阶段）。
- **token**：子智能体最终报告的 `subagent_tokens`（含其全部工具往返）。主线程的消耗未单列。
- **补丁轮数**：自交付帖起算，需要我们追加的 patch/说明轮数（0 = 一发即合）。「待审」期间先记 0。
