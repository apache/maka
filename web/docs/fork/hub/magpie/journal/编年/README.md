## 追加规则

- 新轮次追加到**当日分册**（`2026-10-DD.md`）末尾；当日没有分册就新建一个，并在下表加一行。
- 历史内容只追加更正，不把旧状态改写成今天的状态；更正写在当日分册里并注明更正哪一天的哪一节。
- 单个分册超过约 80 KB 时，按轮次（`##` 节边界）拆成 `2026-10-DD-a.md` / `-b.md`。编年日分册（lint 跳过）适用 80 KB 例外；通用分卷阈值 45 KB 见 [handbook/10 §1](../../../../handbook/10-文档维护与结构.md#1-三条原则)。先例：2026-10-17、2026-10-25（保留原文件名为前半、拆出 `-b`，2026-11-07 执行）。
