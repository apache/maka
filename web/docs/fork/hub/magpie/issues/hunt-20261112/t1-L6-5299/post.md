Mapping your 31 events against main (`f6c882ad7`): your ask 7 — reuse the session's own recovery instead of unconditionally resending the whole history — **landed upstream today**, and one more of your buckets has a partial fix. The rest is design space I'd not patch from the side.

**Auto-update restart → full retransmit** (your 5 losses within 15 minutes of a restart, and the general "new process + full history" mechanic): as of v0.1.3899 (`531b27783`, #6292, landed today), when the gateway ends it shelves every idle Claude Code run to `claude-shelf.json` — per conversation the session id, project folders, account, tools and cache marks — and the next gateway starts Claude Code with `--resume` and feeds it the new turn alone, instead of the whole transcript (~100k cache-write tokens on a long conversation). A shelf that doesn't parse, another version, a missing session file or a non-project folder falls back to today's replay. Runs still inside a turn (or parked on tool results) when the gateway stops are deliberately not shelved — so your "interrupted mid-turn" buckets (the 8 insert-interrupted and 8 client-cancelled) are outside this fix by design.

**The work-folder trust prompt** (your 1 event): magpie writes `hasTrustDialogAccepted` for its own work folder into each saved account's `.claude.json` (`ClaudeTrustFolder`, #4830) — but only into directories of magpie's saved accounts, never the user's own `~/.claude.json`. A remote CLI running on the user's own config still gets asked, which matches your 45-second timeout in an unattended session.

**What remains design space** — your asks 1-3 (lifecycle across interruptions, request serialization, cancel semantics that don't drop the whole conversation) and 6 (diagnostics: session↔process mapping, why-logged, retransmit reasons) are the maintainer's to weigh; ask 4 (restart protection) is what the shelf now does for idle runs, ask 5 the trust write above, and ask 7 the `--resume` reuse. Ask 6 in particular would have made your 12 "cause beyond log retention" rows decidable.
