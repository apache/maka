## 每单 SOP（刷新轮适配）

1. **实时排雷**：gh 读该 issue 全部评论至末页（created_at 一律 UTC+8 换算）。三查收编信号（**lower+contains**）：
   - 维护者（yetone）末评含 `landed` / `fixed in` / `v0.1.` 开头版本号 / `Landed as`；
   - `git log upstream/main --grep="#<N>"` 有 yetone 署名提交且语义等价覆盖；
   - 单已 closed。
   命中任一 → **不 rebase**，发简短英文出列帖（列三查证据），该单记 OUT，跳到下一单。
   有维护者/reviewer 的新修复建议或问题 → 在 rebase 时一并落实/回应（这是本轮"完善"的核心），帖内逐点回应。
2. **自建 worktree**（只碰自己车道的分支）：
   `git -C <主仓> worktree add /tmp/mg-1110-<lane>-<n> -b <branch> origin/<branch>`（本地分支在则用本地名；分支名以任务书清单为准）。
   完成后 `git worktree remove` 自清。
3. **rebase**：worktree 内 `git fetch upstream`（实时）→ `git rebase upstream/main`。
   - 冲突逐 hunk 裁决：保上游新语义 + 我方修法并集；上游已等价实现的部分让我方 patch 让位；裁决逐条写入帖。
   - rebase 后在新基点重验。
4. **测试（六要素之"实名绿"）**：从该单我方 PATCH 帖提取实名测试清单（原帖都列了），新基点全部重跑必须绿。没列就 rg 该单新增测试名。命令形态：`GOCACHE=/tmp/mg-verify-<lane>-gocache go test -tags nogui -count=1 -run '<TestA|TestB|...>' ./internal/... -timeout 10m`。并发改动加 `-race`。
   预存红对照（父提交同样红才算环境项，帖内照列）：`TestMothX` / `TestLaneLimitRoutes` / `TestProxyCheckSaysAProxyPassedBy` / `TestHostToldTheGatewayAddress` / `TestPluginCheckinAsksAgainAtUntil`（仅 -race 间歇）。GUI 引擎差异跑不了=NOT-RUNNABLE 如实标，不硬跑。
5. **消融（回红）**：**在新基点重做**。变异=摘修复逻辑 hunk（字段型摘 continue/if 分支等），**禁止整文件回退**（build failed 假红判例）；test-only 单=断言回退修复前形态。变异后 `git diff --stat` 复证变异生效 → 跑实名测试应红 → 还原 `git checkout -- <files>` → 复绿。
6. **兄弟面（同族全查）**：rg 该修法的同族调用点；**重点比对 `git log --oneline <旧base>..upstream/main -- <同族文件>`**——上游这批新提交动过同族文件的逐点复核我方 patch 是否仍完整成立；改/不改逐点写理由。
7. **实证**：该单原帖的复现形状（fixture/假上游/探针）在新基点重放；真机才能跑的如实标 NOT-RUNNABLE（引用原帖已有实证+新基点 fixture 证据）。
8. **git am 即进验证**：`git format-patch -1 --zero-commit -o /tmp/mg-1110-<lane>/` → 在**干净检出树**（另一 worktree checkout upstream/main）`git am <patch>` 必须零冲突成功 → `shasum -a 256 <patch>` 取前 16。
9. **push**（显式 sha refspec，全部实时取）：
   `git push origin $(git rev-parse HEAD):refs/heads/<branch> --force-with-lease=<branch>:$(git ls-remote origin refs/heads/<branch> | cut -f1)`
   注意本地分支可能不存在（远端权威），lease 旧值必须 ls-remote 实时取。
10. **发帖**（英文，handbook/03 纪律）：`gh issue comment <N> -F /tmp/.../body.md`（**-F 非 -f**；body 含 `\u0000` 或 >30KB → 贴 fork `.patch` URL 形态 `https://github.com/ggbdpq/magpie/commit/<sha>.patch`）。刷新帖格式：
    ```
    Rebased onto current main `<sha12>` (<date>). <零冲突 / 冲突裁决逐条>
    Tests re-run on the new base: <实名清单> — all green. (-race where applicable)
    Ablation re-done on the new base: <变异点> → red → restored → green.
    Sibling scan vs <旧base>..tip: <结论/逐点理由>
    Fresh patch: `git am` ready, sha256[:16]=`<hash>`; branch: `<link>`; <NOT-RUNNABLE 如实项>
    <对维护者/reviewer 新评论的逐点回应，若有>
    Generated-by: GLM-5.3-Flash (ZCode)
    ```
11. **回读**：`gh api repos/yetone/magpie/issues/<N>/comments --paginate` 列表端点取末条，比对 author/字节（单评论端点 404 假象判例）。
12. **落账**：产物（patch 文件/body.md/测试日志/消融日志）写 `docs/hub/magpie/issues/hunt-20261110/<n>-<slug>/`；**编年/claims 由主线程统一写**，车道在回报中给出每单结果行即可。
