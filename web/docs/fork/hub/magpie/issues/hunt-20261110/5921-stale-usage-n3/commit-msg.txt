provider: a re-login for a Claude account gives way the allowance the sign-in before told (#5921)

Claude Code's /usage is run by magpie, never Anthropic asked, and what
it told is kept per account in claudeUsage for the Usage page's timer,
the switch list and routing. The keeping knew no credential: a re-login
for the account Claude Code is signed in to — a plan move on it, a Max
5x upgrade — swapped the tokens under a kept reading, and the reading
served on. On a headless `magpie serve` (delete-cloud) the card said
`plan: max` — the plan is read with the credential, fresh — while its
windows stayed at the sign-in before, `7 days: 100%`, for some 45
minutes, though the account's real allowance was 0% on every window and
a separate `magpie accounts` process had written a fresh reading to
quotas.json meanwhile: the kept entry's hearing stood newer than that
disk reading (withHeardClaude), and nothing unasked re-read — no local
session .jsonl a gateway that only proxies would write, no qualifying
rate_limit_event — until a hand refresh.

A sign-in for an account can only change what was told of it, so now
the keeping knows what told it:

- A reading keeps the sign-in it was told by (claudeCredMark, a digest
  of the live credential's access token), and claudeWindows, before it
  lets the account Claude Code is on serve what is kept, drops a
  reading told by another sign-in of the same account: the next look
  reads again, on the new plan's allowance. A move to another account
  takes nothing away — the reading kept is that account's own, and it
  stands for it while Claude Code is signed in elsewhere (moved off,
  nil_1024). Kept under the old code with no mark at all, an entry is
  another sign-in's to the fix as well: a gateway already holding the
  stale reading is re-read on its first look after the upgrade.
- A sign-in magpie made itself (addLogin, and the switch that puts a
  saved account's sign-in on Claude Code) now drops the account's kept
  allowance with the folder's older sign-in it already gave way

  plan before; what Claude Code said as it answered is stamped with the
  sign-in that said it too.
