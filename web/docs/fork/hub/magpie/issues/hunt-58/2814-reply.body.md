On opening a PR: I can't — this repository takes pull requests from collaborators only, so outside patches stay in the fork-patch form. Concretely: [`hunt44-a-sessions-steady`](https://github.com/ggbdpq/magpie/tree/hunt44-a-sessions-steady) carries the one commit on top of upstream `95ef45fda4b3`, and the format-patch in my comment above applies with `git am` as is. Authorship survives the apply the same way it would through a PR — the commit's `From:` keeps ggbdpq as the author, or a `Co-authored-by:` line works too. If a collaborator would rather land it through a PR, the branch is there to be picked up as is.
