## 根因

Responses→Chat 转换中 `searchRoundsBack`（responses.go）对无 Claude signed thinking 的消息执行 `DeleteFunc(isSearch)`——解析阶段保存的普通 `web_search_call` 历史（query+sources URL）被静默删除，Chat 上游读不到已执行搜索的历史 → agent 长会话反复搜索反复"复核"。

## 修法

普通搜索历史转 assistant 文本（`Searched the web for: <query>` + `Pages found:` + URL 列表，共用 `searchSaid` 助手）；不造孤立 tool call（无配对结果）；不造搜索正文（输入里没有的正文不编造）；signed thinking 重建分支逐字节不变（ToolResult 文本改由同一助手产出）；无搜索项请求不进函数。
