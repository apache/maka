## 核心证据链（帖内要点）

1. **错误串非 magpie 生成**：`Unsupported credit amount/currency: £225.52 (billing account … is read in USD; supported: USD, JPY)` 在全仓全历史零命中（`git log --all -S "Unsupported credit"`、`-S "credit amount"`、`-S "supported: USD"` 全空）。magpie 自有余额错误均为小写自有措辞（"no balance in the reply"、"the reply is not JSON"，internal/provider/balance.go）。
2. **GUI 只是透传**：allowance 卡前缀 `t("Allowance unavailable: {why}")`，{why} 是读取失败的原始错误（internal/gui/assets/app.js:13686、:13735，各截 160 字符）。
3. **magpie 无货币白名单、不拒 GBP**：Balance URL/Path 任意金额；`readBalanceOne` 接受 `$¥€£` 前缀（balance.go:831）；DeepSeek 读取器显示 vendor 列出的每种货币，`currencySign` 对未知码返回 `"GBP "` 前缀（balance.go:294-303）不拒绝。
4. **结论**："supported: USD, JPY" 是报告者所用 vendor billing API 的限制（GBP 计价 billing account 被拒），magpie 如实显示。typed balance（v0.1.3281 f8525323d，11-08 引入）晚于本单（11-06），非同一面。
