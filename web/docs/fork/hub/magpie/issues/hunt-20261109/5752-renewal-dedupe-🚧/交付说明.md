## 修复摘要

共享根因 = `internal/plugin/host.js` 的 `renewLocked`(续期结果的判定/回写处),三刀:
1. `auth.refresh` 给回非 object → 记 `unrenewed` 退避(`gone:false`, error:"")+ 一条 error log(旧代码无退避,每次使用都重试)。
2. 合并后的 sign-in 仍 due(`renewAt(a,next)` 已过)且没带来新 token(`!changed(next,was)`)→ **不保存**(保存只会触发 changed() 全量重列)、记退避带原因、log。
3. 仍 due 且有新 token → 照旧保存(auth 事件照发),然后记退避(按新 secret),30 秒内不再重放。
不再 due → 原行为不变。Go 侧零改动(keepalive 的 `r.Due && !r.Renewed` → `keepAliveBackoff` 分支已覆盖 host 现在报告的 waiting/error 形状)。

失败读取语义:读不到续期结果(undefined)= 这一次没续成但无错误可说 → 30s 退避、不标 gone、不保存、每次尝试一条 log。
