## 失败读取语义（本单核心是检查与消费脱绑，方向=绑定+fail-closed 终止）
- stillExpiring 读失败 → ("", false) → 不花（与修复前 err→false 一致，check 计划重试）。
- 所查卡消失（held false）→ 有名错误上抛 → spend() err → `e.next=retryResetLook` 5 分钟内重评，不静默不换卡。
- Each 缺失（len(Each)!=Count）→ credit="" → 旧行为保底：该态下 Until 与列表同源，风险窗口不扩大；做成"拒绝消费"会让计数不一致的账号永远不自动用卡（行为回退），取舍记录在案。
- 热路径代价：expiring 是 5-30 分钟粒度后台循环，非请求热路径；每 pass 多传一个字符串，零额外 IO。
