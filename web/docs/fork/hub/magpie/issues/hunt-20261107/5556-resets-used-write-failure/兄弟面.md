## 失败读取语义（本单核心是失败被吞，方向=fail-closed 有名错误）

- noteResetUsed 返回 error 后，唯一调用方只 log 不上抛——**这是刻意的 fail-visible 而非 fail-closed**：消费已发生，上抛会把部分成功伪装成可重试失败（报告者红线），readResetsUsed 的解析失败走 copy-aside 防覆盖（既有语义）。
- 热路径代价：仅 `out.Code == "reset"` 成功路径多一次 error 返回与（仅失败时）一条 log，零额外 IO，无热路径代价。
