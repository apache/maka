# #5556 根因与修法：Codex 用卡记录写入失败被静默忽略

单况：OPEN，报告者 cgsme（2026-11-06），零评论，无 open PR，无交叉引用，同域 log/-S 扫描无收编（codex_resets_used.go 自 4795f5646 初建后仅 #2017 e297a8ab2 触碰读语义，写路径无人动）。

## 根因

`noteResetUsed`（internal/provider/codex_resets_used.go:82-105 @ 665b9aff1）无返回值，主写入两处丢弃错误：

```go
_ = os.MkdirAll(settings.Dir(), 0o755)
_ = steady.WriteFile(resetsUsedPath(), append(b, '\n'), 0o600)
```

唯一调用方 `spendCodexReset`（internal/provider/codex_resets.go:307 @ 665b9aff1）在 `out.Code == "reset"` 后调用它并继续返回成功 `ResetOutcome`。磁盘满/权限/路径异常（如 codex-resets-used.json 被建成目录）时：服务器消费已完成、调用方收到成功、用卡历史无记录、零日志。

调用链（全量枚举）：`UseCodexResetCard`(hand,指定卡)/`useCodexReset`(空卡) → `spendCodexReset` → `noteResetUsed`；`useCodexReset` 上游 3 个：`UseCodexReset`(hand)、`SpendExpiringCodexResets`(expiring)、`AutoUseCodexReset`(week)。

## 修法（following the reporter's own analysis，对称于上游 #2017 先例）

1. `noteResetUsed` 返回 `error`：`os.MkdirAll` 失败或 `steady.WriteFile` 失败时返回有名错误 `keeping that a reset was used to <path>: <err>`。readResetsUsed 失败后的 aside 备份保持 `_ =`（原语义，次级防线，报告者未主张）。
2. `spendCodexReset`：`if err := noteResetUsed(...); err != nil { log.Printf("Codex reset of %s spent, but keeping the record of it failed: %v", user, err) }`——**只 log，不改变返回值**。

取舍：
- **不把记账失败变成可重试消费错误**（报告者红线）：卡已在服务器花掉，若 err 上抛，Usage 页/CLI/gateway 调用方会把本次视为失败，用户重试=再花一张卡。形态对称于上游 #2017 对 `codex-autoreset.json` 的 `save()`（codex_autoreset.go:336-348：写入失败 log.Printf，不改 spend 成功语义）。
- 报告者"在适合的调用路径提示用户"：最小实现取日志可见（与 #2017 同级）；页面级提示牵动 gui 层，超出最小面，留维护者定夺。
- 消费只调用一次：修复后语义不变（记账失败不重试 consume），测试以 consumed==1 锁死。
