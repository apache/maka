## 4. 两端合并观察

1. **判定一致性**：同一 "a hard task" 意图在两端、两个不同的真实分类器（deepseek-flash / deepseek-v4-flash）下均正确命中规则 1 并指向正确成员——GUI/CLI/本地自算三条入口走的是同一 `turnDecide`，无分叉。
2. **A1 是 macOS 改键时的回归**（归因如实）：修键撞车时把 i18n 键 `"Try"` 改成了 `"Try these rules"`，但编辑器分区标签仍调 `t("Try")`——键已不存在，四语言裸露英文。macOS 的 UI 测试断言了按钮和占位符、没断言标签，所以没拦住；Windows 真机肉眼抓到。**修复建议**：标签复用 `"Try these rules"` 键，按钮换一个新短键（词由你定，如 "Try them"/"Run the try"，改完必须过 i18n-keys 守卫——短键易撞子串）。
3. **A2 布局缺陷**（Windows 发现、已修复闭环）：宽窗下结果块被挤进 72px 标签列。修复 `.rt-gedit > .hint { grid-column: 1 / -1; }` + 布局断言（结果宽 ≥ 输入行宽 ×0.9），TDD 红（72px vs 732px）→ 绿；触及组编辑器的 17 个回归文件 116/116、i18n-keys 3/3；真页面复测 989px/353px。**WebKit 缺口本次已在 macOS 补跑：16/16 绿。**
4. **A4 语义校准**（记录措辞以实测为准）：Routing 页 trace **会**显示判断调用行，但带独立「路由分类器」徽标并标明非对话轮次、$0.000；用量记录 GUI 路径为 `agent=magpie, kind=routing`，server 路径 UA 派生为 `magpie-router`——均为 magpie 自有调用，措辞统一为「magpie's own」最准确。
5. **真实模型行为观察**：单意图组下小模型倾向答 1（macOS 侧 "hey, what's up?" 被判 hard task 一次）；A3 的「"X 中的 X"」句式冗余会放大这个观感。两个开放项相关，可一起定。
