# catalog, provider, sessions, cli: a Claude model's 1-hour cache write is 2× input only at Anthropic's (#3435)

## Summary

Copilot bills a Claude model's 1-hour cache write at its 5-minute price and its list names no 1-hour one (claude-opus-5.5: $5 per million, whatever the TTL). `catalog.OneHourFor` filled a Claude model's missing 1-hour price as 2× input for every provider alike, so `copilot/claude-opus-5.5` was priced $8/M for an hour's write: on the issue's third request magpie recorded $0.125456 where Copilot charged $0.078443, and a long session's first 1-hour write was recorded $3.74 against Copilot's $2.35. The 2× input is Anthropic's own charge, so the fill now applies only to a price of Anthropic's. A test built on the issue's own numbers fails on the parent (1h = 8, the call at $0.125456) and passes here.

## What changed

`OneHourFor(provider, id, p)` fills 2× input only when the price is of Anthropic's: the maker's list, a Claude Code account's (`claude`), or one no provider is named for — those fall back to the maker's list, so the bare-id and any-provider prices keep today's rule. The catalog build passes the models.dev provider id, so only the maker's own entries are filled and every provider's list price stands as it lists it; the four callers each pass what they know: the catalog build the provider id it is reading, `provider.priceOf` the id of the user-priced provider (or none for a `*/model` key), and the sessions and CLI any-provider reads none, since a bare id is billed at its maker's.

Not changed, on purpose:

- Anthropic everywhere keeps 2× input: its own list entries, the maker's entries every fallback reads, a Claude Code account's list, a user price on `anthropic/…` or `claude/…` without a 1-hour part, and a price given for the model from any provider.
- A price that already has a 1-hour part is never touched, whoever it is for.
- Tune is untouched. Its replay reads agent files, which name the model but not whoever served it, so neither `WeightsFor` by provider nor a replay at `provider.EffectivePriceIn` has the data it needs; a name that already carries a provider (`copilot/claude-…`) already takes the non-Anthropic weights. Recording who served each call is a bigger change than this issue needs. The report's side note — `tuneOf` replays only the `claude` and `codex` agents, so Claude Desktop's Code tab gets no advice — stands as an observation.
