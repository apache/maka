## 任务书必含（每单一份，主线程拟）
1. 读全 issue+评论+tip 代码；先列 3-5 假设排序；让位闸复查→出列或做。
2. take 占坑：`gh issue comment N -R yetone/magpie -b "take"`（竞速敏感单先 take 后读料）。
3. TDD：`grep -n '^func Test'` 取精确测试名（错配=假绿）；RED→最小修复→GREEN；**消融前先提交**（未提交先消融=checkout 清掉工作树修复，本会话 N 现）；消融=只回退产品文件（测试留着，测试引用新符号时拆行为测试到独立文件保编译），基线=**分支父提交**（非旧上游 SHA），输出看原文。
4. 矩阵：定向+改动包全量（`go test -tags nogui -timeout 25m`）+race（流式/并发必跑）+gofmt -l+vet+`go build ./...`；预存红如实标注（TestCodexPoolSaysTheClientsVersion/TestMothX/TestEveryRouteHasACommandOrIsNamed/TestProxyCheckSaysAProxyPassedBy/TestHostToldTheGatewayAddress/TestPluginCheckinAsksAgainAtUntil/ dockflap cgo warning）。
5. Watched 三查：兄弟面 rg 全查列改/不改（含「该不该走同一个口」的收口之问）；读失败语义；热路径代价。
6. **全链路发布门（用户定版 11-04）**：实际 rebase 到当前 main（3way am --check 实测）+ git am 即进；分支、sha256、测试、消融回红、兄弟面、实证（真实路径复现）**全部落在 issue 里可核查，缺一个不准说完成**。
7. commit：`git -C <worktree> -c user.name=ggbdpq -c user.email=ggbdpq@gmail.com commit -F <msg文件>`；subject 仓库风格小写祈使句；尾注 `Generated-by: GLM-5.3-Flash (ZCode)`。对外零中文；临时文件私有路径（mg122-* 命名防车道相撞）。
8. 发布（&&门控禁 ;;）：push→ls-remote 核对 SHA=帖中 head→format-patch 副本落产物目录→sha256 前 16→帖（Write 写文件禁 heredoc）→`gh issue comment N -R yetone/magpie --body-file <文件>`→GET 回读。POST 失败先 GET 核实绝不重发。

## 帖形态（五段+三件套）
- 五段：What's wrong / Root cause / The fix（patch 折叠块+SHA-256 first 16）/ Verification（表格行间禁空行）/ Not verified+AI use。
- 三件套：①`**Attribution**: AI-written; I've read the whole diff and the tests pass. Please keep the author (`ggbdpq`) or add `Co-authored-by: ggbdpq <ggbdpq@gmail.com>.` ②patch 折叠块（`git am applies it as is; SHA-256 first 16: <hash>`）③`**Branch with the commit**: [<分支>](https://github.com/ggbdpq/magpie/tree/<分支>) (head `<full SHA>`).`
- **credit 是第⑨查**：发帖前 grep 报告者实名（本会话四单漏 credit 全 PATCH 补齐——占位符/漏名/漏 AI 披露都犯过）；PATCH 评论用 `--input JSON 文件`（gh -f/-F 不展开 @file 二现）。
- AI 披露帖内可见一次：嵌 patch=尾注承载、Attribution 以 AI-written 起句；判定帖=尾部 `AI use: ...`。
- 判定帖出口：Q2 钉不死/设计拍板/方案先行→英文判定帖（take 后发：机理+判定表+两案留维护者+Not verified+AI use）。
- **主线程主单原型打穿既有契约时**：回滚（revert）+判定帖（原型/回退对留分支作证据+正确形状描述+两案）——比硬交打穿 failover 的 patch 有价值（#4166 判例）。
