## 铁律（违者必踩，全有判例）

- 本地分支可能落后 origin 正本——开工 `git reset --hard origin/<branch>` 对齐再 rebase。
- `--force-with-lease=<ref>:<oldsha>` 冒号语法（= 分隔不生效）；shell 环境吞 refspec 字符——关键参数一律加引号。
- 包全量必带 `-timeout 45m`（默认预算 panic 属跑法参数非产品红）。
- 单评论 API 端点 404 假象——发帖后与回读一律用 issue 列表端点；POST 结果不明先 GET 核实绝不重发。
- range-diff `=` 为零漂移判据；patch sha256 变≠漂移（上下文行变是常态）；patch-id 不等≠未收编（上下文漂移时比纯 +/- 行）。
- 消融红会随上游吸收变形（门/上限类）——退门不红≠测试无牙，用更低旧门取红+帖内如实披露。
- 派 rework 前重读 issue 末评——防报告者按 spec 自交付撞车（#6288 判例）。
- 复验先读原帖拿定向测试名/消融形态/兄弟面/实证形态；author 保留（背书单名单见台账）；不接维护者亲单（#6601/#6602/#6734=兄弟单例外）。
- 独占 worktree+唯一日志（/tmp/mg-<轮>-<单>.log，输出落文件禁 | tail）；验证进行中禁动同 worktree。
- 文档纪律：编年只追加禁改历史节；audit1/账册/编年=历史归档禁删禁打包；**每次问询刷新 draft/hunt/README.md「当前状态」节**；文档改动后 fork 根跑 `python3 scripts/docs_lint.py` 清零。
- 本地记录中文、issue/commit 英文；不自动 commit/push 文档；推文用户自己发，你不发帖不催。
