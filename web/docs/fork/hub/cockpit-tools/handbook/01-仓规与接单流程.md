## 仓库身份

| 远端 | 地址 | 用途 |
| --- | --- | --- |
| upstream | jlcodes99/cockpit-tools | 项目本体，PR 目标 |
| origin | ggbdpq/cockpit-tools | 我的 fork，PR 分支推这里 |

- 默认分支 `main`，PR base 一律 `main`。**维护者修复极快**——动手前必重新复查 issue 是否已被上游修掉。
- 分支命名遵 [12 §命名规范](../../../handbook/12-通用纪律与执行声明.md)：`fix/<单号>-<slug>`（type 按性质），subject `fix(<scope>): <summary> (#N)`；老分支不改名。
- 无认领机制：0 评论 + 无 PR = 可接。
- **知识交集最强**：内嵌 CLIProxyAPI，对 [CLIProxyAPI](../../cliproxyapi/handbook/01-仓规与接单流程.md) 的全部积累直接复用（配置/网关/凭据语义）。

## 硬约定与 CI

- 首贡献者 fork PR 的 Build Matrix / CodeQL 是 **action_required**（维护者手动批准 workflow 才跑）——本机验证矩阵是唯一独立证据。
- 无 fmt 门禁；`include!` 分片文件本身非 rustfmt 规范——diff 按文件既有风格写。
