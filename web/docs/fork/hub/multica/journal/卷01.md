## #9024 时钟语义查证（2026-10-02 第三轮续，一手证据链钉死）

上轮"Windows QPC 睡眠前进"的**机制推理错了**（基于记忆引二手，M2 现世报），但结论歪打正着。本轮三步一手查证：
1. **Go runtime 源码**（sys_windows_amd64.s，master）：`nanotime1` 读 `_INTERRUPT_TIME`（KUSER_SHARED_DATA 页），不是 QPC——`MOVQ $_INTERRUPT_TIME, DI; MOVQ time_lo(DI), AX; IMULQ $100, AX`。
2. **微软 QueryUnbiasedInterruptTime 文档**："The unbiased interrupt-time count does not include time the system spends in sleep or hibernation"——unbiased 不含睡眠。
3. **同文档**："The system uses biased interrupt time for some operations, such as ensuring that relative timers that would have expired during sleep expire immediately upon waking"——**biased（= InterruptTime = Go nanotime 来源）含睡眠**。
