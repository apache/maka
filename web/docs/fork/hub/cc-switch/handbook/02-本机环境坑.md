# cc-switch 本机环境坑

> 2026-10-21 自项目 README 迁入（正文未改）；2026-11-08 增补 macOS 现役坑节（10-25~11-08 多轮实测沉淀）。

## macOS 现役坑（2026-11-08 定版，均实测）

- **cargo 一律 `cd src-tauri` 后跑**：Cargo.toml 在 `src-tauri/` 子目录，worktree 根目录跑 `cargo` 报 "could not find Cargo.toml"（#7814 轮实录）。rust-toolchain.toml 钉 1.95，见 [handbook/01](01-仓规与接单流程.md)。
- **worktree 前端验证先装依赖**：主仓 `node_modules/.bin` 为空（半截安装）不可借用；worktree 内 `pnpm install --frozen-lockfile --ignore-scripts --prefer-offline`（pnpm store 热，实测 ~2s）后才有 vitest/tsc/prettier。
- **拼接式冲突解的验证三件套（CI 有 `clippy -D warnings` 门，cargo test 不覆盖）**：`cargo fmt --check`、`cargo clippy --lib -- -D warnings`、`prettier --check`——三个都**单独跑、不接管道**（`| head` 吞 rc 假绿，#7781 轮 fmt 实录）；`#[allow(...)]` 标注不可拼进 doc 注释末行（吞行失效，同轮 clippy 实录）；前端侧手拼的闭合后缀会被 prettier 抓（#7857 轮实录）。本地没跑的检查一定会被 CI 逮住。
- **worktree 冷编译耗时**：`cargo test --lib` 首次 5-10 分钟——放后台跑，等 CI 的空档并行；第二次起增量秒级。
- **zsh/bash 数组与分词**：zsh 数组 1 基索引（`${arr[0]}` 为空→循环漏项）；zsh 里 `set -- $pair` 不分词，须 `${=pair}`；bash 脚本禁 `${=var}`（bad substitution 直接带崩脚本）——bash 侧一律索引数组。
- **gh/jq 杂项**：轮询 API 偶发空行/EOF，下轮自愈不重试；`run list --limit 1` 只看最新 run——同 head 多 workflow 时（如 Label PRs）不能当 CI 绿佐证，核 `workflowName`。

## 本机环境坑（Windows + Git Bash，已实测）

> **Windows 已退役（历史）**：本节为 Windows + Git Bash 时代的实测记录，主力环境已转 macOS，未在 macOS 上再核验，仅作历史参考（2026-11-07 标注）。

- cd 进仓触发 fnm 钩子截断 `&&` 链（cargo 命令前先 eval fnm env，否则 pre-command hook 报 Node 版本错误截断链条）。
- 切分支后 cargo 增量缓存可能指纹失配（rlib format 报错，挂在集成测试目标）——绕法：`cargo test --lib <name>` 只跑 lib 目标；验证分支相关声称用 `git show <sha>:<path>` 读对象，别信工作树（工作树可能不在你以为的分支上）。
- 前端侧 pnpm + vitest；`tsc --noEmit` 干净为门；预存失败用干净基线 worktree 对照定性。
