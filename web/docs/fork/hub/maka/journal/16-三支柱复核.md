## 执行配方(每单,自足)

1. **前置**:读台账本行+journal/12、13 该单原记录+PR body 与全量 commit 消息(files/commits API);产品文件清单从 PR files API 取。
2. **worktree**:共享仓 /private/tmp/maka-rv/repo(已 fetch upstream/main 1b7572848+fork 全分支,node_modules 软链到 maka-pr1,依赖补丁已应用);`git -C /private/tmp/maka-rv/repo worktree add /private/tmp/maka-rv/wt-<n> <PR head SHA>`;PR 若触碰 package.json/lock → 依赖面变化,消红降级标「未验(依赖面)」。
3. **消红(执行级)**:基线=**merge-base(head, upstream/main)**(多 commit PR 的 head^ 是 fix commit 本身,勿用——6403 实测假绿教训);`git -C wt-<n> checkout <merge-base> -- <产品文件们>` 还原产品文件保留测试→跑该单 Verification 表的目标测试(命令以 PR 自述+台账为准)→确认红且断言点名行为,原始输出落 /tmp/rv-exe/<n>-red.log 逐行读;恢复(`checkout HEAD -- <产品文件们>`)→绿,落 <n>-green.log。变异点必须落在语义分叉行(修复 hunk 本体)。本地无法经济执行的红载体(如 #6389 storybook 全量)如实标「未验」+理由,不硬凑。
   **环境坑(实测,持续增补)**:①worktree 用 /tmp/rv-exe/wt-init.sh <n> <sha> 建(局部 node_modules:第三方软链 maka-pr1、@maka/* 软链 worktree 自己的包——隔离正确,整根软链会让 @maka/* 解析进 maka-pr1 树使消红失效);②建后必须 `npm run sync:model-metadata --silent`(model-metadata.generated.js 是 gitignore 生成物)+ 按需 `cd packages/<x> && npx tsc -p tsconfig.json` 造依赖 dist(@maka/core/dist 缺=ERR_MODULE_NOT_FOUND 整文件挂);③macOS 无 timeout 命令,限时用 `perl -e 'alarm N; exec @ARGV' cmd...`;挂死型红(如 6403)本身就是缺陷证据,如实记形态;④**共享仓存在名为 head 的引用**——消融基线一律先 `git rev-parse <head>^` 打印显式 SHA 再用,小写 head^ 会解析到 fork main fa15e64fc(批次 B #6329 实测污染);⑤依赖 @maka/runtime 内部链的套件(如 #6386 compactor)需在 worktree 的 packages/runtime/node_modules 再软链→maka-pr1 同名目录(根 node_modules 的 v5 https-proxy-agent 缺命名导出会假挂);⑥根 node_modules 偏旧:runtime 包 tsc 有 10 个预存 TS 错(dist 照常产出,不影响运行)。⑦**gh api 发文件正文必须 `-F`(大写)**——`-f body=@file` 把路径当字面量发出(本轮三条 PR 声明评论实锤,6289 回读正文=path 字符串;用 `-F` PATCH 修正);核评论落帖勿用 per_page=3 首页(升序=最老三条)。
4. **兄弟面**:在 worktree 里 rg 同名判定/同型反模式/同函数两套标准,对照 PR+commit 已记录清单,漏的位置列 file:line。
5. **实证**:按 patch 判真实环境(SQLite/文件系统/host 进程)vs stub;stub 未申报→P2;时序/性能单必须有 benchmark 红证据。
6. **行号重核**:对 upstream/main 1b7572848 核触碰文件自分支基点后是否又被 main 改过(git log upstream/main -- <文件>),变了→行号漂移标注。
7. **判定与分级**:三项各给 过/补/伪;P1=消红不成立或修法错;P2=兄弟面遗漏或实证未申报;P3=表述/证据不全。
8. **收尾**:删本轮 worktree;子智能体把逐行结论追加到自己的批次报告文件(/tmp/rv-exe/batch-X.md),**台账统一由主线程写入**;主线程对 P1/P2 逐条复核后才入账。
