### ② 嫌疑链实测结论
- **(a) tabs-hydration 双格式水合 → 排除（探针 S4 绿证据）**：legacy→unified 是一次性迁移。legacy 输入 2 条重复记录水合折叠为 1 行，persist 后 unified 再往返行数不变。唯一副作用：迁移首刻 hydrateLegacyFormat 从 raw session 直接建 tab 可能写两个同 id tab（`id=filePath`），但下次 hydrate `dedupeTabsById` 折叠——一次性尘埃，不是增长环。
