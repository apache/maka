验证 release

以下命令校验最新版本。校验历史版本时，请替换路径中的版本号。

第 1 步：导入 release manager 的公钥
curl -O https://downloads.apache.org/incubator/maka/KEYS
gpg --import KEYS
第 2 步：校验签名
curl -O https://downloads.apache.org/incubator/maka/0.2.2-incubating/apache-maka-0.2.2-incubating-src.tar.gz
curl -O https://downloads.apache.org/incubator/maka/0.2.2-incubating/apache-maka-0.2.2-incubating-src.tar.gz.asc
gpg --verify apache-maka-0.2.2-incubating-src.tar.gz.asc apache-maka-0.2.2-incubating-src.tar.gz
第 3 步：核对校验和
curl -O https://downloads.apache.org/incubator/maka/0.2.2-incubating/apache-maka-0.2.2-incubating-src.tar.gz.sha512
shasum -a 512 -c apache-maka-0.2.2-incubating-src.tar.gz.sha512
