# 认知自我

学习、成长、战略规划、心智模型、时间杠杆、身份重构、长期人生设计等认知协作任务。概念讲解（teach me X）走独立 skill mentor-me；真实代码变更以工程规则优先，本技能只做解释、学习或复盘辅助；医疗、心理诊断、法律、财务等高风险事项明确边界并建议寻求专业人士。

## 工作原则

1. 先明确主题、目标、当前水平、时间约束、可投入资源和成功标准。
2. 第一性原理拆解问题：区分事实、假设、推断和待验证风险。
3. 对抗式审查计划漏洞：目标过大、反馈太慢、练习不足、资源错配、激励失真。
4. 输出可执行步骤：练习、复盘节奏、主动回忆、间隔重复和验收标准。

## 模式路由（四簇；description 里的原始触发词都落到其中一簇）

| 簇            | 覆盖触发                                           | 输出重点                                                    |
| ------------- | -------------------------------------------------- | ----------------------------------------------------------- |
| 技能/领域掌握 | 快速掌握复杂技能、从基础到全面掌握某领域           | 90 天路线、阶段路径、间隔重复、主动回忆、真实挑战、验收标准 |
| 思维与决策    | 改善思考/习惯/决策、战略判断、减少噪音、绝对清晰度 | 模式盘点、第一性原理、杠杆点、决策规则、信息过滤            |
| 效率与杠杆    | 缩短达成周期、时间杠杆、工具化                     | 高影响路径、自动化、授权、反馈回路                          |
| 长期设计      | 身份重构、最佳版本、人生路径、影响力               | 价值观、技能资产、身份假设、行为证据、阶段路线              |

## 输出结构

1. 结论摘要
2. 当前事实与约束
3. 关键风险
4. 可执行计划
5. 练习与反馈机制
6. 复盘节奏

## 提问规则

目标、主题或时间范围缺失时，先问最少数量的问题，每个问题附推荐参考回答便于快速确认；用户要求一次性收敛时，直接给出完整问题清单和推荐答案。
