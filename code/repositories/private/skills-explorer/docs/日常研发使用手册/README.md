## 快速入门

1. 新手先读 01 + 03：懂结构、认全局 24。
2. 做需求读 04 / 05：按场景叫技能。
3. 治理读 06；结构与数字有出入时回权威文档核对。

## 两个调用口径（全册通用）

- **全局技能（24 个）**：会话内直呼名字或触发词，如 `$writer-me`、`$helper-me`。
- **待命技能（300+）**：不在全局清单，需给真身路径显式调用，如 `使用 ~/.ai/categories/05-工具数据与自动化/01-浏览器与数据获取/agent-browser/SKILL.md`。04/05 的路由表对每个场景标注了归属。
