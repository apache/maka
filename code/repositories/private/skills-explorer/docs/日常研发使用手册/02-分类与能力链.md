## 一、七大活跃分类速览

分类名即主归属判断顺序：改变 Agent 能力归 01，组织任务归 02，做产品定义归 03，做界面归 04，做工程质量归 05，接工具数据归 06，做内容经营归 07。

| 分类                     | 职责                      | 代表 skill（未标"全局"的均为待命，按路径调用）                                                                                                                                                                                                  |
| ------------------------ | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 01-Agent系统与Skills工程 | 生产和管理 skill 本身     | `find-skills`、`grilling`、`ponytail`（均全局）；`skill-creator`、`writing-skills`、`skill-judge`、`writing-plans`、`handoff`、`caveman`；04-Codex原生工作流 24 个仅 Codex                                                                      |
| 02-研究产品与决策        | 从想法到 PRD              | `brainstorming`、`grill-me`、`to-prd`、`to-issues`                                                                                                                                                                                              |
| 03-设计体验与前端应用    | UI/UX 与前端实现          | `css-me`、`ui-me`、`taro-me`、`typescript-magician`、`jsdoc-typescript-docs`（均全局，真身在 99-01 或本类）；待命：`ui-ux-pro-max`、`design-taste-frontend`、`extract-design-system`、`interaction-design`、`shadcn`、`nextjs-react-typescript` |

## 三、一人公司能力链（现行版）

链路不变：沉淀能力 → 编排执行 → 研究问题 → 定义产品 → 设计体验 → 工程实现 → 测试交付 → 工具自动化 → 内容增长 → 反馈沉淀。每段的主选换成现行技能：

| 阶段       | 现行主选（全局）                                                | 待命补充                                                     |
| ---------- | --------------------------------------------------------------- | ------------------------------------------------------------ |
| 沉淀能力   | `find-skills`、`project-workflow-skill-builder`、`skill-doctor` | `skill-from-masters`、`writing-skills`、`skill-judge`        |
| 编排执行   | —                                                               | `writing-plans`、`handoff`、`verification-before-completion` |
| 研究问题   | `grilling`                                                      | `brainstorming`、firecrawl 市场研究组                        |
| 定义产品   | `helper-me`（prd-me 节）                                        | `to-prd`、`to-issues`、付费区 `proto-to-prd`                 |
| 设计体验   | `ui-me`、`css-me`                                               | `ui-ux-pro-max`、`design-taste-frontend`                     |
| 工程实现   | `taro-me`、`vercel-react-best-practices`、`typescript-magician` | `nextjs-react-typescript`、`shadcn`                          |
| 测试交付   | `tdd`、`code-simplifier`、`helper-me`（quality-me 节）          | `systematic-debugging`、`webapp-testing`、`vitest`           |
| 工具自动化 | —                                                               | `agent-browser`、`chrome-devtools`、`firecrawl-workflows`    |
| 内容增长   | `writer-me`、`show-me`                                          | `copywriting`、`seo-audit`、`pptx`                           |
| 反馈沉淀   | `writer-me`（总结沉淀）→ `project-workflow-skill-builder`       | `skill-from-masters`                                         |

编排执行一段目前无全局技能，属已知空档：长任务规划类（writing-plans/handoff）都待命，需要时按 01 分类路径调用。
