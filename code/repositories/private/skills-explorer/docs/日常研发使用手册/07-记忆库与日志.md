## 日志

`update-skills.js` 的运行日志（`skills-update.log`：npx skills update 拉上游、sk-doctor 体检输出）。**临时性产物**：git 不跟踪，脚本每次运行 `mkdirSync` 自建自写。目录删除无副作用，下次跑 `update-skills.js` 自动重建。

**排障口径**：看 skill 体系健康状态不要翻日志，直接跑 `node ~/.ai/scripts/sk-doctor.js`——日志只留运行轨迹，doctor 给结论。
