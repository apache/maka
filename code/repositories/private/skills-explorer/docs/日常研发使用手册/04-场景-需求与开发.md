## 主线速查

1. 有 PRD → helper-me 抽蓝图 →（需要拆任务再叫 to-issues）。
2. 只有截图 → proto-to-prd 转 PRD → 回到 1。
3. 写页面 → ui-me 定结构、css-me 定样式、taro-me 管多端、vercel-\* 管 React 写法。
4. 联调 → helper-me 的 api-me / zustand-me 节。
