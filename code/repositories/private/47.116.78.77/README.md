# 47.116.78.77 本地镜像

源站 http://47.116.78.77/ 上两个应用的本地镜像，2026-09-05 抓取。一个文件夹 = 一个源站，从本目录起静态服务后，URL 路径与源站完全一致。

## 内容

| 本地路径 | 源站 | 说明 |
|---|---|---|
| `home/` | `/` | 「理解大模型 · 从 Token 到 Agent」交互式课程，Vite 单包 SPA，全部 16 课内容都在 302KB 的 JS bundle 里 |
| `harness/` | `/harness/` | 「如何 Harness 我的大模型 · Harness 的演进和未来」幻灯片，单个自包含 HTML（#/页码 键盘翻页）+ 2 张 PNG |
| `如何Harness我的大模型.pptx` | — | 幻灯片的原始文稿（已有的本地文件，非抓取） |

## 使用

双击 `启动.bat`（或在目录里跑 `python -m http.server 8777`），然后：

- 课程：http://127.0.0.1:8777/home/
- 幻灯片：http://127.0.0.1:8777/harness/#/9 （# 后数字即页码）

直接双击 index.html 打不开（ES module / 相对资源不允许 file:// 协议），必须走静态服务。
