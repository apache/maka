# 中文语言偏好设置

## 语言要求

- 所有回复和对话都使用中文（简体中文）
- 知识库文档、学习笔记使用中文
- 错误信息和日志信息的解释使用中文
- 技术术语可以保留英文，但需要提供中文解释

## 文档撰写规范

- 使用中文标点符号（，。！？：；""''）
- 技术文档结构清晰，使用中文标题
- 代码示例后提供中文说明
- 保持专业但友好的语调

## Kiro Spec 文档语言

`.kiro/specs/` 目录下的所有 Spec 文档必须使用中文：

- `requirements.md` - 需求文档使用中文描述
- `design.md` - 设计文档使用中文描述
- `tasks.md` - 任务清单使用中文描述

**例外**：

- EARS 模式关键词保持英文（WHEN、THE、SHALL、IF、THEN、WHILE、WHERE）
- 技术术语可保留英文，但需提供中文解释
- 代码示例保持英文

## 工程产物语言（英文）

以下内容使用英文，与国际工程规范保持一致：

- 源代码
- Git commits、PRs、issues
- Changelog、Release notes
- API 文档

## 例外情况

- 代码本身（变量名、函数名等）使用英文
- 配置文件中的键值对使用英文
- 第三方库和框架的名称保持原文
- URL 和文件路径保持原文
- i18n 本地化资源可使用中文
