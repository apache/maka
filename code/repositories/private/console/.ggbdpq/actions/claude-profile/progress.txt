### 2026-01-14 桌面端应用预设白屏修复 + SSOT 改造

- 复现证据：
  - 操作：桌面版点击"学习模式"→弹窗确认应用
  - 现象：应用预设后弹出"检测到外部修改"冲突对话框，潜在白屏风险
  - Console 错误：useFileWatcher 在非 Tauri 环境报 transformCallback undefined

- 根因分析：
  1. 冲突检测逻辑缺陷：应用预设后 hash 变化被误判为"外部修改"
  2. 文件 watcher 竞态：写入后的 settings-file-changed 事件与 mutation 的 onSettled 产生竞态
  3. 无 ErrorBoundary：任何渲染错误会导致整个 UI 崩溃
  4. 缺乏 optimistic update：mutation 没有使用乐观更新

- 修复点：
  1. 新增 ErrorBoundary.tsx：捕获渲染错误，防止白屏
  2. 改造 useFileWatcher：
     - 添加 Tauri 环境检测（动态 import）
     - 使用 useIsMutating 检测正在进行的写入
     - 添加 2 秒忽略窗口避免自身写入触发冲突
  3. 改造 useApplyPreset：
     - 添加 onMutate 乐观更新
     - 添加 onError 回滚
     - 添加 onSuccess 用返回 hash 更新缓存
  4. 改造 App.tsx 冲突检测：
     - 引入 isMutating 检测
     - 使用 lastWriteTimeRef 记录写入时间
     - 写入后 3 秒内不弹冲突对话框
  5. 新增回归测试 useSettings.test.ts（5 个测试用例）

- 验证命令与结果：
  - pnpm typecheck → 通过
  - pnpm test → 28 tests passed
  - 浏览器测试：应用学习模式预设 → 不白屏，不弹冲突对话框，UI 正确刷新
