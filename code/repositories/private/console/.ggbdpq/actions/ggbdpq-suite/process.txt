## 8. Vue 3 与 Next.js 子项目决策记录

**决策时间**：2026-01-26

**背景**：
- workflow-engine/admin-console 使用 Vue 3 + Element Plus
- workflow-engine/developer-portal 使用 Next.js 15

**短期策略**：
- 保持隔离运行，不做强制迁移
- 两个项目维持现有技术栈独立演进
- 不纳入 React 统一技术栈约束范围

**后续评估**：
- 待 suite 核心迁移完成后，再评估是否迁移至 React
- 若迁移，admin-console 可考虑 shadcn/ui 替代 Element Plus
- developer-portal 需评估 SSR 需求，若无强需求可迁移至 Vite + React Router
