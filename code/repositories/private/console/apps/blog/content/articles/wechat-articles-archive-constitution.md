# 公众号文章归档宪法 v1.1

文件名建议：公众号文章归档宪法\_v1.1.md  
描述：把任意来源的公众号文章从按月份堆放迁移到按主题归档。分类体系固定为 11 类，提供裁决优先级、关键词触发器、冲突处理、以及可复制的归档提示词。本文不讨论 ChatGPT 项目文件夹结构。

## 0. 范围与边界

范围

1. 适用于任意公众号来源，例如 与AI同行之路 链熵工坊
2. 覆盖 2025 与 2026 等跨年份文章
3. 目标是把文章标题清单稳定映射到 11 类目录

边界

1. 不为 ChatGPT 对话做项目归档
2. 不新增额外顶层分类
3. 不创建 年度盘点 年度系列盘点 这类新类目

---

## 1. 11 类标准目录定义

01 入门与基础  
新手上手、全景概览、基础流程、基础术语

02 核心功能深度解析  
单一能力的机制与正确姿势，例如 会话 记忆 MCP Hooks Subagent Plan LSP Code Review 权限模型

03 Skills 专题  
Skills 理念、技能包开发、规范、生态、Skill Creator、资源库

04 企业级应用三部曲  
组织流程、团队落地、管理视角、SOP、运营与治理

05 版本更新追踪  
版本号区间、更新点、发布上线、时间线、changelog、阶段演进复盘

06 架构与源码分析  
架构范式、逆向与源码、系统提示词、设计哲学、产品哲学的工程拆解

07 对比与迁移  
工具对比、迁移方案、横评、范式差异、选型

08 实战与避坑  
生产实践、踩坑清单、长跑落地、可复刻工作流、风险与安全实践

09 性能与优化  
Token 预算、成本、提速、稳定性治理、长任务变慢、缓存与加速

10 模型与新特性  
模型发布、能力评测、趋势与新特性解读

11 配置与工具  
安装配置、settings、模板脚手架、终端美化、工具开源与用法、插件安装与管理

## 2. 归档裁决规则 v1.1

### 2.1 核心原则

以文章的主承诺裁决  
标题关键词用于快速定位  
正文承诺拥有更高裁决权

### 2.2 硬规则优先级

当标题同时命中多类时，按以下优先级裁决，保证每篇只落一个主类

1. 11 配置与工具
2. 05 版本更新追踪
3. 09 性能与优化
4. 02 核心功能深度解析
5. 03 Skills 专题
6. 04 企业级应用三部曲
7. 07 对比与迁移
8. 08 实战与避坑
9. 06 架构与源码分析
10. 10 模型与新特性
11. 01 入门与基础

### 2.3 年度盘点类文章处理规则

年度盘点不单独建类  
按主骨架映射到 11 类中的一个主类  
常见映射

1. 以版本时间线为骨架，归 05
2. 以团队落地与流程治理为骨架，归 04
3. 以成本与 Token 策略为骨架，归 09  
   只选其一

## 4. 输出格式标准

每篇文章输出一行  
日期 标题：分类编号 分类名

示例  
2025-12-17 Claude Code 重磅更新：官方插件市场正式上线：05 版本更新追踪  
2025-12-10 Claude Mem 让 AI 拥有永久记忆：02 核心功能深度解析  
2025-11-26 省钱秘籍：一招省 60% Token 消耗：09 性能与优化

## 5. 可复制执行的归档提示词

模板 A 批量归档  
请把下面文章标题严格按 11 类目录归档。要求每篇只选一个主分类，使用以下优先级裁决：  
11 配置与工具  
05 版本更新追踪  
09 性能与优化  
02 核心功能深度解析  
03 Skills 专题  
04 企业级应用三部曲  
07 对比与迁移  
08 实战与避坑  
06 架构与源码分析  
10 模型与新特性  
01 入门与基础  
输出格式为：日期 标题：分类编号 分类名。  
标题清单如下：

1. ...
2. ...

模板 B 有争议条目裁决  
下面这几篇可能跨类，请按主承诺裁决并给一句理由，最终仍只落一个主分类：

1. ...
2. ...

模板 C 年度盘点映射  
下面这篇属于盘点类文章，请在 11 类里选最贴近的一类，只给一个主类，并说明映射依据：  
文章：...

## 6. 落地操作清单

1. 建立固定目录  
   01 到 11 一次建好，长期不改编号与命名

2. 迁移历史文章  
   从按月份列表导出标题，批量跑 模板 A 得到归档清单

3. 执行搬运  
   按归档清单移动文章到对应目录  
   保留原始日期在标题或文件名中

4. 新文章接入  
   每次入库先跑 模板 A  
   避免积压成按月份堆放

5. 规则维护  
   出现高频争议时，只调整优先级或触发器  
   不改 11 类目录结构

## 7. 说明

与AI同行之路 与 链熵工坊 可以共用同一套 11 类体系  
原因是 11 类描述的是文章主题与产出承诺，与来源无关  
来源差异只体现在清单维度，例如 单独维护 链熵工坊 2025-12 归档清单
