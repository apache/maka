# 只给AI一个清单，它就把项目搭起来了

- **视频 ID**：`V20251207-AIAutoProjectBootstrap`
- **日期**：2025-12-07

> **一句话**：新项目早期不一定需要 Ledger；最关键的是清晰 spec、合理拆解、稳定的 action protocol。

## 精华总结
- 论文框架很强，但工程级 demo 少；你做的是“论文启发 + 工程落地”的杂交实验。
- POC 证明：spec + todo list + 结构化 prompt，可以让模型跑完一个 phase；但 phase 之间仍需人工衔接。
- 关键认知升级：不是 AI 能跑多长，而是它在什么条件下稳定、在什么条件下必失效。
- 未来长周期 agent 的方向：phase 分段闭环 + 可恢复状态（harness），而不是一次性贯通。

## 行动清单
1. 项目早期先把 spec 和 TODO 做到可验收，不要一上来 overdesign 全套系统。
1. 把工作切成 phase：每个 phase 都在上下文窗口内闭环验收。
1. 尽早建立可恢复机制（状态落盘/可重入），否则长链路一崩就全崩。
