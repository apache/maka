# 我直接演示 AI Coding 怎么从需求跑到验收

- **视频 ID**：`V20251223-AIExecutionPipelineDemoAndMonthlyReconciliation`
- **日期**：2025-12-23

> **一句话**：这期不是成果秀，而是对账：让“AI 做完了”变成可验收、可追溯、可返工的证据链。

## 精华总结
- 主控只做计划/调度/验收，不写业务代码；执行统一走 subagent_shim，避免黑盒。
- Run / Step / Round 不是目录结构，而是责任边界：每一步都有输入、输出、证据与返工记录。
- 你在做“月度对账”：复盘阶段二兑现到哪、失败模式是什么、下一阶段该补哪块地基。

## 行动清单
1. 把执行入口收敛到 shim（单一入口），不要让“手工执行 + AI 执行”混在一起污染证据链。
1. 每个 Step 结束都做一次“证据验收”，不通过就写结构化 Reject Note 再 resume。
1. 定期做对账：把可复用的 lessons 写进 evolution，而不是只留在聊天记录里。

5. 这是一个少见的、真实的工程叙事：
   - 不承诺完成时间
   - 不回避未兑现部分
   - 用证据而不是情绪建立信任
