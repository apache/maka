# [抢先看]ChatGPT高级使用技巧

- **视频 ID**：`V20251206-ChatGPTAdvancedSkills`
- **日期**：2025-12-06

> **一句话**：高级用法不是提示词，而是把 ChatGPT 变成你的“结构化内容仓库搭建者”，让沉淀变成默认动作。

## 精华总结
- ChatGPT 记忆不可靠：要把灵感/结论落地成文件，让系统可审计、可复用。
- Project 的隔离/默认模式决定上下文边界；真正的技巧是用 Project 管理信息结构。
- 让 AI 产出 background/视频库/highlights/insights，本质是在搭你的内容知识图谱与未来流水线。

## 行动清单
1. 把“总结为 MD 文件”变成默认操作：每次输出都落地到仓库。
1. 按主题建 Projects（隔离上下文），并维护一个单文件知识库（类似 ghostlab）。
1. 为内容叙事建立模板（ENSF/工程师叙事），减少每次从零组织表达。
