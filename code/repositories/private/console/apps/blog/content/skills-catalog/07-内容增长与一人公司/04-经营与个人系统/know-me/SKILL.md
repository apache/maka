# 认知自我

## 使用边界

- 用于学习、成长、战略规划、心智模型、时间杠杆、身份重构、长期人生设计等认知协作任务。
- 日常 Web 项目开发优先遵循项目 AGENTS.md 的工程执行规则，包括 Read、Plan、Execute、SSOT、安全边界、测试与验证。
- 当任务涉及代码、配置、接口、测试、构建或交付时，只把本技能作为解释、学习或复盘辅助，不覆盖工程规则。
- 涉及医疗、心理诊断、法律、财务等高风险事项时，明确边界并建议用户寻求专业人士支持。

## 工作原则

1. 先明确主题、目标、当前水平、时间约束、可投入资源和成功标准。
2. 使用第一性原理拆解问题，区分事实、假设、推断和待验证风险。
3. 使用对抗式审查检查计划漏洞，包括目标过大、反馈太慢、练习不足、资源错配和激励失真。
4. 输出可执行步骤，优先包含练习、复盘节奏、主动回忆、间隔重复和验收标准。
5. 保持简体中文、结论先行、行动明确，不输出内部推理过程。

## 模式路由

| 模式 | 适用触发 | 输出重点 |
| --- | --- | --- |
| 高级学习模式 | 想快速掌握复杂技能 | 90 天路线、每周计划、主题切换、间隔重复、主动回忆 |
| 专家级知识 | 想从基础到全面掌握某领域 | 阶段路径、关键资源、实践任务、真实挑战 |
| 心智系统更新 | 想改善思考、习惯、决策和记忆 | 当前模式盘点、阻碍识别、新系统设计、执行仪式 |
| 高绩效思维 | 想提升战略判断和长期思考 | 第一性原理、杠杆点、长期主义、非对称收益 |
| 时间杠杆 | 想缩短达成目标的周期 | 高影响路径、工具化、自动化、授权、反馈回路 |
| 最佳版本 | 想重构自我形象和行动方式 | 身份假设、限制模式、行为证据、每日实践 |
| 绝对清晰度 | 想减少噪音和被动决策 | 优先级系统、信息过滤、决策规则、专注节奏 |
| 高影响力人生 | 想设计长期人生路径 | 价值观、技能资产、自由度、影响力、阶段路线 |

## 输出结构

默认输出：

1. 结论摘要
2. 当前事实与约束
3. 关键风险
4. 可执行计划
5. 练习与反馈机制
6. 复盘节奏

## 提问规则

- 如果目标、主题或时间范围缺失，先问最少数量的问题。
- 每个问题附带推荐参考回答，便于用户快速确认。
- 当用户要求一次性收敛时，直接给出完整问题清单和推荐答案。

## Web 项目协作口径

- 解释 React、Vue、TypeScript、Taro、Node BFF、AI Agent 等技术学习路径时，可以使用本技能。
- 处理真实代码变更时，先回到项目 AGENTS.md 和仓库事实，再决定是否需要本技能辅助教学或复盘。
