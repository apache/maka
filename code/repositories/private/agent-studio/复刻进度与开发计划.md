## 2. 交付目标与证据规则

目标是能打开完整侧栏、进入七种模式及核心画布、使用真实数据并保存本地编辑的应用。当前还原的是发布 JavaScript，不是原始 TS/TSX 或服务端源码。

- 页面验收写明页面、样本、操作和结果；只读详情不等于编辑保存完成。
- 直接调用公共 `request` 属接口测试；同页回读不自动等于重载后恢复。
- 历史记录中样本 ID 错误、测试计数过期或过度概括的部分，按本轮复核说明降级；保留记录供追溯。
- 更新采集包不清空浏览器的四份用户快照，也不擅自删除既有本地记录。旧快照中的编辑、删除和当前新基准可以不同。
- 有效空响应、接口失败、未采集和未运行分别记录，不以空数组替代失败。
- 当前原站和旧采集的租户上下文是否相同，需要用 ID 交集核对；不能把所有差异都解释为时间增长。
