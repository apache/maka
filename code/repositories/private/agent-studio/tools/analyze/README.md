# tools/analyze/

分析工具，用于检查代码质量和完整性。

## 工具列表

- `check-imports.py` - 检查导入语句
- `check-patches.py` - 检查补丁应用状态
- `find-editable.py` - 查找可编辑组件
- `find-modes.py` - 查找模式定义
- `inspect-evidence.py` - 检查证据文件
- `module-links.py` - 分析模块链接关系

## 使用

直接运行 Python 脚本：
```bash
python tools/analyze/check-imports.py
```
