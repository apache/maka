1. 标签体系直连曾稳定白屏，报“容器元素el的宽高不能为0”。本轮探针定位到 Spin 外层高 441px、内部高 2px、画布高 0px 的断裂布局链。补外层 flex 后，两组非空标签树直连恢复，画布为 956×445；其中“候选句 / 饮水打卡（1） / 拍照测肤”三节点树刷新保留身份。另一个真实空标签库显示导入提示，画布为 956×441，三者错误数组均为空。没有原站同页复现证据，不能把修前缺陷称作原站固有；导入/更换仍未验收。
2. 文档删除、下架菜单在本轮样本中明确为 disabled；未弹确认框符合禁用状态，不能定性为浏览器事件桥故障。可操作样本的 UI 删除闭环仍需单独验证。
3. 可编辑插件、低代码与工具型节点编辑、标准/超级智能体关联选择器及部分业务版本表单，尚无完整逐项 UI 操作证明。
4. 旧 29 个知识库没有音视频样本，只能说明旧采集数据为空。当前账号的媒体数量须以新采集结果为准，详情播放和编辑不能据模块存在判定完成。
5. 四对截图存在原站新增导航、列头、租户展示和数据内容差异。像素差异指标是描述工具，不能用任意阈值把这些差异变为验收通过。
