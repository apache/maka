# 飞书转存专家

**商店版本**: 0.7.27 | **Manifest**: V3

## 功能概述

飞书转存专家是一款飞书文档多格式导出工具，支持将飞书文档导出为 PDF、Word、Markdown、HTML 等格式。

核心功能：
- 飞书文档多格式导出（PDF/Word/Markdown/HTML）
- 图片/表格完整保留
- 多平台文档增强（飞书 + 更多）

## 技术架构

- **核心库**: html2canvas + jsPDF + docx
- **导出格式**: PDF / Word / Markdown / HTML
