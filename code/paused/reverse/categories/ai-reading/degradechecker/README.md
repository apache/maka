# ChatGPT Degrade Checker

**商店版本**: 2.4.6 | **Manifest**: V3

## 功能概述

ChatGPT Degrade Checker 用于检测 ChatGPT 是否被降级到旧版/性能较差的模型版本，帮助用户确认当前使用的模型质量。

## 技术架构

- **框架**: 原生 JavaScript
- **检测方式**: 分析页面中的模型版本标识和 API 行为特征

## 权限

`storage`, `activeTab`, `scripting` 等
