# YouMind AI Web Clipper

**商店版本**: 0.3.0.33 | **Manifest**: V3

## 功能概述

YouMind 是一款 AI 驱动的网页剪藏和笔记工具，支持 YouTube 视频笔记、网页标注、AI 摘要等功能。

核心功能：
- YouTube 视频笔记（时间戳标记）
- 网页标注与剪藏
- AI 摘要（Claude / Gemini 集成）
- 思维导图式内容组织
