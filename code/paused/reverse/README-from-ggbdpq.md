# reverse 目录索引（SSOT）

> 最后核验：2026-09-20。未来的我或 AI Agent：**只读本文件即可判断新内容放哪**；仍拿不准时原位保留并在此记录原因，不要猜。本目录是 `E:\ggbdpq\` 下的长期资产聚合目录，全盘规则以 `E:\README.md` 为准。

## 一级结构

| 目录/文件 | 职责 | 收什么 | 不收什么 |
|---|---|---|---|
| `categories\` | 批量逆向产出，按用途分 5 类 | `categories\{分类}\{插件名}\{YYYY-MM-DD}-{模型}\`，插件级 README + 各版本还原项目 | 原始 crx（→ `crx-archive`）、深度多版本案例（→ `cases`） |
| `cases\` | 深度逆向案例，一目标一目录 | 多版本对比、源码对照、逆向笔记、非扩展目标（如 cursor-byok） | 常规批量产出（→ `categories`） |
| `crx-archive\` | 原始 .crx 素材存档，只进不出 | `crx-archive\{下载日期}\` | 任何解包/还原产出 |
| `docs\` | 方法论与批次索引 | 指南、案例库、Skills 指南、批次索引报告 | 插件级 README（留在 `categories` 各自目录） |
| `CLAUDE.md` | Agent 会话入口与关键约定 | — | — |
| `README.md` | 本文件，目录唯一总索引 | — | — |

## 新内容放哪（决策表）

| 情况 | 动作 |
|---|---|
| 常规逆向一个新插件 | `categories\{分类}\{插件名}\{日期}-{模型}\`，并在该分类 README 表格补一行 |
| 深度逆向（多版本 / 源码对照 / 非扩展目标） | `cases\{日期}-{目标}的逆向工程\` |
| 下载了 crx 还没逆向 | `crx-archive\{今天日期}\` |
| 方法论、流程、批量报告 | `docs\` |
| 临时实验、一次性中间产物 | 不进本目录 → `E:\tmp\{主题}-{日期}\` |

## 规则

1. 移动一律同盘 rename（`mv`），禁止复制后删原件。
2. `cases\` 各目录自包含：crx、笔记、还原源码都留在案例目录内。
3. 插件数量、版本号等易腐数字以 `categories\{分类}\README.md` 表格为准，本文件不维护计数。
4. 大体积中间产物删除前需人工确认（现存大件：`cases\2026-06-25-cursor-byok的逆向工程\work\` 约 3.3G，为 IDA/重建中间产物）。
