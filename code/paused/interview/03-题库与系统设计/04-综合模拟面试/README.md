# 综合模拟：五种选题入口

每周最多安排一场，按本周真实卡点选一种。**模拟替代当天日课，总计不超过60分钟**；不叠加普通题量，也不要求五种全部做完。当前尚无本人闭卷成绩。

| 类型 | 从现有材料选题 | 检查什么 |
|---|---|---|
| 基础能力 | [F01—F08](../00-P0-必背.md)选两题 | 机制、一个反例、本人职责边界 |
| AI 项目深挖 | [P04](../../01-AI项目与Agent工程/04-面诊成交助手-证据溯源.md)或[P02](../../01-AI项目与Agent工程/02-AI音频编辑-Node-BFF.md)，按需[P05](../../06-三旗舰作品集加固/01-qoder-proxy-api-叙事与十问.md) | 30秒定位、2分钟决策、真实证据与未验能力 |
| 系统设计 | [S01/S02](../03-系统设计题.md)选一道 | 状态所有者、失败路径、最小验收；方案不冒充实绩 |
| 实战编码 | [按需手写](../01-P1-重要.md)选一个小问题 | 实现或伪代码的正确边界、失败检查；不改项目源仓 |
| 综合／HR | [自我介绍](../../00-事实与简历/03-自我介绍-60秒与120秒.md)、[HR与反问](../../04-表达与模拟/04-HR与反问.md)与一份真实JD | 日期／归属一致、岗位匹配、具体反问；履历与动机据实 |

## 60分钟流程

1. **5分钟**：闭卷自我介绍，核对岗位与本人职责。
2. **15分钟**：围绕所选类型进行机制追问；编码题可在这一段解释最小实现与失败检查。
3. **20分钟**：P04或P02项目深挖，按30秒→2分钟→证据／失败路径展开；P05仅按追问选用。
4. **20分钟**：核对原回答，纠正事实与机制，重答一个卡点并记录证据及下次复测；未完成的不补成通过。

## 有辨别力的评分

| 维度 | 0分 | 1分 | 2分 |
|---|---|---|---|
| 事实与归属 | 编造／冲突／把计划当实绩 | 大体准确但缺范围或时点 | 能区分本人、团队、演示、设计及验证时点 |
| 技术机制 | 只有名词或明显错误 | 主链正确但缺关键因果 | 能解释状态与数据流，并回答为什么 |
| 失败与验证 | 无失败路径／测试抓不住错误 | 提到异常但没有可判定结果 | 给具体故障、观察点与应失败的反例 |
| 表达 | 跑题或无法说明职责 | 能回答但超时／缺结论 | 限时完成，结论明确且可展开证据 |

四项0—2分只用于真实练习，不是招聘通过线。事实冲突不能靠其他维度得分抵消；看稿后的重答单独记录，不覆盖闭卷原答。若未作答，对应项保持空白，不填0分。

连续追问：你本人做哪一段？为什么？失败怎样表现？有什么更小方案？怎样证明？记录统一写入[模拟面试记录](../../04-表达与模拟/05-模拟面试记录.md)。

## 面试官怎样逐层追问

机制段先让候选人完整回答，再根据真正卡住的地方选一个追问。基础题可从“作用域／事件循环／状态归属”进入，要求画顺序或数据流；AI 题可从 chunk、schema、任务或引用进入，要求区分展示成功与业务成功。问题卡来自 F01—F08／A01—A10，不再建立一套新题号。

项目段固定问“你本人负责哪一段”，然后只沿一条链路深挖。P04 可沿顾客数据→mapper→依据展示→人工操作，P02 可沿提交→处理→查询／回调→产物。公开备料按追问选 P05／P11／P12，不在20分钟内轮讲三项目。公开项目的5—8分钟长稿是选用一份时的展开目标，仍占用这20分钟，不另加时。

可检查的追问顺序是：成功输入是什么→失败发生在哪里→用户看到什么→哪个观察证明当前处理正确→还有什么未验证。若候选人只答名词，追加反例；若事实已冲突，先定位提交、职责与证据，避免靠更多术语绕过问题。面试官也不能把提示后的答案记为独立闭卷能力。

## 五种类型的最小题组

| 类型 | 机制段只选一组 | 项目段连接点 |
|---|---|---|
| 基础能力 | 两题中挑一个反例：旧闭包／晚到响应／错误缓存归属 | 连接P04数据归属，或P02任务状态，不强行讲AI模型原理 |
| AI 项目 | A01+A03 或 A06+A07，指出每层失效条件 | 当前源码边界：固定卡片、页面续追、文本子集 |
| 系统设计 | S01或S02：先澄清，再画一个异常时间线 | 方案与历史实现分别回答，不按想象填“做过” |
| 实战编码 | 一个解析／并发／状态小题，写最小实现或伪代码 | 解释会失败的检查；只练题，不动项目源仓 |
| 综合／HR | 从真实JD选职责与一个不匹配点 | 用两分钟项目支撑匹配，超证据部分明确待核验 |

## 评分怎样发现真实短板

“终态不能被晚到事件覆盖”只算机制表述；如果还指出任务标识、时间线和应观察的终态，才具备失败验证证据。说“测试都通过”却不知道检查了什么，不给失败与验证2分；说“P11服务重启续跑”与当前证据冲突，事实项应处理为冲突，并回查后重答。这里是评分示例，不是本人已有分数。

一次模拟最多挑两个影响回答的缺口：一个事实缺口、一个机制缺口。事实缺口回到事实源／源码，不靠补写口号；机制缺口看相应扩展段，重画原失败链路。记录保留原问题、原答摘要、所获提示、证据、看稿重答和下次复测条件。未练过的题保持空白；本次重答会了，也不替未来闭卷复测预填通过。

若当天只有15分钟，使用忙日的一题闭卷5分钟、项目30秒与追问5分钟、查证记录5分钟，记为忙日练习。它不按60分钟模拟计分，也不把缺失环节补成已完成。模拟剩余时间优先复盘，不靠追加新题证明复习量。
