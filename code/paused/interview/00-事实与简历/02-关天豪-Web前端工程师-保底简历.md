## 项目经验

### 业务监控预警平台（SSAP）

服务于业务行为监控、规则配置与安全审计。
- **技术栈**：React + TypeScript + Shineout。
- **核心功能开发**：数据看板、规则与采集来源配置、审计列表及详情；将多级筛选状态收拢为 Hook，维护响应类型与枚举。
- **工程实践**：统一请求层处理权限、错误码及登录态衔接，减少业务页面重复判断。

### 研发运营与预算平台（DOMP / BCP）

分别支撑研发指标管理与预算编制、执行、审批。
- **技术栈**：React + ECharts + Redux + TypeScript。
- **核心功能开发**：DOMP 图表与运营模块；BCP 预算、树形数据和审批交互。
- **工程实践**：图表按容器、数据映射与配置工厂分层；处理树遍历和不可变状态问题，结合实际需求复用权限、请求与下载能力。

### 涉案财物管理系统

为财物登记、出入库和库房业务提供操作界面。
- **技术栈**：Vue3 + Element Plus + Vuex + Sass。
- **核心功能开发**：不同财物类型的录入流程、按钮级权限、RFID 相关接口交互。
- **工程实践**：封装 EZTable 分页表格，采用按需加载和路由拆分；未附性能测量记录的提升比例不作为成果数字。

### 美业智能工作台与面诊准备

- **技术栈**：Taro + React + TypeScript + Zustand。
- **核心功能开发**：资源排期、顾客跟进、护理报告、AI结论依据展示与品牌端商品卡片。
