# 自我介绍：60秒与120秒

身份与日期见[事实基线](00-个人事实基线.md)。这是练习稿，录音后按实际语速删减。

## 60秒

我是关天豪，2018 年起从事 Web 开发，主要使用React、Vue和TypeScript。过去做供应链B端平台，现在在数联天下做美业AI应用，工作从前端扩展到Node服务。我负责接诊准备中的结构化卡片和依据展示，也做音频任务流程、BFF及客户识别服务。个人项目分别实践文本协议网关、AI应用演示和Agent行为规范，面试时我会按岗位选一个展开。我想找AI应用或Agent工程方向的岗位，优势是把模型输出接入业务流程，处理状态、失败和人工确认，而不只停留在聊天界面。

## 120秒

在60秒稿之后展开一个案例：接诊准备里，顾问需要知道AI建议来自哪里。我负责前端，通过mapper把不同数据域转换成视图模型，展示来源、引用原文、后端可信度字段和录音入口，同时管理切换顾客后的缓存失效。音频项目则让我向服务端延伸：从小程序任务创建，到Node调用ffmpeg、对象存储和状态回调，再到人工确认保存。个人网关补充契约隔离与文本兼容经验；agent-hub可公开演示页面刷新后续追任务，但它的证据分数是fixture；coding-agent用统一场景观察五实现的部分行为，不宣称完整等价。团队的流式内核、模型分析与我的UI/任务工程职责是分开的。我希望继续把这些工程能力用于真实的AI产品。

## Web岗位开场替换

我更擅长复杂B端应用的数据、状态和组件设计。在希音做过监控、预算与运营平台，积累图表分层、级联筛选、权限和请求层经验；当前AI业务增加了跨端与Node实践。根据岗位需要，我可以先展开SSAP/DOMP，也可以讲接诊准备。
