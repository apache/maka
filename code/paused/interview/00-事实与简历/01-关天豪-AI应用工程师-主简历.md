### AI 音频编辑与客户识别 · Node 服务工程（公司项目）

独立负责音频编辑小程序子包，主导音频 BFF，并开发从中拆分的客户识别服务。
- **技术栈**：Taro + TypeScript；Fastify + ffmpeg / ffprobe + COS + node:test。
- **核心功能**：串联任务创建、状态查询、音频处理、对象存储、回调与人工确认；记录任务快照并处理超时和临时文件清理。
- **服务演进**：通过 capability / provider 适配分离识别流程、输入来源和外部能力，复用共享音频模块；编写 Java Mock BFF 支持接口就绪前的并行联调。

### qoder-proxy-api · 文本协议兼容网关（个人公开项目）

- **技术栈**：TypeScript + Node.js + HTTP / Fetch + SSE + node:test。
- **实现**：Gateway、CLI、Cloud Agents 三类上游统一为 Canonical Request/Event；适配 Chat、Responses、Messages 文本接口，复用事件聚合与显式模型路由。
- **验证与边界**：无凭证离线合同与 fake 上游测试；当前是文本兼容子集，Gateway 保持实验性，不宣称完整工具调用、图像兼容或真实客户端全链路。

### agent-hub · AI 应用工程演示（个人公开项目）

- **技术栈**：React + TypeScript + Zustand + FastAPI。
- **实现**：跨 chunk SSE 解码、固定 schema 卡片、fixture 证据展示；页面刷新按 taskId 查询快照并续轮询到终态。
- **验证与边界**：公开契约/API/浏览器三层 CI；演示数据不代表可信度算法或推荐质量，页面恢复不代表后端重启续跑。
