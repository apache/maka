# 面试复盘

当前没有本轮实际面试复盘，以下仍为空模板。模拟练习另记[模拟记录](../04-表达与模拟/05-模拟面试记录.md)，不能当真实面试结果。

## 每场只记影响下一次回答的内容

- 日期、公司、岗位、轮次、JD与使用的简历版本：
- 原题、关键追问、我的原回答：
- 面试官实际反馈（与个人推测分开）：
- 一个最影响回答的卡点：
- 核对的证据／唯一答案入口：
- 限时重答版本与下次复测日期：
- 后续行动与截止日期：

事实冲突回[事实基线](../00-事实与简历/00-个人事实基线.md)；机制遗漏回F/A核心题，JD特定题回按需题库；证据不足回[待核验清单](../00-事实与简历/06-待核验清单.md)。不为复盘新造数字或追加未经验证的项目经历。

## 每周回看

只从真实[投递记录](02-投递记录.md)与本页计算结果；区分样本数和比例。没有足够样本时保留观察，不把一次面试推断为市场规律。

## 区分事实问题与表达问题

复盘先分类：职责说错回事实源，机制不清回核心题，缺证据回待核验，冗长或答偏回项目稿。记录面试官究竟改变了哪个条件，再重答同一个问题；不把自己猜测的淘汰原因当反馈。长答被打断时，记实际插问点，而不是默认稿件太长或技术太浅。
