## 方法与写作约定

正文保留短答，并补充原理、可演算案例、失败条件、取舍、递进追问与官方参考；先闭卷回答，卡在哪一层就查哪一段。P04/P02 与公开 P05/P11/P12 已在各自主文附 5—8 分钟口述底稿（30 秒说明问题与职责 → 2 分钟主链路 → 180 秒失败与取舍）。方法只维护在[每日训练](04-表达与模拟/00-每日口述训练.md)；没有做过的消融只讲实验设计。题目用“结论—机制—反例—本人案例—边界”；项目用“30秒—2分钟—架构—难点—追问—证据”。身份与日期只维护事实基线，数字集中到证据登记；练习与投递记录只填真实发生的结果。

## 维护与恢复

身份、日期、归属先改事实基线；数字先改证据台账；答案只维护在题库或项目唯一正文。简历与 GitHub 主页是展示副本，主页只保留公开可核验的内容。
