# 模拟面试记录

本轮只完成材料与源码核验，尚未听取本人闭卷回答。以下仍为空模板，不代表已发生的成绩。

## 单场记录模板

- 日期 / 模拟卷 / 使用的简历版本：
- 原题与追问 / 30秒、2分钟或深挖层级：
- 我的原回答：
- 事实是否与基线一致：
- 技术机制遗漏：
- 缺失证据或过度声明：
- 重答版本 / 查阅了哪份证据：
- 回流文档与下次复测日期：
- 到期复测原回答 / 是否仍需查稿：

记录只保存真实练习过程；旧模拟记录作为历史材料留存。

## 新增长答记录字段

- 5—8分钟试讲的实际时长／插问位置：
- 主链路能否脱稿／用了哪个案例：
- 追问改变了什么输入或假设／结论是否修正：
- 事实、推断、未验证项是否混淆：

只在本人实际练习后填写；目标时长与稿件长度不是成绩。参考稿可以标“待练”，不能代填独立完成。
