# UI polish, 2026-09-26: the Maka look

Goal: a window the Maka core team would accept as theirs. The authority is Maka's own design
system, `$MAKA_REPO/DESIGN.md` (read §2 Surfaces, §3 Ink, §4 Borders, §5 Elevation, §6 Radius,
§8 Color, §9 Components before touching anything). AllSum (a gpui-kit app) is the reference
for what gpui-kit can look like; Maka Desktop is the reference for information and brand.

The icon set, the composer dock and the transcript rows were drawn in a private Paper file
(pages Icons, Components); its artboard exports were not carried into this repository. The
icon SVGs in `assets/icons/maka/` are the same geometry, served through
`shared::icons::MakaIcon`. A browsable design sheet generated from the same icon source is
`docs/design/design-sheet.html`.
The Paper free tier hit its weekly MCP limit before the sidebar and full-screen artboards
were drawn; the values below are the spec for those regions.

All sizes are rungs of Maka's type scale (12 / 14 / 16 / 18 / 20 / 22; review round 6).
Every value below is a target. Where gpui-kit cannot express one, say so in the commit body
and pick the nearest expressible value; never invent an API.

## 1. Palette (theme tokens)

Remap gpui-kit's theme colours (`cx.theme()`) to these roles, light / dark. Do it once, in
one place (a Maka theme module), so every view follows. No hex literal outside that module.

| Role | Light | Dark | Use |
|---|---|---|---|
| canvas (base) | `#F7F7F7` | `#111113` | sidebar and the window floor behind the plate |
| plate (raised) | `#FFFFFF` | `#171719` | the main reading plate, composer dock, dialogs |
| overlay | `#FFFFFF` | `#1B1B1E` | menus, popovers, dialogs, toasts |
| sunken | `#EDEDED` | `#09090B` | segmented track, recessed chrome |
| bubble | `#F2F2F3` | `#242427` | user message bubble |
| code | `#F1F1F1` | `#111113` | code blocks, expanded tool output, a prompt's command (Maka Desktop's code block is `#111111` in dark); inline code takes ink 6% |
| ink | `#0F0F12` | `#EEEEF1` | primary text and icons |
| ink muted | `#525252` | `#A3A3A3` | secondary text and icons (the only other text tier) |
| border | ink at 10% | ink at 10% | structural boundaries |
| border soft | ink at 6% | ink at 6% | row dividers inside a group |
| hover | ink at 4% | ink at 6% | row and control hover wash |
| selected | ink at 6% | ink at 9% | selected sidebar row |
| primary | `#0260A6` | `#5FB6FF` | the one solid CTA (send), links; text on it `#FFFFFF` / `#171717` |
| accent | `#57A3EF` | `#58B0FF` | focus ring, text selection, live state |
| brand | `#71A8FD` | `#71A8FD` | the wordmark only; never a CTA |
| success / warning / destructive | `#007A11` / `#AB3900` / `#C90000` | `#279936` / `#E26C00` / `#FF6367` | status ink and 8px dots |

Rules from DESIGN.md that the palette must keep: two ink tiers only; accent is signal, never a
flood; one separator per edge (fill step, line, or shadow, never two).

## 2. Type

System UI stack (SF Pro, PingFang SC for CJK). Mono: SF Mono, then Menlo.

| Role | Size / line | Weight |
|---|---|---|
| display (empty-state line) | 22 / 32 | 400 |
| heading (dialog titles) | 16 / 24 | 600 |
| body (transcript, inputs) | 14 / 22 in the transcript, 14 / 20 elsewhere | 400 |
| label (buttons, row titles) | 14 / 20 | 500 |
| row (sidebar task titles) | 14 / 20 | 400 |
| supporting (ages, footers, captions) | 12 / 20 | 400 |
| code (blocks, prompts) | 14 / 20 | 400 |
| compact code (tool rows, tool output) | 12 / 20 | 400 |

Body is 14px, not gpui-kit's 16px default: set the window's rem so 1rem = 14px or set sizes
explicitly, whichever gpui-kit supports cleanly, and check nothing else shrinks below 12px.

## 3. Radius

control 6 (chips inside dense rows, keycaps, inline code) · surface 10 (buttons, inputs,
sidebar rows, segmented control, code blocks) · modal 12 (plate, tool group, dialogs, menus)
· chat 28 (user bubble and composer dock, which round together) · pill (send button, badges,
dots). Nothing interactive is square.

## 4. Window and surfaces

- The window floor is canvas. The sidebar sits on canvas with no divider line.
- The main area is one white plate: inset 8px from the window's top, right and bottom edges,
  flush to the sidebar on the left with the same 8px gap, radius 12, no border and no shadow
  in light mode (the fill step is the separator). Dark mode may add a `border soft` ring if
  the fill step alone is too weak; not both.
- The plate's header is 48px, no divider under it. Title 14/600 ink, 20px from the plate's
  left edge. Header actions (sidebar toggle when collapsed, history arrows) are 28px ghost
  icon buttons.
- Traffic lights stay in the sidebar header row (already built).

## 5. Sidebar (256px)

- Header row: traffic lights, then sidebar toggle and back/forward as 28px ghost icon buttons
  using `MakaIcon::Sidebar`, `ChevronLeft`, `ChevronRight`.
- Brand row: the Maka wordmark (`MAKA_WORDMARK`) in brand blue, 18px tall (69px wide), 16px from
  the left; search icon button at the right edge. Replace the PNG app icon here.
- Primary rows (New task ⌘N): 32px, radius 10, 8px inset from the sidebar edges, icon 16
  muted + label 14/400 ink, shortcut 12 muted right-aligned.
- Folder row: same geometry, `MakaIcon::Folder`, folder name, `ChevronDown` 14 muted.
- Segmented control (By time / By project): 28px, radius 10, track sunken, selected segment
  on plate with `0 0 0 1px border soft` and a 1px 6% shadow, label 12/500; unselected label
  ink muted.
- Group headers: 12/500 ink muted, 28px, chevron 12, 16px left padding.
- Task rows: 32px, radius 10, 8px inset, title 14/400 ink with ellipsis, age 12 muted
  `tabular-nums` right-aligned in a fixed 40px lane; running replaces the age with
  `MakaIcon::StatusRunning` 14 in primary; flagged shows `MakaIcon::Flag` 12 muted before the
  age lane. Hover = hover wash; selected = selected fill, title stays 400.
- Footer row: 44px, 8px dot (success / warning / destructive by connection state) + Host name
  14/400 + root badge (pill, 20px, 12/500 muted on hover fill). No top divider unless the list
  scrolls (already built).

## 6. Empty state

Wordmark in brand blue, 104px wide, centred; 16px below it the line "What should we work on?"
at display 22/400 ink; 8px below, "Tasks run in <folder>." at 14 muted. 32px below, the
suggestions as a single column of quiet rows, not cards: 44px tall, radius 12, `border soft`
ring, `MakaIcon::Thinking` 16 muted + text 14 ink, hover wash. Width = the reading column.
Remove the robot disc.

## 7. Transcript

- Reading column 720px max (`COLUMN_MAX_WIDTH_REMS` at 14px rem = 720 / 14 ≈ 51.4rem; keep a
  single constant), 24px side padding inside the plate.
- User message: right-aligned bubble, bubble fill, radius 28, padding 10 / 18, max 70% of the
  column, body 14/22 ink. No border.
- Assistant text: plain on the plate, body 14/22. Headings 18/600, 16/600, 14/600 with 16px
  above and 8px below. Inline code: code fill, radius 6, 1 / 5 padding, mono at the body size. Code block:
  code fill, radius 10, padding 12 / 14, mono 14/20. Block quote: 2px `border` rule at the
  left, text ink muted. Tables: `border soft` hairlines, header 14/600.
- Tool group: consecutive tool calls share one container: radius 12, `0 0 0 1px border` ring,
  plate fill. Rows 36px, 12px side padding, 10px gap: kind icon 16 muted (`ToolTerminal` Bash,
  `ToolRead` Read, `ToolEdit` Write/Edit/MultiEdit/NotebookEdit, `ToolSearch` Glob/Grep/LS,
  `ToolWeb` WebFetch/WebSearch, `ToolPlug` MCP and anything else), tool name 14/500 ink in a
  fixed 84px lane, summary mono 12 ink muted with ellipsis, optional diff counts `+N` in
  success and `−N` in destructive (mono), status icon 14 (`StatusDone` muted, `StatusRunning`
  primary and rotating, `StatusFailed` destructive, `StatusStopped` muted), chevron 14 muted
  only on hover or when open. Row dividers `border soft`. Expanded output: inset 38px left,
  code fill, radius 10, mono 12/20, max 12 lines then scroll.
- Thinking: same row geometry as a tool row but standalone (no group ring), `MakaIcon::Thinking`
  16 muted, "Thought" 14/500, first line 12 muted with ellipsis; hover wash radius 10.
- Turn footer: supporting 12/20 ink muted, "3 minutes ago · qwen2.5:7b"; on hover a 24px copy
  icon button (`MakaIcon::Copy`) appears after it.
- Queue plate (above the composer): radius 16, canvas fill, 12px padding; caption 12/500 muted
  "Queued after this turn"; each entry 32px with `MakaIcon::Queue` 14 muted, text 14 ink
  ellipsis, actions as 24px ghost icon buttons.

## 8. Composer dock (drawn in Paper)

- Width = reading column, 16px above the plate's bottom edge.
- Plate fill, radius 28, `0 0 0 1px` ink at 8%, `0 1px 2px` ink at 4%, `0 4px 8px -4px` ink at
  8%, which stays on the plate (dark: drop the two shadows, keep the ring at 10%). Padding 12.
- Input: body 14/20, padding 6 / 8 / 2, no inner border, grows 1 to 8 lines, placeholder ink
  muted "Ask anything…" (running: "Queue a follow-up…").
- Controls row, 2px gaps: attach 28px round ghost (`MakaIcon::Plus`, muted), model chip and
  mode chip (28px, radius 10, 14/500 ink, `ChevronDown` 14 muted, hover wash), flexible gap,
  then the send button: 32px circle. Empty draft: sunken fill, `MakaIcon::Send` muted.
  Ready: primary fill, `Send` in on-primary. Running: ink fill, `MakaIcon::Stop` in plate
  colour. One button, three states; never two buttons.
- Attachment chips sit between input and controls: 28px, radius 10, sunken fill, file name 14
  ink + size 12 muted + `Close` 12.

## 9. Menus, dialogs, controls

- Portal surfaces follow DESIGN.md's floating recipe: overlay fill + `border soft` ring +
  one soft shadow + radius 12.
- Menu rows 32px, radius 6 inside a 4px padded menu, icon 16 muted, label 14, shortcut 12 muted.
- Buttons: 32px, radius 10, label 14/500. Primary = primary fill; secondary = plate fill with
  `border` ring; ghost = no fill, hover wash. Focus ring = accent, 2px, offset 1px.

## 10. Acceptance

Screenshots at 1512x885, light and dark, of: empty state, a transcript with a tool group and
code, a running turn with the Stop button and a queued message, the sidebar with a selected,
a running and a flagged task, Settings › Connections, the footer menu. Each compared against
this document and the Paper artboards. Then two independent reviewers (Opus and Fable)
judge the screenshots against AllSum and Maka Desktop and must both say it is ready for the
Maka core team.
