# Quicklink · 快捷链接

插件 ID 为 `maka.links`，1.2.0 兼容既有快捷链接数据、条目 ID、收藏和快捷键。使用宿主提供的列表、编辑表单及条目设置。

在快捷工具搜索“Quicklink”或“快捷链接”，进入后选择“新建”：

- 固定网址：`github.com` 默认使用 HTTPS，也可填完整网址。
- 应用深链：`slack://channel?team=T&id=C`（需要安装对应应用）。
- 本地文件或文件夹：`~/Documents` 或绝对路径
- 搜索模板：`https://example.com/search?q={query}`，也支持 `{argument name="Query"}`。
- 多参数模板：`https://example.com/{项目}/issues?q={关键词}`

打开模板时自动显示参数表单；重复参数只填写一次，参数按 URL 组件编码。`query` 显示为“搜索词”。参数仅支持网址路径、查询和片段，不能改变协议或域名；最多 12 个不同参数。文件路径中的花括号按字面处理。条目设置可添加别名、收藏和快捷键。

选中具体链接，点底栏的“条目设置”。例如给“搜索文档”设别名 `docs`，在首页输入 `docs` 后按回车即可执行。给同一条链接录入全局快捷键后，可以从其他应用唤起它的参数表单。
